# Rule: Guidance Non-Response Handling

各学科已给出明确引导、学生却未正面回应时，按下列信号识别理解困难并先提供支架，再考虑换话题。本规则不用于一般回答质量或情绪评估。

## Signals

| Signal | Description | Example | Detection Threshold |
|--------|-------------|---------|---------------------|
| Short Answer | 当期望解释时，给出简短回答无解释 | "是七"（无后续解释） | 回答少于5字且无后续解释请求时 |
| Skip Request | 跳过引导请求，直接要求换题 | "太简单了，在难点" | 明确要求跳过或换题 |
| Incorrect Apply | 在后续问题中错误应用引导方法 | 引导用加法检查，仍用计数 | 后续问题中未使用引导方法 |
| Contradiction | 响应内容与引导目标矛盾 | 验证加法答案与减法结果不符 | 响应内容与引导验证目标不一致 |
| Fake "I Know" | 说"我知道了"但应用仍错误 | 声称理解凑十，但计算仍用逐数相加 | 声称理解后的首次应用即错误 |

### lower_primary (1-3 年级)

- 简短回答阈值应更宽松：学生天然表达简短
- 重点检测：跳过请求、错误应用、矛盾响应
- 支架方法优先：操作物模型（手指、画图）

### upper_primary (4-6 年级)

- 简短回答阈值更严格：应能给出更多解释
- 重点检测：Fake "I Know"、错误应用
- 支架方法优先：具体例子、重新表述

## Required Action

1. 视为潜在弱项。
2. 先提供支架，再考虑换题。
3. 支架方式优先：改说法、举例、拆步骤、用操作物。
4. 让意义可见，不要直接告知答案。

## Constraints

- 检测阈值要保守。
- 支架方法要符合年级。
- 支架尝试不超过 3 次。
- 不羞辱学生，不强行推进。

## Example

**引导**: "想一想：6 + 几 = 13？"

**响应**: "是七"（无解释）

**检测**: Short Answer without explanation → 潜在弱项

**要求**: 不跳过，提供支架方法
- "我们看看为什么6+7=13能帮我们检查13-6"
- "你能用手指摆一摆吗？"

**禁止**: 继续问下一道题"试一道：12 - 5 = ?"

## Non-Goals

- 不定义具体支架方法库
- 不替代一般响应评估
- 不检测情绪或态度

## Acceptance Criteria

此规则有效当：能识别会话中的明显引导非理解情况，触发后行为符合 Required Action，支架方法符合年级水平。
