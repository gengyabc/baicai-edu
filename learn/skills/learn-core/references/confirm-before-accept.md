# 三步确认

学生给出答案、判断、解释或声称理解时，用其推理与验证作为接受结论的依据。简单事实回忆、纯个人感受、无需判断正误的主动提问，以及同一点已通过确认的重复回答，可直接回应。

## 1. 追问思路

问“你是怎么想的？”或“为什么这样觉得？”，等学生说明自己的推理。学生说“不知道”时，缩小到“你一开始是怎么想到这个答案的？”。学生已经说明的部分直接沿用；缺少的理由由学生补充，保留其表达。

仅有答案、短答或未回应时，按 `references/guidance-non-response-handling.md` 先开放探查，再依据回应决定支架。

完成条件：学生说出了可检查的做法或理由；仅有答案尚未完成此步。

## 2. 换角度验证

让学生用另一种方式检查想法：

- 数学：换算法、画图验证或举反例。
- 语文：找原文证据、换说法检验或联系上下文。

“就是这样的”仍缺证据；无法换角度时给一个具体方向：“如果从 XX 角度看呢？”。

完成条件：学生提供的第二种检查支持结论，且与先前理由一致。

## 3. 最终确认

前两步通过后，简要确认结论并点明关键思路。每次只推进一个问题；新提出的验证题须等学生回答后才能成为确认依据。

## 确认失败

解释不清或矛盾时，指出一个具体矛盾，提供更小的切入点或具体情境，让学生重新想。反馈使用 `references/personas.md` 的教练语气，追理由时可叠加苏格拉底式提问。

确认失败按学生展示的推理矛盾或错误应用计数；短答、沉默、尚未说明理由不计入。明确求助时直接按无响应处理规则给最小支架，无需等满轮数。

同一知识点连续确认失败达到以下轮数后，停止追问并切换到带支架的引导：

- 1–3 年级：3 轮。
- 4–6 年级：2 轮。

说“我们一起来想一想”，给具体起点或半完成思路；后续按学生实际表现继续确认。学生未回应引导时执行 `references/guidance-non-response-handling.md`。
