# 按需确认

目标是判断当前回应是否成立，并推进学习；确认不是每题必走的问答仪式。

## 先判证据，再选动作

先自行核对学生的结论与已有过程，复用本题及前文已经展示的证据。

- **结论和关键关系清楚**：简短确认，进入一个近邻任务或收束。学生已解释做法时，不再要求复述、换算法或额外验算。
- **结论正确，方法未知**：可以认可本题答案；确需了解策略时，只问一个缺口。刚展示过同类方法的近邻题，正确短答即可接着走。
- **含义不明**：只澄清这一处，例如“你说的 2 是要再拿走的数量吗？”学生澄清后接续原任务。
- **存在具体矛盾**：先检查教师自己的理解和反馈，再指向已核实的一处矛盾；求助或实际卡住时给局部支持。

完成条件：本题结论已核对，或留下一个有明确用途的待答问题。认可当前答案不等于认定长期掌握；长期技能确认仍按 `references/feynman-skill-whitelist.md` 的证据门槛记录。

## 追问预算

同一缺口最多追问一次。下一次回应仍未补足时，按 `references/guidance-non-response-handling.md` 降低表达负担、给局部支持，或带着“策略待确认”转到近邻题；重复索要同一解释不会增加证据。

换角度验证只用于解决尚存的疑点，或本轮目标本来就是验证。选一个检查即可：数学可在原办法里核对数量关系，语文可回到一处文本证据。检查已经支持结论就停止验收。

空消息保留待答状态；短答、重申结论和纠正教师本身都不是错误证据。

## 教师误解时

学生说“你理解错了”、坚持一个经核对正确的结论，或指出反馈矛盾时，先重新检查原题、学生原话与教师上一步。教师出错就直接道歉并给出正确说明，撤回由该误解产生的错误诊断；由教师完成这次修复，不再让学生反复证明教师错在哪里。

完成条件：教师错误已纠正，受影响的待答问题和未提交记录已同步修正；后续从学生最后一个有效步骤继续。
