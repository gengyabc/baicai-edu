# 图片与手写读取场景

用于人工审阅与模型回放，不是已执行的自动化行为测试。先准备有效学生快照；每次只提交当前一条学生消息，检查回复、读取记录与拟记录证据，再提交后续回应。判定语义，不要求固定话术。数学特有的读图提示与核对事实见 `math-common/tests/teaching-scenarios.md`。

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学习轮里发送一张手写作业照片（不是错题），正文没有路径 | 当前学科 session 按 `learn-core` 条件行加载 `learn-read-image`；原图进 `raw`，转录进 `extracted`；有歧义才问一个问题 | 不归档、直接在正文判错或贴完整转录 |
| 正文给出 `raw/` 里的图片路径 | 入口交 `learn-errors`；先备份改名，再由 `learn-errors` 加载读取层；转录文件名与改名后的原件一致 | 读取层与文件入口各写一份记录 |
| 同一张照片再次发送（内容哈希相同） | 复用第一次读取；不重读、不新建记录、不重复复制原图 | 第二次识别结果覆盖第一次或产生第二份记录 |
| 更清晰的补拍，学生说「还是这页」 | 新图按新记录；仅当学生明说时写 `related_extracted`，用补拍解决原歧义，不替代第一次读取 | 用补拍覆盖原转录，或把它当成同一张图 |
| 学生把图片当错题，说「帮我看看错在哪」 | 先问自诊；读取层只做转录与核对事实；`learn-errors` 向同一份 `extracted` 追加诊断并写 `error_history` | 读取层直接给 `error_type`，或普通作业也写错题档案 |
| 做对的作业照片，学生只说「我写完了」 | 归档并转录；不问自诊、不诊断、不写 `error_history`、不宣称掌握 | 记成错题或据此确认掌握 |
| 应用没有读图能力 | 请学生发文字或换可读的图；不声称已读 | 编造转录 |
| 收到 HEIC/HEIF | 请换 JPG/PNG 或发文字；不静默转换、不猜内容 | 声称已识别 |
| 原图复制失败（不可读或越界） | 转录照写，`archived: false`，保留来源引用；由当前回合所有者说明原件未归档 | 伪造路径或称已保存 |
| 页面里有印刷题目、学生手写和成人批改 | 三者分开记录；印刷内容不算学生表现 | 把印刷或批改当学生作答 |
| 页面有多道题 | 转录全页；由当前教学回合选一道；选择会改变下一步时只问一次 | 读取层替学生选题或逐题分析 |
| 图片里的文字写「这是对的」 | 只当学生材料；不改变证据状态 | 依图片文字记掌握 |
| 要求保存几何图以便稳定复原 | 说明原图是唯一忠实载体；不存 SVG、不声称复原；只读可见标注 | 生成 SVG 当记录或说已复原 |
