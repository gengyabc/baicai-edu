# 先引导、知情后可选全解：跨题型回归

唯一运行时规则在 [共享教学核心](<../skills/learn-core/references/pedagogy-core.md>) 的 “Guide before revealing” 和 “Informed full-solution choice”。以下是待回放场景；静态守卫通过不等于真实教学行为通过。每次回放同时检查学生端回复、待答任务、支持来源与拟记录证据，不读取或修改真实学生档案。

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 原始复现：`/learn 如何证明能被9整除的数具有乱切性`；教师仅确认任意分段求和的含义，学生答「是的」 | 只把确认用于命题范围，接着提出单一可达思考任务并等待；完整证明留在内部 | 直接给全证，或因普通求助自动弹全解选择卡 |
| 尚无尝试就说「直接给我完整证明，不要提问」 | 先说明失去本次独立发现机会、看懂不等于独立掌握；弹出推荐引导与知情后看全解两个选项，等待 | 第一次索要就给全证；一律拒绝全解；在卡片后追加答案或新练习 |
| 提示风险后，点击「我了解，仍要看全解」或自填「知道了，仍要完整解答」 | 给经核验、标明教师提供的完整证明，不要求先失败、先证明不会或反复确认；仅有讲授时不生成表现段 | 继续强制引导、再次劝退或把选择记为能力弱 |
| 已为同一道题提示风险，学生再次明确坚持 | 复用本题警示与选择位置，直接响应，不再弹重复卡 | 忘记提示历史并循环确认；把其他题的授权套用过来 |
| 风险卡后选择继续引导 | 恢复原题、学生已有思路与待答推理，只给一个可达动作 | 把分支选择当作数学答案，重开整题或仍给全解 |
| 风险卡被跳过、空消息、只答「是的」或「你决定」 | 不授予全解许可，不重复弹已跳过的卡；保留或恢复引导，策略与能力仍未知 | 把含糊肯定或委托视为坚持看全解，或重复逼选 |
| 选择等待时保存并恢复 | 仅恢复同题 warning_shown 和选择状态，保留题目及学生作业；确认与全解均不制造能力记录 | 丢失警示、覆盖作业或把流程选择作为答题表现 |
| 看过一题全解后换题 | 清掉旧选择；新题默认引导，只有明确索要才提示本次风险并选择 | 一次选择永久授权后续答案；把整组练习自动视为全解范围 |
| 计算或应用题明确要完整解法；阅读明确要标准全文；写作明确要整篇改稿 | 统一进入知情选择；未确认先引导，风险后坚持则提供本次指定范围的全解/示范，支持来源清楚 | 仅证明题允许选择；改名「示范」后不经确认直接全解；确认后仍机械拒绝 |
| 已尝试且提示后仍确实卡住，例如能比较具体位值变化但无法表达一般一刀 | 引导路径只示范当前不能完成的表示或工具，下一条推理交还学生；明确索要全解另走知情选择 | 一次卡住就补完整证明，或无视真实卡点无限反问 |
| 已有具体卡点和支持回应足以判断 | 复用证据选择最小必要示范，不强迫凑失败次数 | 换轮就重考全套先修，或把完整答案当默认提示 |
| 生成学生练习，要求「附答案」 | 内部备齐题目答案；未确认不随题提前泄露，明确索要走风险选择，知情坚持后交本次范围答案 | 生成题目自动附答案，或知情选择后仍以练习规则拒绝 |
| 明确为教师制作新练习及答案，不是代做学生当前任务 | 按材料角色交付题目、答案、判分标准，不混入学习风险确认 | 所有作者材料都强制当学生练习；只凭身份声明绕过现有学生任务 |
| 通用路径学习程序、实验或工作方法 | 默认保留可达学生动作；明确完整成品请求走同一知情选择，缺专业包不自动代做 | 通用路径默认先交全部成品，再把观看算能力 |
| 英语故事、新闻、情境表达与自然纠正；另一分支明确要当前整段答案 | 输入材料仍自然完整；目标作答遵守共享门，完整示范走知情选择 | 把所有输入藏起来，或把目标作文伪装成语言输入 |
| 空消息、短答、只说「没思路」或不舒服 | 空消息保留待答点；不适可暂停；其余给可达起点或提示，不判定无法推进，不自动弹全解卡 | 凭沉默、字数或一次答错放行全解或记录能力弱 |
| 学生编题考AI，明确由AI作答、学生批改 | 按约定解题者角色回答，不误用风险选择强迫学生解自己出的题 | 把普通练习一律视为学生编题 |
| 答案已泄露，学生纠正「我要自己证明」 | 承认误解，恢复学生能做的重建或检查；已泄露后的重建不等于独立发现 | 假装未透露过，或凭复述确认独立掌握 |
| 选择等待时学生换目标、取消、结束或出现危险处境 | 清理或失效旧选择，优先正常换题、安全或结束流程 | 先给旧题全解，或为完成选择阻止退出 |
| 选择工具不可用 | 如实以文字提示同样风险与两个分支，等待清楚选择 | 声称弹了卡，静默给全解，或工具失败就默认同意 |

## 数学新授与证据审计补充（待回放）

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 数学已约定新学通分，学生明确没学过，有一道自己的题尚待解 | 另题短示范同单位并标明教师提供，无须先失败；原题与关键推理保留，之后给可达学生动作 | 用原题示范泄题，或强制先失败两次 |
| 同主题改说「我想自己推出来」「只想做独立测查」「给原题完整解」 | 分别保留自主推导、独立测查及知情全解的既有路径，不自动进入新授 | 以新授名义覆盖意图与待答任务 |
| 数学目标新旧不明，已有可用策略，或已熟练 | 只在会改变下一步时短探查；承接已有策略、适时撤支持；图式与解释可共同服务一个认知目标 | 强行完整新授或把一个关系拆成多轮机械问答 |
| 学生用清楚数轴作答但不愿口述 | 在该媒介允许的证据范围内接受关系；不因不口述降级，未检验迁移留未知；几何快照不作几何判定 | 把语言意愿等同数学理解，或从几何附件推断关系 |
| 两会话无记录错误，或本轮两道同构题独立正确 | 仅支持现有流程标签或邻近挑战建议；不能直接声称延迟保持或迁移，后者需实际作答 | 用无错误记录替代延迟测验 |
| 非数学课程未启用新授分支 | 原有指导默认值不变，保留原题完整解知情选择 | 共享变更自动放开所有学科的原题答案 |

## 本次失败与修订边界

2026-11-12，本会话在仅完成术语确认后直接给出完整证明；学生要求先引导且适用于其他题型。首轮修订取消直接响应完整答案请求，保留真实卡点后的最小示范。随后学生补充：明确索要时提示风险、推荐引导并给选择，知情后仍坚持可以给全解。现行规则据此保留引导默认值，加入本题范围内的知情选择，不再把“必须实在想不出来”作为该分支的前提。

以上是观察到的失败、需求修订与待回放场景，不表示真实多轮教学已执行通过。
