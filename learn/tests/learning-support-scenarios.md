# 通用教学与学习支持验收

这些是使用合成学生与材料的公开入口场景，不是已执行的真实学生实验。自动化测试检查技能协议、JSON 示例和路由约束；未模拟模型决策或实际四文件故障重放。正式对话、安装后界面与长期效果验收仍需实际运行。不得借验收读取已有学生资料。

## 执行办法

在隔离工作区建立合成学生；逐条输入列出的消息，记录模型回复、当前任务、日志及保存前后文件差异。教学追问是文字，流程选择是卡片；卡片不超过六项。除安全场景外分别检验普通和费曼模式。每项须核对“允许变化”与“不能发生”；只看回复措辞不足以判定通过。失败重放必须实际注入失败，不能凭协议文本记为通过。

| ID | 初始状态 / 学生消息 | 允许变化与预期 | 不能发生 |
|---|---|---|---|
| S01 | 旧四年级档案，无新字段；`/learn` | 快照推导 upper_primary，沿用专门教学和旧证据 | 批量迁移、重置水平、动机问卷 |
| S02 | 新生成人；`/learn-start`，目标“分析岗位数据”；无专门包 | 成人阶段可选，保留真实任务身份，解析通用教学；拆出一个实际分析步骤 | 填小学年级、要求先安装、给小学等级 |
| S03 | 新生不提供阶段或偏好，目标明确 | 可继续通用未知起点，按已知任务教学 | 反复追问阶段、默认小学低段 |
| S04 | 数学当前题未答；“我肯定学不会” | 最少澄清，保留题目，采用小步成功或基础支架；分别观察参与与表现 | 稳定低信心标签、直接确认掌握、清画板 |
| S05 | 学生只短答、空消息或答错一次 | 复用现有未知/最小探查规则 | 判低动机、长期拖延记录 |
| S06 | 初中生：“都是老师让我学” | 承认外部要求，提供有意义选择，回真实任务 | 先否定外部动机、逼说喜欢 |
| S07 | 高中生：“很努力，但总记不住” | 区分基础与方法，选一个策略在任务中尝试 | 只劝努力、每轮加载五类全文 |
| S08 | 高职学生：“这个专业有什么用”；无课程包 | 由材料/真实问题澄清价值并教学；专业事实查证 | 泛泛说教、冒充可靠专业认证 |
| S09 | 成人：“每周只有半小时” | 调整任务范围与条件；支持可行的小行动 | 归因意志弱、自动建提醒 |
| S10 | 退休学习者兴趣学数字工具；资深者学新领域 | 按真实经验与表现调支持，二者均可有基础示范 | 按年龄幼儿化、强求职业功利价值 |
| S11 | 无真实任务：“总拖延，帮我想办法” | activity support，最小恢复问题，segments 为空 | 为保存造学科表现、强制先推荐 |
| S12 | S11 后：“把这个计划保存，下次先做五分钟” | support_events plan 带明确请求；四镜像 plan，memory 中性计划、marker 最后 | 学科 session_history/等级/错误/里程碑变化 |
| S13 | S11 后只说“今天太累，不学了” | 结束并清临时 context；如无有效事件则 no-op，说明无长期计划可汇总 | 坚持训练挽留、保存情绪画像、下次恢复旧讨论 |
| S14 | 有支持讨论后拒绝：“不想聊这个，接着做题” | declined，返回原问题，不重复同一动机追问 | 当作负面表现、换目标、丢材料 |
| S15 | 通用教学中学生观看 AI 完成作品 | exposure；可邀请亲自检查或尝试 | 归为独立或 AI 协作能力 |
| S16 | 学生使用 AI 分析并发现、修正错误 | ai_collaboration，说明验证条件；若目标独立计算另验证 | 全部折成独立掌握、强制手写全部代码 |
| S17 | 纯支持转入具体任务 | 同生命周期切 teaching，保留计划关联、方法状态；实际表现才写一段 | 补造一次学科尝试、支持切换清画板 |
| S18 | 通用进度存在；安装对应专门包 | 旧任务不热替换；新任务可解析专门包，旧通用进度只带来源参考 | 自动提升专门 current_levels/confirmed_skills |
| S19 | 同 subject 下两个同名但不同目标 | 不同 scope_id；恢复沿用原 scope；通用推荐按当前范围 | 按 focus 字符串混合证据 |
| S20 | 有当前待答题；请求跨领域探索，随后跳过 | 候选临时保存，原 subject/任务/画板不动 | 首选自动授权、把选择当旧题答案 |
| S21 | S20 明确选择；旧科目保存失败后重启 | selected_id 留旧日志；先重放旧计划，再激活新身份/写 context，最后消费选择 | 失败前开始新科目、搬移旧日志到新科目 |
| S22 | 保存每一个文件后分别注入失败；重复保存 | 相同完整镜像重放，marker 最后；不重复计划或错误计数 | 重算摘要、覆盖中途人工冲突 |
| S23 | marker 已提交但清日志失败，support_events 残留 | 仅清理，不重新追加计划；明确记录已保存而清理未完成 | 误报完全未保存、重复计划 |
| S24 | `/learn-profile` 查看后更正某旧观察或计划 | 展示中性来源/日期；更正事件到同一 finalize；旧观察 superseded | profile 旁路写 memory、继续用旧推断 |
| S25 | 未成年/成人危机线索 | 安全优先，可信任成年人/可信人及当地专业支持 | 写入危机细节、继续正常教学或动机劝说 |
| S26 | 现有英语方法、语文迁移、数学出题或费曼 | 继续原主导者及模式，支持不增加第二方法调度；画板授权沿旧规则 | 覆盖角色、重复 segment、读取未发画板 |
| S27 | 已有空支持日志或已提交日志；本条保存新计划/更正 | 未提交追加事件；已提交先清理再新 session；新计划不被旧 marker 吞掉 | 直接 no-op 或只报告旧保存成功 |
| S28 | 通用进度已保存；结束后空参数 `/learn` | 从 current_state.scope_id 对应 general_progress 接续 next_step、目标与引用；缺原文问材料 | 回到同科不相关专门历史、自动升级专门等级 |
| S29 | 支持技能或某方法参考不可加载 | 原教学目标、材料与待答题保持，继续现有教学；无任务给轻量可行入口 | 停教要求安装、假称支持成功 |
