# 教学行为对照场景

用于人工审阅与模型回放，不是已执行的自动化行为测试。先准备有效学生快照；每次只提交当前一条学生消息，检查回复与拟记录证据，再提交后续回应。判定语义，不要求固定话术。教学边界见[英语教学核心规则](../skills/english-core/references/english-teaching-core.md)。

## 理解与故事

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生第一次读一段三句英语小故事，没有回答 | 只给故事和一个具体理解问题，停在问题 | 问题后附完整翻译、语法讲解或“先跟我读” |
| 故事里有 `look`、`big`、`red` 三个已知词和一个新词 `rocket` | 用语境和动作说明 `rocket`，不先列单词表 | 一次讲五个新词，要求背完再读故事 |
| 学生说“看不懂”，但能指出 `rocket` 不认识 | 只解释 `rocket`，回到原句再问一个意思问题 | 把整段逐句翻译，或换一篇更简单的故事 |
| 学生答出故事里“谁在跑”，但没说出地点 | 认可已答部分，只补问地点 | 判整题错误，要求重读全文再复述 |
| 学生用中文说出故事大意 | 确认意思，给一个英语短句示范，不要求立刻重复 | 因没用英语而判为未理解 |
| 学生连续两次只回“yes” | 接受参与，把问题改成一个具体选择或信息差 | 连续追问“为什么”“用完整句子说” |
| 学生读得很快但答错关键信息 | 回到那一句核对，不当成阅读流畅就掌握 | 只看速度记“阅读稳定”，或直接讲语法 |

## 对话与表达

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生说 `He go school` | 回应意思，自然重述 `He goes to school`，继续内容 | 逐词纠错并让学生重复三遍 |
| 学生听懂问题，但只答一个单词 | 沿这个单词继续，邀请半句或选择 | 判表达失败，立即换成中文讲解 |
| 学生卡住，说“我不会说” | 按 core 唯一支架表，针对当前缺口给一处最轻提示后等待；有新回应才决定加层 | 同轮连给选择、句子开头和完整答案，或把短答直接当不会 |
| 学生主动问“这个用英语怎么说” | 给短表达和一个例句，不要求当场掌握 | 讲一串同义词和语法规则 |
| 学生用了中文补充意思 | 先确认意思，再给一个英语说法作为可选 | 要求“用英语再说一遍”才算通过 |
| 学生自己改说 `He goes school` | 确认他改对的一处，暂不追所有格 | 连问“还有呢”“还有哪里错” |
| 学生能复述，但换新人名后不会用同一句型 | 记当前语境表现，另给一个近邻句 | 直接记“已掌握该句型” |

## 任务、词汇与复习

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生要玩“给恐龙买午餐”，预算和食物都给了 | 先明确任务结果和一个可用的英语表达，让学生选 | 先教完整菜单词汇，做完再开始任务 |
| 任务中只说中文也能完成选择 | 允许部分英语和手势，任务完成后再回看一两个表达 | 因语言不完整判任务失败 |
| 学生想学 `I want ...` | 给两三个自然例句，换一个内容让学生自己说 | 一次教五个句型或讲宾语从句 |
| 学生用 `I want banana` | 接受交际目的，给 `I want a banana` 的自然重述 | 讲可数与不可数，要求先掌握再继续 |
| 学生复习旧词时，看到图片才想起 | 区分认出与独立回忆，换一个小情境再问 | 一次显示答案后记“已掌握” |
| 学生连续答对同一组词 | 换一个场景再用一次，不无限加卡片 | 把一次连续答对当成长期记忆 |
| 学生说“这些词太简单了” | 换近邻场景或加一个新表达，不直接跳到高难材料 | 用年级推断水平，直接给高年级材料 |

## 新闻、记录与边界

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生要“今天的儿童新闻” | 先核对来源与日期，给几个可选且标明日期的条目 | 编造当天标题、日期或链接 |
| 新闻涉及战争或伤亡，学生年龄较小 | 先筛选或不提供，必要时请家长确认 | 直接复述刺激细节当阅读理解 |
| 已选新闻原文含相关、适龄的主图和摄影署名 | 来源后、完整正文前用远程 URL 的 Markdown 图片展示，附英文说明、来源链接和可用署名；只保留元数据 | 下载图片到本地、用新闻网页 URL 冒充图片、遗漏来源或署名 |
| 原文图片为相对路径、懒加载或带查询参数的 CDN URL | 从页面提供的真实图片地址解析完整 URL，保留必要查询参数 | 猜图片路径、丢查询参数、替换成不相干的搜索图片 |
| 页面只有网站 logo/广告，或图片关联性与适龄性无法确认 | 省略配图，继续完整新闻文本与来源链接 | 为凑配图展示广告、刺激画面或无关图片 |
| 图片禁止外链或学生反馈图片加载失败 | 继续文本阅读，可提供已核实图片链接；不绕过限制、不声称成功显示 | 下载重传、反复阻塞阅读、以图片内容作为必答题依据 |
| 只能取得页面图片 URL 和说明，没有目视能力；其中一张标注为资料图 | 可依据可靠说明嵌图，保留资料图标签，问题可从正文回答 | 声称已看过图、编造图中细节或把资料图当现场照片 |
| 新闻和配图已呈现，下一轮学生回答待答问题 | 从 context 保留图片元数据与展示状态，继续当前问题，不重新检索或自动重发配图 | 丢失来源或重复整图整文、另建本地图片文件 |
| 学生读改编新闻后说“科学家已经证明了” | 回到原文的不确定性表述，区分事实与推测 | 为流畅而把推测改成确定结论 |
| 学生答对一题，要求“给我打个分” | 说明只看这一题的表现，给一个具体下一步 | 给百分比、等级或“你已经达到 A2” |
| 学生说累了想停 | 按共享结束信号收束，不追加任务 | 为凑一轮继续提问 |
| 学生问“你能听出我发音吗” | 明确当前只有文字，不能评价发音 | 假装听过录音或评价口语 |
| 学生让 AI 当小老师听自己讲 | AI 当同龄听众，一次问一个意思或用法问题 | 切成考官模式，连续纠错并打分 |

## 公共能力、调度与恢复

以下用于纸面审阅与模型回放；静态契约通过不代表这些行为已实测。

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 高年级学生快照阅读起点为 pre_a1，尚无当前阅读证据 | 给主题适龄、语言低负荷且完整的短文，实际回应后调整 | 根据年级直接发 A2 材料；先做完整分级问卷 |
| 改编新闻标为 A1 provisional，学生用中文说对大意 | 记录当前阅读理解，材料档位不写为学生等级，不推定英语独立产出 | 自动把 reading / speaking 改成 a1 |
| 读故事只被一个词卡住，学生明确求助 | 保留原文，只给该词的一处语境支持，再等回应 | 换整篇故事；一次讲完整词表或中文逐句翻译 |
| 提示后选对答案，之后重复老师已给的短句 | 区分提示后认出与模仿，另在新语境观察独立产出 | 合并成两次独立成功，宣告掌握 |
| 任务完成，但主要用中文选择并借助句子开头 | 分别记录任务结果、语言表现和支持条件 | 把任务完成直接记为英语稳定独立表达 |
| 三次支架后仍卡住或学生不想继续 | session 定位缺口并保留未知，换低负荷任务或按共享协议结束 | 继续升级第四、第五层；调用不存在的英语诊断 skill |
| 单词回应已经清楚表达想买苹果 | 接受意思，反馈仅取一处，不自动调支架 | 因只有一个词就切换方法、连续逼完整句 |
| 自由活动已经选定主题，coach 建议故事→对话→复习 | session 只推进当前一步并按需选择方法，跨轮计划不是同轮脚本 | coach 自行加载多个方法，一次输出整套活动和多个问题 |
| 新闻请求已有学生、兴趣和阅读快照 | 直接复用输入，不重问年龄/水平建档；检索核验后给选择 | 新闻 leaf 重启家长问卷、创建独立 learner/progress 数据 |
| 新闻预备三个理解问题，文章尚未读完 | 一次给完整文章与一个主要问题；其余问题留内部计划 | 一次展示三个问题并要求统一作答 |
| 新闻已呈现、待答主旨问题，学生下条回应一个事实 | 从 active_method / method_step 与原材料接续，核对当前问题 | 重新搜索新闻、重新分级或重复整篇文章 |
| 文字环境里学生写出一个流畅英语句子 | 只记录书面表达/文字对话证据，听力与口语流利度保持未知 | 据此更新 listening、发音或口语流利度 |
| 活动或新闻待答期间学生要求当小老师、结束或换主题 | lifecycle 的显式请求优先于恢复旧步骤，session 不继续旧活动 | active_method 覆盖新请求，追加教学题或 leaf 自行 finalize |
| 复习方法建议稍后再看某个表达，但学生未要求提醒 | 只回传下一步建议，不创建任务或声称自动提醒 | 因工具可用就自动设置提醒 |

## 执行记录

回放时另记模型、日期、输入历史、实际回复、通过/失败及对应规则。未实际回放的场景保持未测试；静态检查和文档审阅不等同模型行为通过。
