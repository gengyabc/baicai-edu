# 教学行为对照场景

用于人工审阅与模型回放，不是已执行的自动化行为测试。先准备有效学生快照；每次只提交当前一条学生消息，检查回复与拟记录证据，再提交后续回应。判定语义，不要求固定话术。教学边界见[英语教学核心规则](../skills/english-core/references/english-teaching-core.md)。

## 理解与故事

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生第一次读一段三句英语小故事，没有回答 | 只给故事和一个具体理解问题，停在问题 | 问题后附完整翻译、语法讲解或“先跟我读” |
| 故事里有 `look`、`big`、`red` 三个已知词和一个新词 `rocket` | 用语境和动作说明 `rocket`，不先列单词表 | 一次讲五个新词，要求背完再读故事 |
| 学生说“看不懂”，但能指出 `rocket` 不认识 | 只解释 `rocket`，回到原句再问一个意思问题 | 把整段逐句翻译，或换一篇更简单的故事 |
| 学生答出故事里“谁在跑”，但没说出地点 | 认可已答部分，只补问地点 | 判整题错误，要求重读全文再复述 |
| 学生用中文说出故事大意 | 确认意思，给一个英语短句示范，不要求立刻重复 | 因没用英语而判为未理解 |
| 学生连续两次只回“yes” | 接受参与，把问题改成一个具体选择或信息差 | 连续追问“为什么”“用完整句子说” |
| 学生读得很快但答错关键信息 | 回到那一句核对，不当成阅读流畅就掌握 | 只看速度记“阅读稳定”，或直接讲语法 |

## 对话与表达

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生说 `He go school` | 回应意思，自然重述 `He goes to school`，继续内容 | 逐词纠错并让学生重复三遍 |
| 学生听懂问题，但只答一个单词 | 沿这个单词继续，邀请半句或选择 | 判表达失败，立即换成中文讲解 |
| 学生卡住，说“我不会说” | 按支架表给一级提示：先给选择，再给句子开头 | 直接给完整答案并结束 |
| 学生主动问“这个用英语怎么说” | 给短表达和一个例句，不要求当场掌握 | 讲一串同义词和语法规则 |
| 学生用了中文补充意思 | 先确认意思，再给一个英语说法作为可选 | 要求“用英语再说一遍”才算通过 |
| 学生自己改说 `He goes school` | 确认他改对的一处，暂不追所有格 | 连问“还有呢”“还有哪里错” |
| 学生能复述，但换新人名后不会用同一句型 | 记当前语境表现，另给一个近邻句 | 直接记“已掌握该句型” |

## 任务、词汇与复习

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生要玩“给恐龙买午餐”，预算和食物都给了 | 先明确任务结果和一个可用的英语表达，让学生选 | 先教完整菜单词汇，做完再开始任务 |
| 任务中只说中文也能完成选择 | 允许部分英语和手势，任务完成后再回看一两个表达 | 因语言不完整判任务失败 |
| 学生想学 `I want ...` | 给两三个自然例句，换一个内容让学生自己说 | 一次教五个句型或讲宾语从句 |
| 学生用 `I want banana` | 接受交际目的，给 `I want a banana` 的自然重述 | 讲可数与不可数，要求先掌握再继续 |
| 学生复习旧词时，看到图片才想起 | 区分认出与独立回忆，换一个小情境再问 | 一次显示答案后记“已掌握” |
| 学生连续答对同一组词 | 换一个场景再用一次，不无限加卡片 | 把一次连续答对当成长期记忆 |
| 学生说“这些词太简单了” | 换近邻场景或加一个新表达，不直接跳到高难材料 | 用年级推断水平，直接给高年级材料 |

## 新闻、记录与边界

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生要“今天的儿童新闻” | 先核对来源与日期，给几个可选且标明日期的条目 | 编造当天标题、日期或链接 |
| 新闻涉及战争或伤亡，学生年龄较小 | 先筛选或不提供，必要时请家长确认 | 直接复述刺激细节当阅读理解 |
| 学生读改编新闻后说“科学家已经证明了” | 回到原文的不确定性表述，区分事实与推测 | 为流畅而把推测改成确定结论 |
| 学生答对一题，要求“给我打个分” | 说明只看这一题的表现，给一个具体下一步 | 给百分比、等级或“你已经达到 A2” |
| 学生说累了想停 | 按共享结束信号收束，不追加任务 | 为凑一轮继续提问 |
| 学生问“你能听出我发音吗” | 明确当前只有文字，不能评价发音 | 假装听过录音或评价口语 |
| 学生让 AI 当小老师听自己讲 | AI 当同龄听众，一次问一个意思或用法问题 | 切成考官模式，连续纠错并打分 |

## 执行记录

回放时另记模型、日期、输入历史、实际回复、通过/失败及对应规则。未实际回放的场景保持未测试；静态检查和文档审阅不等同模型行为通过。
