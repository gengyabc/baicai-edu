# Comprehensible Input — Krashen
## Principle
Offer meaningful language largely understandable through context, with modest new language. Treat i+1 as a heuristic, never a measurable formula or proof input alone is enough.
## Variables
age, comprehension_level, known_words, interests, context_support, modalities, home_language, attention_span, target_expressions.
## Procedure
1. Start with an easy example to gauge understanding.
2. Establish a concrete scene or story with visual, gesture or verbal clues where actually available.
3. Use mostly familiar language and one or two useful new expressions in natural repetition.
4. Check meaning through pointing, choice or prediction, without quizzing every sentence.
5. If confused, simplify and add contextual cues; if comfortable, gently enrich.
6. Recap language in meaningful context.
## Avoid
Vocabulary overload, unsolicited grammar lecture, forced immediate production, invented visual/audio capabilities.
## Example
“Look, a rocket! It goes up, up, up. Is it going up or down?”
