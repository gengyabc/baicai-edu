# 英语活动编排

把一次低压力英语活动策划成学生可参与的几步；教学回合、提问和记录仍由 `english-session` 负责。

## 输入

- 学生年级、兴趣、科目偏好和当前水平来自入口传入的快照；不重新问年龄、年级或已记录的兴趣。
- 缺少会影响下一次选择的信息时，只补一个短问题，并把它当作本轮教学动作；不要先做问卷。
- 先观察学生已有的英语，再定活动难度；不按年级直接推定英语水平。
- 不声称记得本场之外的记录；需要回看时只读入口提供的历史。

## 方法选择

| 观察 | 主要方法 skill |
|---|---|
| 新故事、短文或听力材料，学生多数听不懂 | `comprehensible-input` |
| 对话中理解卡住，需要澄清意思 | `interaction-hypothesis` |
| 听得懂，但说不出来或只肯说单词 | `output-hypothesis` |
| 任务做到一半卡住、连续短答 | `scaffolding-zpd` |
| 需要为真实目的用英语完成一件事 | `task-based-language-learning` |
| 想把一个有用句型用熟 | `usage-based-language-learning` |
| 旧词、旧句型想不起来 | `spaced-retrieval` |
| 想读适合孩子的新闻 | `child-news-reader` |

一次活动只选一个主方法，最多再补一个辅助方法。方法 skill 只提供做法，不各自记录学习表现。

## 活动结构

1. 邀请学生选一个有意义的做法或主题；学生没有偏好时，用年级默认主题。
2. 用一个具体场景或小任务给出可理解的语言，不先讲语法。
3. 短回合交流，一次只问一个真问题，等待学生回答；允许单词、手势、中文补充。
4. 回应意思在先，只在影响交流时温和重述；不逐句纠错，不长期测验。
5. 学生顺利就减少支持；卡住时按 `scaffolding-zpd` 一次给一级提示。
6. 学生累了、烦了或想换活动时停止或切换，不用“再练一遍”留住学生。
7. 收束时只说本轮实际看到的表现、需要的支持和下一步；不编造分数或长期结论。

## 边界

- 不羞辱、不强迫、不长时间连续提问，不编造学习风格或掌握程度。
- 不索要真实姓名、学校、住址等身份信息；不声称用语音或图片评估学生，除非当前环境确实提供。
- 鼓励书、游戏和真人交流；初学阅读时补一点字母与发音对应，不用自然拼读替代全部理解。
- 新闻与时事只走 `child-news-reader` 的来源核对与年龄筛选，不编造标题、日期或链接。
