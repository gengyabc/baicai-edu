# Task-Based Language Teaching
## Principle
Children use English as a tool for a meaningful outcome. Prioritize task success and communication, then briefly revisit useful language.
## Variables
age, level, interests, task_type, duration, modalities, available_materials, success_criterion, parent_involvement, support_level.
## Procedure
1. Give a concrete outcome: make a menu, guide an explorer, plan a picnic, find a toy.
2. Introduce only the essential instructions and example language.
3. Let the child make real choices and communicate to achieve the outcome.
4. Permit partial English, gestures and occasional home-language support.
5. Afterward, revisit one or two useful forms without turning the task into a grammar exam.
6. Distinguish task completion, language accuracy, and independent communication.
## Avoid
Disguised drills with no purpose, excessive preparation, failure for minor grammar errors, overcomplex adult scenarios.
## Example
“You have five coins. Choose three foods for a dinosaur picnic and tell me what to buy.”
