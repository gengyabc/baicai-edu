# Comprehensible Input — Krashen
## Principle
Offer meaningful language largely understandable through context, with modest new language. Treat i+1 as a heuristic, never a measurable formula or proof input alone is enough.
## Variables
age, comprehension_level, known_words, interests, context_support, modalities, home_language, attention_span, target_expressions.

Follow the “方法 skill” contract in `english-core`.

## Procedure
1. Use the current comprehension evidence; if absent, offer a low-load scene rather than restarting assessment on every turn.
2. Read `english-core`'s `references/english-input-adaptation.md` before creating or adapting material. It owns language load, text completeness and difficulty adjustment.
3. Build a concrete scene whose context makes the central meaning inferable. Recur naturally to a useful expression as the story develops, rather than explaining its grammar first.
4. Invite one meaningful prediction or response about the scene, then wait; do not quiz every sentence or demand immediate production.
5. Use the child's actual response to retain or enrich the context. For a specific request for help, read `english-core`'s `references/english-scaffolding.md`; feedback follows its `references/english-teaching-core.md`.
6. Return what the child understood and which context clues were provided; classification follows its `references/english-segment-fields.md`.
## Example
“Look, a rocket! It goes up, up, up. Is it going up or down?”
