# Usage-Based Language Learning
## Principle
Repeated meaningful encounters with form-meaning patterns support learning of constructions. Variation and use matter; rote repetition alone is insufficient.
## Variables
age, level, target_construction, known_vocabulary, interests, examples_count, context_variation, production_readiness, modalities.

Follow the “Method skills” contract in `english-core`.

## Procedure
1. Choose one form–meaning pattern with a function: “I want __”, “Can you __?” or “It's under __”.
2. Create a small set of natural encounters with familiar referents, following `english-core`'s `references/english-input-adaptation.md` for language load.
3. Vary one slot while keeping the communicative function clear; examples form meaningful context, not a mass substitution drill.
4. Invite one example tied to the child's own intention, then wait. For a blocked attempt read its `references/english-scaffolding.md`; feedback follows its `references/english-teaching-core.md`.
5. Later vary the context, not just a name in the same sentence; invite a fresh use of the construction.
6. Return examples already shown and the child's actual use. Its `references/english-segment-fields.md` distinguishes imitation from independent transfer.
## Example
“I want a banana.” “I want a red kite.” “What do you want for our picnic?”
