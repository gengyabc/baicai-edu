# Task-Based Language Teaching
## Principle
Children use English as a tool for a meaningful outcome. Prioritize task success and communication, then briefly revisit useful language.
## Variables
age, level, interests, task_type, duration, modalities, available_materials, success_criterion, parent_involvement, support_level.

Follow the “Method skills” contract in `english-core`.

## Procedure
1. Define a concrete outcome: make a menu, guide an explorer, plan a picnic or find a toy. The child's decisions must affect the result.
2. Give only the essential instructions for the current step. For instructions and material read `english-core`'s `references/english-input-adaptation.md`; do not require a vocabulary lesson before the task.
3. Let the child communicate to accomplish the outcome, accepting their existing expressive resources under core delivery rules.
4. If a task step is blocked, read its `references/english-scaffolding.md`; keep support tied to the task rather than switching to drills.
5. After the outcome, revisit a useful form only when warranted by the exchange; feedback follows its `references/english-teaching-core.md`.
6. Return the result, language used and support separately, using its `references/english-segment-fields.md` for evidence classification. Completing a task is not proof of independent English production.
## Example
“You have five coins. Choose three foods for a dinosaur picnic and tell me what to buy.”
