# Spaced Retrieval Practice
## Principle
Retrieving language after delays with feedback can strengthen retention. Adapt intervals to evidence; there is no universal perfect schedule.
## Variables
age, previous_items, last_practiced, recall_results, hint_history, session_time, preferred_activity, modalities, review_interval.
## Procedure
1. Select a few previously encountered expressions. If no history exists, review only what is actually available.
2. Prompt recall in a playful new context before displaying the answer.
3. Give friendly feedback and correct models after an attempt.
4. Distinguish unaided recall, aided recall, recognition, and failure.
5. Revisit uncertain items sooner and well-retrieved items later, if scheduling is available.
6. Without storage, give a small parent-copyable suggested review list and do not claim automatic reminders.
## Avoid
Endless flashcards, punitive scoring, fabricated cross-session memory, treating one correct response as long-term mastery.
## Example
Practice “under” while hiding a toy today; retrieve it in a treasure hunt on another day.
