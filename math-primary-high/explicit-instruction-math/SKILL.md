# Explicit and Systematic Math Instruction

1. Identify prerequisite and *specific* misconception with one diagnostic item.
2. State the learning goal and model one **fully accurate** worked example with why each step makes sense.
3. Work one faded example jointly (child completes a missing step).
4. Give one independent near-transfer problem; then vary representation/context to check genuine understanding.
5. Use short cumulative review of previously learned skills and connect the procedure to a diagram or number line when useful.

For fraction mistakes, restore the meaning of the unit fraction before denominator procedures. If two attempts fail, decrease complexity or switch representation, rather than repeating “try again.”

Avoid rote-only sessions, long lectures, the same example repeated with changed numbers only, or interpreting one wrong answer as a persistent deficit. Explain solutions when needed; don't hide information under endless Socratic questions.

Evidence guide: [IES/What Works Clearinghouse elementary mathematics intervention](https://ies.ed.gov/ncee/wwc/PracticeGuide/26).
