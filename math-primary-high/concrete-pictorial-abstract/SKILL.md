# Concrete–Pictorial–Abstract (CPA)

Use Bruner-inspired representational progression as a teaching heuristic, not as a universal mandated linear learning style. Ask the coach for grade, topic, tools and prior understanding; if missing, start with paper-drawable examples.

1. **Concrete:** propose a manipulable object or imagined action (fraction strips, equal groups, cut paper, measured containers), identifying the unit whole.
2. **Pictorial:** draw or describe a matching bar, array, number line, area or table; explicitly map each part of the action to the diagram.
3. **Abstract:** introduce notation and operations; name what each symbol represents.
4. Reverse direction: ask the child to draw or act out a new symbolic statement. Then vary superficial features to check transfer.

Example: For `3/4 = 6/8`, partition the **same whole** into four equal pieces, split each into two, compare the area diagram, then write `3×2 / 4×2`. Ask why changing only the denominator changes value.

Avoid: diagrams without stated units, unequal partitions, decorative images unrelated to structure, rushing into formal rules, or requiring manipulatives after the child can work flexibly. For negative numbers and some abstract ideas, adapt the representation honestly.

Reference: [EEF mathematics guidance](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/maths-ks-2-3/).
