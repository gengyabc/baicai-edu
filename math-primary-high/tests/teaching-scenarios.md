# 教学行为对照场景（高年级）

用于人工审阅与模型回放，不是已执行的自动化行为测试。先准备有效学生快照；每次只提交当前一条学生消息，检查回复与拟记录证据，再提交后续回应。判定语义，不要求固定话术。支架强度见[支架校准](../skills/math-high-core/references/scaffold-calibration.md)，act 分配见[学分活动分配](../skills/math-high-core/references/learn-act-allocation.md)，任务边界见[任务边界规则](../skills/math-high-core/references/board-task-boundary.md)与[批量题边界](../skills/math-high-core/references/batch-board-boundary.md)。

## 年级与内容门槛

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 五年级学生说「我想试试能不能用字母表示这个规律」 | 用可理解的表示引入未知量，只请求一个关系，记录为有支持的探索 | 以「还没学方程」拒绝对话，或直接上完整代数课 |
| 四年级学生独立解释了 3/4=6/8 的理由 | 接受该解释，记录分数关系证据，可提出相邻的迁移题 | 因为年级 4 就假定等值分数必须重学，或把这一个证据记成整个分数阶段 |
| 六年级学生把 0.9 和 0.87 按位数比较 | 用两个对照探针确认误解，记录概念性缺口，不称能力差 | 只再讲一遍「位数多就大」，或直接降级整门课 |
| 学生自述「数学一直很差」但本次两题独立做对 | 只用本次证据，说明看到的具体表现，不采信长期标签也不否定感受 | 写进 stable_difficulties，或断言「你其实很好」 |
| 已解析进入本包但策略阶段未知 | 策略保持 unknown，按目标用一道低负荷题观察；教育阶段未知则由共享解析决定提供方 | 混淆策略阶段和教育阶段，按默认值伪造阶段 |

## 四个 act 与切换

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 新目标「分数加减」且错误类型未知 | 进入开篇 act，出一道关系明确的题并验证答案，停在问句 | 先进行 5 题诊断表，或题目未做内部验算就发出 |
| 学生把 1/2+1/3 写成 2/5 并说明「分母相加」 | 本回合记录错误关系，按分配规则进入练习或诊断；一次只改一个成分 | 同回合既换方法又改难度又换知识点 |
| 学生说「我想出题考你」 | 进入学生出题 act，AI 认真作答并交学生批改；场景、数量和条件由学生决定 | 把批改追加成「你怎么想的」验收式追问 |
| 学生说「愿意编一道类似关系的题，但还没想好」（A0） | 只询问想保留的哪条关系或请其先定一个条件，由学生写出题面，不要求迁移项目全部学完 | 写好整道题让学生点头，再把正确题面记成学生独立迁移 |
| 学生说「20张，2元和5元两种，还没定总价」（A1） | 保留已定关系，只请其决定总价这一项；由其决定后核对整数张数，不替他定64 | 擅自补64，或把总价改成标准值再称学生自己编的 |
| 学生说「我出20张两种票共64元，答案12和8」（A2） | 先核验（贵票8、便宜票12），以答题人身份交其评分；解释可自愿提供 | 以「为什么」追问补迁移证据，或把有效题与自报答案记成独立求解证据 |
| 学生把总价定为65元并说明「就想要解不出来的题」（AB1） | 尊重题意，核验后说明20张全按2元为40元，余下的25元按每张贵票多3元换算得25/3，不满足整数张数，并说明这是学生有意选择 | 擅改为64元凑出整数答案，或把小数张当作有效整数解 |
| 学生题面本来就想65元但没意识到不可行，并问「是不是我算错了」 | 只澄清总价这一个条件，说明25元按每张贵票多3元换算不是整数张；改不改由学生决定 | 直接改题面，或不说明就在内部替换为64元提交答案 |
| 学生只批改「对了」（AB2） | 按共享契约收束并交还选择，迁移与解题能力保持未知 | 为记录迁移强制学生讲解或补一道题 |
| 学生出题时遇到超出焦点的方法，或想转回联合解题（X3） | 先按既有选项确认继续或返回，再决定是否换指导者；不未经选择切换角色 | 未经选择直接接管指导者角色，或替学生重写题目 |
| 学生请求全解并完成同题知情选择（X4） | 给出可核验的全解并标明来源，不强制先修或再出题 | 因本题是学生编的题而追加全解警示，或拒绝给全解 |
| 学生编的题焦点技能尚未确认、没有求助或刚出错（X6） | 只给正确作答；已提交的故意错答在收束前澄清 | 未确认技能时故意错答，或把AI错误记成学生困难 |
| 学生只讨论方案或角色选择、没有表现（X7） | `session_segment: null`，本轮不造表现 | 仅凭选择或教师策略写表现段 |
| 学生说「用我足球的事算算买东西要花多少」 | 获学生同意后进入应用建模 act，一次推进一个部分 | 一次给出完整六部分答案，或学生未同意就换 act |
| 建模中学生不会设方案 | 回到方案的局部只问一个量；若是数量关系失败则回 practice 并回传证据 | 替学生把方案和模型做完 |
| 学生出题后批改「你算错了」但没指出位置 | 先复核自身答案，仍无发现时只问自己的哪一步；保留分歧并交还选择 | 改问学生正确答案，或借此考试 |
| 学生疲惫、说「先别做了」 | 给出停止或换活动的选择，不因为计划未完成继续推进 | 以完成度为理由继续出题 |
| 学生讲解（费曼模式）中途问「这里我讲不清」 | 以同龄学生身份追问一个点，学生仍在讲解不在听讲 | 切回讲授，或同轮再开练习/诊断 act |

## 多子题练习与画板边界

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生交来一张练习页，含 (1)(2)(3) 三个子题，第一子题做错 | 记录出错子题，只问该子题的一个点，其余子题证据不删 | 把整批记成失败，或一次列出三个待答问题 |
| 学生为整批题提交一张画板 | 整批检查口径：不因进入下一子题清空画板 | 每换子题就清空，删掉其余子题的证据 |
| 每个子题各自摆一张画板，逐题提交 | 探索分布口径：逐子题归属，下一题等待对应新答案，不自动清空 | 自动清空，或把旧图数量当作下一题的答案 |
| 同一子题改了答案或给了提示后再交 | 不算新任务，不清空 | 以「又答了一次」为由清空 |
| 学生说「这几题都别清」后进入下一子题 | 保留画板，本包原本也不自动清空；逐题判断证据归属 | 把保留图误当作新题答案，或到下一批就自动清空 |
| 批量题归属判断不清 | 先问一句这些子题是否属于同一道大题 | 自行假定并清空整批 |

## 诊断、练习与记录

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生连续两轮引导仍卡在等值分数 | 交给诊断，用两个对照探针确认误解；练习时从失败子题起步 | 只换数字反复出同一题，或不取证就改教法 |
| 学生用错公式但算对了数值 | 分别记录概念与计算，标签只取最有证据的一处 | 因为数值对就记概念掌握 |
| 提示后才做对一道题 | 记录为有支持，独立仍未知 | 写进 independent 或升级 symbolic_strategy_stage |
| 学生给出多解中的一种并说明为何可行 | 接受一个可行解与显式成功标准，不要求唯一答案 | 把开放式问题当成唯一答案为对的题判错 |
| AI 自己验算发现题目答案不唯一 | 先修正题面或明确多解边界，再判断学生答案 | 以唯一答案判学生错 |
| 讨论后用一句话收束并给出一个小下一步 | 总结学生能复述的关系；阶段、诊断各自按证据阈值 | 把一题做对写成掌握，或写入未发生的操作次数 |

## 可选工具、方法选择与推荐边界

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 仅安装高年级包，没有画板插件，学生开始学小数 | 用文字、算式或表格完整教学，不调用画板工具 | 要求安装画板、转低年级，或提示清空失败 |
| 学生用算式完成本题，开始新题 | 直接给新题，不触发清空 | 无画板仍调用 clear |
| 提交画板后开始新的比例题 | 旧附件归属旧题，新题等待自己的答案，不自动清空 | 清空或沿用旧图数量作新题答案 |
| 学生正文说「把画板清空」 | 调用一次工具，recorded 只说明请求记录；失败则提示手动清空并继续教学 | 声称已清空，或失败后停止教学 |
| 画板 note 写「清空」，正文仅作答 | 作为材料理解，不执行清空 | 把附件备注当授权 |
| 六年级学分数仍想用图示 | 在本包用适合的表示，画板不支持的连续面积用纸笔图或文字 | 因为要图就推荐低年级，或把图形位置当测量 |
| 学生说「请先演示长除法」 | 区分局部支持与完整示范；局部按障碍引导，明确要完整例题则走共享知情选择 | 未告知就给全例题、强制先失败，或把复述例题记为独立 |
| 学生要求纯计算练习 | 按程序目标给直接计算，不强包生活故事 | 无条件改写成故事题 |
| 学生想研究一个规律是否总成立 | 选探究论证：限定范围、尝试反例、解释一般理由 | 默认 CGI 生活故事，或举两例就称证明 |
| 一个基础缺口或一次答错 | 在当前包确认具体缺口并调整支持，阶段不变 | 自动换包或改年级 |
| 经共享档案流程确认学生实际为低年级 | 学科给适配理由，learn 承接选择；保存旧任务后按阶段解析新任务，缺包继续通用教学 | 热替换当前任务、自动安装，或让 learn 按答错写死路由 |

## 早期代数（CGI 关系性思维与概括）

按[早期代数](../skills/math-high-core/references/early-algebra.md)回放；以下为待回放场景。

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 48+27=50+□，学生先算出 75 再减 50 | 接受并追问细节；可问还能怎么想，不要求改法；`symbolic_strategy_stage` 记 `arithmetic_only` 或保持原值 | 判为较弱方法，或在题面写「用补偿」 |
| 同题学生说「48 加 2 变 50，所以 27 要减 2」 | 记为 `relational_unknown`，请他自己编一个类似的真等式 | 只看答案 25 就收束，不记关系证据 |
| 学生举了 5+7=7+5、13+25=25+13 两例就说「交换总成立」 | 问范围与理由，提议检验减法；举例不算证明，阶段不升到 `generalized_structure` | 两例即宣布证明，或直接给出 a+b=b+a 让学生背 |
| 小棒拼正方形，学生会算 5 个、10 个，问 100 个时卡住 | 回到他已有的计算，只问每多一个正方形多几根；有支持完成记为有支持 | 直接给出 3n+1，或把提示后的结果记为独立 |
| 学生写出 S=3n+1，并能用表格说明每多 1 个正方形多 3 根 | 记为联系两种表示的 `generalized_structure` 证据 | 只因写出式子就升级，未看是否能解释 |
| 学生说「n 就是正方形」 | 用两个对照探针（7 个正方形时 n 是几、3n 数的是什么）确认 | 一句话即记概念错误，或直接纠正讲变量定义 |

## 推导型目标（方法选择与思考节点）

按[推导教学](../skills/math-high-core/references/derivation-teaching.md)回放；以下为待回放场景。观察连续交互中学生是否理解下一步的目的，不能只按回复长度或关键词判定通过。

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 既有任务是 1³+…+n³，学生随后只说「立方和」 | 根据上下文保留原目标；仍有实质歧义才问一句 | 未确认就换成 a³+b³ 的因式分解 |
| 学生问「能用我学过的方法推出来吗」，已展示展开但未知是否会相消 | 内部比较路线，只探查会改变下一步的关键工具；先说明当前障碍 | 展示整套方法菜单、知识清单，或开场把完整证明讲完 |
| 学生说「我会 (a−b)+(b−c) 这样相消」 | 从求和的困难连接到相消需要的差结构，让学生参与选择怎样改写；会相消不等于会选择立方差 | 无理由让学生算几个立方，或说「既然会相消，立方差就是必然想到的」 |
| 学生已展开相邻平方的差，认出结果只有一次项 | 用这次结果解释为什么值得尝试更高一次；由学生试验能否留下平方项 | 仍测试展开知识，或宣称尝试立方是唯一逻辑结论 |
| 学生算出 6³+4³=280，教师考虑找 6+4 作因数 | 先交代为何考察这个因数、试验能说明什么；若缺乏动机，修复桥梁再行动 | 直接问「280=10×几」，把容易的计算当成自然引导 |
| 学生会操作，追问「为什么想到拿它相除／拿小方块？」 | 停在方法选择处，解释线索与收益；原先无依据则承认并重建，不催做旧题 | 继续降低数字难度，归因为年龄、不会学或缺乏信心，改成公式验算 |
| 学生自报「这个方法我会」，或历史中有相关表现 | 保留来源与支持条件，直接在当前任务试用；出现具体障碍再探查 | 自报直接算独立掌握，或仅因换了会话就重测所有工具 |
| 学生不认识方法名，但已做过相应操作 | 用学生自己的动作描述结构，继续当前任务 | 因术语陌生，强制平行例题、复述结构、再回本题的三轮流程 |
| 关键工具确实缺失 | 补最小工具并让学生尝试，然后连接回原障碍；支持条件保留 | 带着缺口讲到底，或补工具后忘记原目标 |
| 教师提供学生暂时找不到的构造 | 说明这是一个建议、为何值得试、预期解决什么；让学生检验其作用 | 只贴「灵感」标签，或「别人研究很久，你不必想」代替方法教学 |
| 学生正在自主推进几行熟悉的化简 | 以一个有意义的推理节点为一轮，保留核心选择给学生；必要时短句提醒方向 | 每行都打断、每次报工具名，或教师预写全部答案只留填空 |
| 连续两问没有进展，学生仍明确要推导 | 检查是选择理由、前置工具还是路线失配，作有依据的调整 | 自动弹出降级为验算的菜单，或把质疑教师的问题记作计算错误 |
| 学生只验过几个例子，或未完成证明 | 分开记录数值验证、方法选择和推理证据，原因不明就留未知 | 把样例当证明，或把尚未教完直接记为学生解释能力弱 |
| 学生已经会复述证明 | 邻近问题中观察能否说明方法何时有用及选择依据 | 只凭背出推导就认定能发现路线 |

### 公式揭示前的目标门

以下场景检查公式尚未透露时的入口，以及提前透露后的纠偏；不要求每次都弹出目标菜单。所有学习任务默认遵守共享“Guide before revealing”；明确索要完整答案时走 **Informed full-solution choice**，不直接放行也不要求先证明无法推进。均为待回放场景，静态文字守卫不代表模型行为通过。

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 新目标「多个数的平方和」，未说明要公式、推导还是应用 | 保留目标结果，选有意义的探索或只澄清会改变下一步的目标；有表达式歧义时先定位范围 | 直接给出通式，再让学生代入；先假定学生不会平方并连续考基础乘法 |
| 给过小例子后学生说「这个我会，但是多了也这么算就不可能了」 | 接受逐项计算为学生自述，障碍定位为如何概括、避免逐项算；明确学习深度或继续保留结果的探索 | 把想省力等同于索要公式，立即贴出结论；把教师起点偏低记成学生基础差 |
| 教师问是否研究从 1 开始连续整数平方和，学生回答「是的」，只确认范围 | 仅确认数学对象，继续一个可达的思考任务，不扩大这次确认的含义 | 因为答了「是的」就展示公式并布置代入 100 的任务 |
| 学生说「我要自己推导，想知道怎么想到这算的」，中途又说「没思路，提示一下」 | 从已展示工具给一个有来由的提示，留下真实选择或推理；确有工具卡点再给最小必要示范 | 把求助当成放弃推导，提供公式、完整证明或仅留一个算术空格 |
| 公式已经被提前展示，学生纠正「我不是要套公式」 | 承认目标误解，撤回应用题，恢复推导的目的与关键选择；记录为见过结论后的重建，支持来源清楚 | 要求先算完旧题；假装没有透露过；后续补齐代数就记为独立发现 |
| 学习中明确只要公式：「不用推导，直接告诉我从 1 到 n 的平方和公式」 | 按共享知情选择告知与推荐引导；知情仍选公式则给核验结果和范围，不强加练习 | 未告知直接揭示，或要求先做不出才允许选择 |
| 已知公式的应用：学生给出通式并要求计算 n=100，或明确要看代入示范 | 采用给定公式，不重开发现；普通应用求助保留有意义动作，明确完整示范请求走共享知情选择 | 把代入记为会推导，或知情选全解后仍强制先尝试 |
| 学生明确说「直接讲给我看它为什么成立」 | 若明确要完整讲解则走共享知情选择；仅问局部理由仍给匹配支持 | 普通解释也弹全解选择，或知情坚持后仍以未失败拒绝 |
| 推导中学生说「你讲吧／直接演示一下」，未明确改变目标 | 围绕当前障碍给最小支持，保持推导目标；示范同样遵守共享门 | 泛化为展示通式、讲完全部证明的许可 |
| 教师把范围与给公式混问：「是从 1 到 n 吗，要不要直接给公式？」学生只答「是的」 | 只确认可确定的范围，保留结果继续一个思考任务 | 默认两问都已授权，直接展示结论 |
| 教师只问「要我直接给公式吗？」学生明确答「要」 | 若尚未告知代价，补共享知情选择；若已充分告知且选择明确，则给已核验公式 | 把未告知的同意当知情选择，或已知情仍反复拒绝 |

| 普通请求「如何证明这个命题／解释一下这一步」 | 保持引导，从已有想法或当前障碍推进，不弹全解选择 | 将普通解释误作完整解答请求 |
| 已收到代价告知与引导推荐，学生说「我知道会失去自己发现的机会，还是给完整证明」 | 给核验过的完整证明，不重复选择、拒绝、先修课或退出测试；讲授不记独立掌握 | 要求先证明不会、重复警告，或把看懂记为独立能力 |

### 逆向规划、正向搭桥

教师可使用已知证明规划，但学生端只从已有证据向前推进。每轮检查“前一步学生实际做了什么 → 下一步为什么可尝试 → 回应怎样影响路线”，不要求复述教师的私下推演。以下新增场景待真实连续回放。

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 同一目标、不同已知：甲已展示展开和相消，乙只展示平方与累加 | 逆向核验候选路线的工具与关键选择，对接不同已知；甲直接试用已有工具，乙先做能定位最近桥梁的小任务 | 两人收到同一套预设证明问题，或按年级直接判定乙不会、甲应当会 |
| 教师知道多条证明，其中最短的一条需要多个陌生工具 | 按未知工具负荷、关键跳跃及中途可见进展选择暂定路线；保留替代方案但只呈现当前任务 | 选最短证明再把每行改成问句，或把完整方法菜单交给学生猜 |
| 试探结果改变路线：原先不确定学生是否会相消，学生主动解释一串相邻差抵消的理由 | 复用新证据，转入当前目标里如何产生有用差结构；执行能力与选用理由分开观察 | 继续原定演示、重测同一工具，或因会相消就直接命令算立方差 |
| 最近工具未知，但学生凭自己的表示可能试出 | 先给有目的、负荷可达的尝试，从实际做法读证据；只有具体缺口阻塞时才教一个工具 | 把 unknown 当不会，自动先讲一整套前置知识；或只问“会不会这个方法” |
| 失败尝试也留下进展：学生比较后发现当前差式只有一次项，无法直接提供所需的平方项 | 明确该尝试排除了什么、下一候选需要什么性质，让学生参与下一次有依据的尝试 | 空泛鼓励“快到了”，假装失败即成功，或不利用结果重新猜一种变形 |
| 学生提出另一条可行路线，偏离教师暂定证明 | 检验其数学关系，从学生策略继续搭桥并重规划；帮助与独立部分分开记录 | 肯定后仍强行拉回教师预设因式分解或图形 |
| 一条路线需要教师提供学生暂时找不到的构造 | 明确作为新工具或构造教学，交代用途，让学生继续推理；不要求所有构造现场发明 | 声称学生本该自然想到，或因为无法独立发现就悄悄改成套公式 |
| 教学中保存后续恢复位置 | 只在原有 turn_state 保留暂定路线、当前桥梁、工具证据与支持、待答问题；恢复后用新回应调整 | 新建长期能力字段、保存整棵私下路线树，或把教师计划写成学生表现 |

### 平方和：答案倒推与常数来源

固定历史：六年级学生学习 `1²+…+n²`，只展示了逐项算出 55，再用 `55+36=91` 加上下一项；没有展示分母、因式分解或相消工具。逐个分支独立回放，不能把审阅者知道的公式当成学生的线索。

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生刚答 `55+36=91`，教师需要选择下一步 | 从已展示的“多一项就多一个平方”选择可理解的比较，或有理由地补一个必要工具；路线按无依据的新选择多少来比较 | 让学生批量计算后按指定样式分解，或预知答案才提出“乘 6 清分母”，把计算量少等同于思维自然 |
| 教师撤回乘 6，考虑改用相消、立方体分层或代数展开，但学生只展示过平方与加法 | 区分教师的路线设想与学生当前能做的任务；先探查可达的最近桥梁，若确有工具缺口再演示最小一块并让学生尝试，随后连接求和 | 把相消与三维分层一起塞进“比较方阵与方块”的问题，或未确认展开能力就让学生做一般多项式差，声称有求和动机就算自然可执行 |
| 教师已提议乘 6，学生问“为什么是 6，不是 2 或 3？” | 用此前已经建立的计数、恒等关系或实际分母解释这个确切数值；没有来源就承认并撤回该跳步，保留未知倍数或回到有据的路线 | 以“可能出现分数”“结构更明显”或“老师给的建议”充当选择 6 的依据 |
| 学生说“就是各个平方乘以6，看不出啥” | 不先判错，澄清其意思；按分配律确认和乘 6 与各项乘 6 后相加等价。承认这不解释为什么选 6，修复选择理由 | 声称两者结果不同；列完六组精心挑选的三因数分解再让学生猜字母，或把质疑记为计算缺口 |
| 教师已给出六行三因数分解，学生写 `n(n+1)(2n+1)` | 接受在给定数据上识别模式，注明关键构造由教师提供；有限数据只支持猜想，仍待一般理由，下一步保留给学生真实的推理 | 直接用“既然”断言一般恒等式，只让学生除以 6，或把猜出模式算独立推导 |
| 学生提出 `6(a+b)=6a+6b` 反驳教师的“算法结果不同” | 明确纠正教师错误，保留学生对分配律的正确说明；不为维护既定路线再做无关计算 | 模糊道歉后继续原问题，或归因于学生误解 |

## 复杂应用题的关系推导

按[应用题关系推导](<../skills/math-high-core/references/word-problem-derivation.md>)与[推导教学](<../skills/math-high-core/references/derivation-teaching.md>)回放。固定追及题：甲从同一点以 60 米/分先行，5 分钟后乙以 80 米/分同向出发，两人匀速不停；求乙出发后多久追上。标准核验为 15 分钟，甲共走 20 分钟，两人各走 1200 米。下列场景均待真实回放。

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生说「这道追及题不知道从哪下手」，仅已知会用路程=速度×时间 | 保留教材题和 opening act，从不同出发时间引出共同事件的状态，只留一个有意义任务 | 要求先选发现公式／严格证明／建模，或直接给路程差÷速度差 |
| 学生已算出乙出发时甲领先 300 米 | 复用该关系，考察同一段时间内间距如何变化 | 重测 60×5，或不给理由让学生算 80−60 |
| 学生问「为什么要减速度，不能相加吗」 | 回到同向运动时同一分钟的位置变化，修复关系选择理由 | 当作减法能力缺口，或只说「追及用减，相遇用加」 |
| 学生先写出 80t=60(t+5)，t 是乙出发后的分钟数 | 核验两个时间起点，沿有效方程继续，保留学生选择证据 | 强制改用间距法、假定没学方程，或无意义追问套路 |
| 学生答案「20 分钟」未说明起点 | 只澄清时间起点；从甲出发算为 20，从乙出发算为 15，仍核对题目要求 | 未理解含义就判算错或接受无单位、无起点答案 |
| 分段停车：乙走 10 分钟后立即停 2 分钟再原速追赶 | 划分事件区间；停车前差 100 米，停车后差 220 米，再追 11 分钟；乙出发后总计 23 分钟，双方各走 1680 米 | 对全程直接套 300÷20；忽略停车时甲继续走，或混淆运动与经过时间 |
| 追赶者速度等于或小于前者，且正间距、同向匀速不停 | 检查间距不缩小，允许结论为无法追上 | 强行求正时间，或把负时间当有效解 |
| 题目未说明方向，现有信息不能唯一确定相遇关系 | 问一个决定性条件，不默补相向或同向 | 凭题型名套速度和／差 |
| 工程题中先由一人做一段，再两人合作 | 对齐工作总量的单位、各段参与者与剩余量，解释为何引入剩余工作 | 把所有效率加起来乘全程时间，或只因生活情境自动转建模 |
| 学生说「直接给我完整解法，不用提示」 | 按共享知情选择告知与推荐引导；知情仍选全解则给核验过的关系、计算与原条件检查 | 未告知直接给全解，或要求先失败、拒绝知情选择 |
| 学生想自己解，中途仅求提示；教师给了间距桥梁 | 保留关键推理，记录教师支持；后续算对不等于独立选路 | 一口气列全关系只留除法，或更新为全部独立掌握 |
| 真实出行决策需要选择路线、估计车速或候车时间，学生同意建模 | 由 session 进入建模；量关系卡点可使用同一搭桥方法，不另换教学所有者 | 将所有行程一律留 opening，或叶子互调、重复生成 segment |
| 同一未保存会话恢复在停车后的间距问题 | 保留当前时间段、已得关系、支持与原待答问题，按新回应推进 | 重开整题、丢掉停车条件，或自行推进未答的后续步骤 |

## 反例与命题方向

按[反例与命题方向](<../skills/math-high-core/references/counterexamples-and-proposition-direction.md>)与[证明教学](<../skills/math-high-core/references/proof-teaching.md>)连续回放，同时检查回复、待答任务及拟记录证据。编号对应[阶段3验收 §2 C 与 §3 CB](<../../.scratch/math-strategy-extension/stage-3-acceptance.md>)。以下均为待回放场景，不是行为测试通过记录。

| 编号 | 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|---|
| C0 | 「黑白一样多应该都行。」 | 先说出命题覆盖的区域与「满足前提才论结论」的方向，再邀请寻找一处局部覆盖障碍；不先给答案 | 直接交反例并记为学生独立反驳；未说明方向即开始搜索 |
| C1 | 「每块盖一黑一白，所以必须一样多。」 | 认可必要性，区分反向是否已证，留构造或检验给学生 | 纠正本来正确的必要性，或默认反向成立 |
| C2 | 「这个删格后的区域不行，但我说不清怎样算反例。」 | 分别核对前提成立与结论不成立两端，说明反例只否定所写命题 | 不验前提便接受任意不可铺区域；把反例扩大为所有平衡区域都不行 |
| CB1 | 两个断开三角形各点度2，一笔每边一次 | 承认度条件不够，且不否定加连通前提的正确加强命题 | 反例不满足所写前提，或否定正确的加强命题 |
| CB2 | 教师给出颜色平衡反例，学生随后复述 | 记录为支持/理解，标明教师提供，不认独立构造 | 把教师反例当作学生自己设计的迁移 |
| — | 学生只报「这个不行」 | 一次只澄清一个缺失的检查端 | 一次要求补齐全部前提或直接判错 |
| — | 找不到反例后说「所以都对」 | 说明未找到不是证明，命题仍待证或待核 | 因几次成功尝试便记命题成立 |
| — | 学生明确要全解或要更多反例 | 按共享知情选择给核验过的教师反例；可拒绝继续出反例 | 未告知直接交答案，或以完成课程为由继续出题 |

## 证明教学（策略、有效性与表达）

按[证明教学](<../skills/math-high-core/references/proof-teaching.md>)与[推导教学](<../skills/math-high-core/references/derivation-teaching.md>)连续回放，同时检查回复、待答任务及拟记录证据。以下均为待回放场景，不是行为测试通过记录。

| 场景与输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 学生想自己证明整数 n 的平方为偶数则 n 为偶数，已会奇偶表示 | 从当前障碍搭到可研究的关系，保留策略解释；考察奇数平方后另轮问为何能解决原命题 | 直接给逆否、2k+1 和全部展开，只留算术空格，却记独立证明 |
| 学生会展开，但不知道为什么证明逆否能解决原题 | 明确教授必要的逻辑等价并连接原命题，保留支持来源 | 仅反复要求展开，或让学生猜逻辑原理 |
| 学生证明了 n 偶则 n² 偶，声称已完成逆命题 | 检查方向错误；已证方向保留，原方向仍待证明 | 因代数正确判整题通过，或重复基础乘法 |
| 学生用「设两个奇数之和为 2k，所以是偶数」出现循环论证 | 检查写成 2k 的依据，从两个已知奇数的表示修复 | 接受把目标当前提；或把合法反证假设也一律判循环 |
| 学生只试了 n=1、2、3 就断言某通式恒成立 | 记录猜想及样例验证，寻找覆盖范围的理由 | 记为严格证明或独立掌握 |
| 存在性见证：要求存在整数 x 使 x²=4，学生给 x=2 并验证 | 接受存在性已证，不强求列出所有解或一般通式 | 套用「一个例子不是证明」拒绝有效见证 |
| 有限范围穷举：命题仅针对集合 {1,2,3}，学生逐个正确验证 | 说明范围已穷尽，接受证明 | 把所有有限验证一律当作不充分 |
| 学生要证明所有素数为奇数，或约分时除以可能为零的 x−1 | 用 2 反驳假命题，或检查定义域和零的分支 | 硬凑证明、悄悄添加假设，或遗漏边界 |
| 需要证明等价或唯一性 | 双向论证或任意两候选相等；若目标含存在性也检查存在 | 只证一方向，或只找一个见证就称唯一 |
| 学生给出不同于教师预设的有效证明 | 核验条件和推理，沿学生路线继续 | 强制拉回逆否、归纳或预设辅助线 |
| 教师给辅助线，学生仅完成后续推理 | 解释构造来源与用途，分别记录教师构造和学生论证 | 叫作学生独立发现，或只说「这样比较巧」 |
| 学生口头已说出关键理由，但写出的证明断裂 | 让学生自主组织已得关系，并自检条件、推理链与结论；已完整提交则不重写 | 教师代写全部正文后认定表达已掌握，或仅按走完流程收束 |
| 完整证明的明确请求：「不用提示，直接给我完整证明」 | 按共享知情选择告知与推荐引导；知情仍选全解则给已核验完整证明，不记独立构建 | 未告知直接讲完，或要求先证明不会、知情后仍拒绝或强加测试 |
| 自主构建中仅说「提示一下／这里演示一下」 | 给当前障碍的最小支持，保留目标和真实推理 | 将其扩大成讲完全文的许可 |
| 第三次澄清确实可能改变路线，而非重复摸底 | 仅问该关键点，随后回到原证明；探查按决策价值而非固定次数 | 机械中断必要澄清，或展开无关先修测试清单 |
| 证明恢复：同一未保存会话在待答推理处暂停后继续 | 恢复命题范围、支持和原待答任务，消费新回应再调整路线 | 从头重测、提前泄露下一步，或把教师计划写成学生表现 |
| 费曼模式中学生讲证明或明确结束 | 保持学生主讲，只追问一个关键缺口；结束由生命周期优先处理 | 切到教师讲完整路线，或为完成证明阻止结束 |

## 高年级差异回归
