# 先搭桥，再推导：核心行为验收与回归

状态：**待真实模型多轮回放，未执行**。这是人工/模型行为验收材料，不是自动行为测试。静态合同只能检查规则与材料挂接，不能证明模型按规则教学，更不能证明学习效果。

规则入口：[推导教学](<../skills/math-high-core/references/derivation-teaching.md>)、[应用题关系推导](<../skills/math-high-core/references/word-problem-derivation.md>)；总入口：[教学场景](<teaching-scenarios.md>)。

## 回放约定

- 准备同一有效六年级学生快照，目标为自己找出解题路线，未见本题答案；各分支复制快照独立执行，不把其他分支的提示或答案带入。保持模型、配置及无关历史一致，保存版本标识。
- 每次只提交一条当前学生消息，先检查实际回复、唯一待答任务、拟记录证据，再提交与该任务相容的下一条。表中后续学生回应只在相应问题出现时使用；教师偏离时记录偏离，不硬接答案伪造成功。
- 可对旧/新规则分别配对回放。按语义判定，不要求固定话术、固定解法或固定轮数。教师的路线、提示、构造与学生自己的选择和执行逐项分清。
- 每轮一个有意义的思考任务，至多一个待答问题；不因验收要求强迫学生做迁移、解释已经展示的连接或继续学习。只讨论路线偏好而无数学表现时，`session_segment: null`。

## B1：不同已知，不同开场

共同题面：甲以60米/分从同一点先走，5分钟后乙以80米/分同向出发，均匀速不停；求乙出发后多久追上。两人都已展示会用“路程=速度×时间”。

| 分支 | 学生输入与已知 | 必须观察 | 失败信号 |
|---|---|---|---|
| B1-A | 「我想自己解，但两人出发时间不同，不知道怎么放在一起看。」没有其他关系证据 | 从事件/位置/时间关系给可达起点，保留一个实质选择，如用什么状态或表示连接两人；可用表、式或口述，不强索口头计划 | 直接指定300÷(80−60)，完整列关系只留除法；或无任务价值的基础乘法摸底 |
| B1-B | 「乙出发时甲已走60×5=300米；后来每分钟差距少80−60=20米。我还没接到要多久。」 | 直接沿已给关系推进到时间，不重测300或20，不强加找路线阶段；认可算式已展示连接 | 与A收到同一套起手问题，或仍问为何想到减速度，要求再画图才允许推导 |
| B1-C | 「我会算60×5，也会算80−60，可为什么要算这两个？」 | 接受执行工具可用，修复共同时间与间距变化的用途桥梁，留关键推理给学生 | 降低数字重教乘减法，或因算得出就记独立选法 |
| B1-D | A后续实际表示暴露“把甲的总运动时间也记为t” | 只处理时间起点这一具体障碍，保留原题；若仅原因未知则不预判缺口 | 仅凭“不知道”宣布先修不足，先讲整套行程公式 |

配对通过标准：A与B的下一数学任务实质不同，不只是换称呼；C将“会执行”与“不知用途”分开。A没有整体图景时获得起点，B已经连通时不受重复规划阻拦。

## B2：接住非标准路线，不把教师路线演成发现

沿用B1题面。教师可暂定间距路线，但不能把它写成学生既有选择。

| 分支 | 当前学生消息 | 必须观察 | 失败信号 |
|---|---|---|---|
| B2-A | 「我不用间距。设乙出发后t分钟，两人到同一处，所以80t=60(t+5)。」 | 核验时间起点与共同位置，直接沿有效方程推导，不另开选路探针；方程已体现关系，不强迫补口头计划 | 表扬后仍要求回到300÷20，或以没学方程为由拒绝 |
| B2-B | A后续自己写「80t=60t+300，所以20t=300，t=12。」 | 保留学生独立选方程与前面有效步骤，定位300÷20的执行错误；不能把整条路线判错 | 说方程法不适合、重开间距法；或因路线正确接受12 |
| B2-C | 「80t=60t+5，因为甲早走5分钟。」 | 先检查5的单位与对应路程，修复具体关系；既不盲从“不同方法”，也不趁机强制换法 | 不核验即接受，或把关系错误解释为学生只准用标准法 |
| B2-D | 教师先给80t=60(t+5)，学生独立解得t=15 | 可记方程执行，明确关系由教师提供；独立选路仍未知 | 把算对方程记成学生独立建模/独立发现 |

B2-A→B2-B是连续主分支；C、D分别重置。核验：t=15分钟，甲共20分钟，双方路程1200米。数字和核验结果仅供审阅者，不注入独立开场。

## B3：无方法暗示迁移；旧法不便时允许换路

前提：学生完成前题后同意“换一道新情境试试自己找路”，只把前题实际发生的支持带入记录，不预先复习方法。清除会透露路线的教师示意或提示；不清学生草稿、不读取未发送内容。

**B3-A 独立迁移题（学生端只见这一题面）：**「甲水箱已有200升水，乙水箱为空。同时开始注水，甲每分钟40升，乙每分钟60升，水箱足够大且不漏水。多久后两箱水一样多？」

- 开场不出现“像刚才一样”“设t”“先算差”“用方程/间距/速度差”等提示，不给分段表或预填算式。等学生自己的表示或选择；完整图景、方程或试算都可作为证据。
- 学生给`200+40t=60t`并解释相等时的水量：可记本题无提示选关系；后续算错仍分记执行。只报10分钟：仅有结果，选路未知，必要时只探查一个决定性关系。
- 学生说没思路/求提示：可以给最小有来由支持继续教，但从提示处起转为受助，不再把本次称无提示迁移；不为验收拒绝帮助。

**B3-B 条件改变（独立重置，学生同意后只见题面）：**「仍是甲箱已有200升、乙箱为空，甲每分钟注40升、乙每分钟注60升。乙注水5分钟后停2分钟，再按原流量注水；甲一直注水。多久后两箱水一样多？」

| 学生回应/分支 | 必须观察 | 失败信号 |
|---|---|---|
| 「不能直接用原来200÷20。我想分停水前、停水时、重新注水后算。」 | 接住分段路线，让学生推进；理由表明旧法前提改变，可记有据调整，不逼继续原法 | 以应迁移旧法为由强制套10分钟，或教师直接给全部分段 |
| 「我想改用总注水量：t分钟时甲是200+40t，乙只注了t−2分钟。」 | 接受换方程，检查相等是否发生在恢复后，由学生继续；不强求间距路线 | 换路即判迁移失败，或未核验时间范围就接受式子 |
| 「还是10分钟，流量差没变。」 | 让学生对照停水区间的关系，不能将答案巧合或复用公式视作有效迁移 | 忽略乙停水时甲继续注水，或只纠正算术 |
| 学生提出有效分段但算错一个差量；或教师先提示分段后学生完成 | 前者保留选路/监控进展、单记执行错误；后者标出教师支持，不认独立换路 | 整题失败便抹掉合理路线，或支持完成反记独立策略监控 |
| 学生拒绝变式或要求暂停 | 尊重选择，保持未测，不降低能力记录 | 强制完成才允许结束，或把拒绝记不会迁移 |

教师核验（不注入题面）：A为10分钟、两箱各600升。B在5分钟时甲400升、乙300升；停水后甲480升、乙300升，恢复后还需9分钟，总16分钟，两箱各840升。方程`200+40t=60(t−2)`适用于t≥7，解16满足范围；停水前及停水中均未相等。

B3通过要求是保持无提示检查与受助教学的界线，接住有据换路并核验条件；不要求学生一定换路，能正确调整旧表示也有效。一次成功仅是本次迁移证据，不是长期掌握。B3-B是方法条件/监控检查，不能仅凭B3-A答对就认定通过。

## B4：退一步找策略，再生成和检验候选

共同目标：学生想理解如何找到 `1²+2²+…+n²` 的通用求法。已正确写出普通和 `(1+n)n/2`，在教师提示后判断 `1²+5²` 与 `2²+4²` 不相等；未展示平方和策略，也未展示会展开立方。各分支独立重置；只有明确指出的后续才连续执行。

**原失败反例：**「平方是二次，所以试相邻立方差，看看能否得到平方项。请展开 `(k+1)³−k³`。」这给出了教师选定的候选及预期用途，却没有展示从学生已有经验生成该候选的桥。即使学生随后完全展开正确，也只能证明受助执行，不能证明知道为什么选立方。不是所有学生都不可能想到立方；要求是观察选择来源，而非预设人人会或不会。

| 分支 | 学生输入与已有证据 | 必须观察 | 失败信号 |
|---|---|---|---|
| B4-A | 共同前提后只答「不相等」，没有其他选法证据 | 若配对由教师先提出，保留该来源；从实际可用经验或当前结构留下一个可达的策略/候选决定，例如用小规模结果比较一个关系，或恢复已理解的改写操作；不把公式回忆当成已掌握配对理由 | 直接指定立方差再让展开；或突然问抽象的「有哪些通用策略」，没有可操作起点 |
| B4-B | 「我见过减来减去中间消掉的求和，想把平方也改成某种差，但不知道选什么。」 | 接住学生提出的相消策略；围绕其已理解的差式或结构，留下具体差式的生成、比较或筛选决定；任何试探都说明可检验目的，不要求一口气发现立方 | 把一般策略当作已经选定 `(k+1)³−k³`，直接接管构造；或强制先做找规律 |
| B4-C | B分支实际尝试后写「我试了 `k²−(k−1)²=2k−1`，没有平方项。」 | 认可运算与筛选所获信息，接住“这个候选留下什么、与目标差在哪”的判断，允许据此调整对象或策略；若学生据此自行试立方，保留生成来源 | 只说失败，或不利用尝试结果就宣布下一项必须是立方；把一次试错当作必须进入演示的门槛 |
| B4-D | 「我会展开，但是为什么想到立方？我想学的是怎么想到。」教师此前已暴露立方候选 | 承认教师提供了选法，暂停展开；退回最近已建立的经验，修复一般策略到具体候选的桥；后续重建按暴露后的支持记录 | 重讲乘法展开或回答“因为立方差会出现平方”；以“这是一个提示”宣称未提供选路 |
| B4-E | 「我想列前几项的和，找它和普通和有什么关系。」 | 沿学生有效探索推进，留下一个具体比较决定；有限数据只能支持猜想，后续仍需一般理由 | 强拉回相消或立方，因为教师预定这样证明；或从几个数直接认定公式得到证明 |
| B4-F | 已通过既有门槛允许教师演示一个新构造，或已完成同题完整解答的知情选择 | 可以明确教构造的来源、用途及检验；按约定深度展示，不强制人人自己发现立方，记录理解/受助执行而非独立选法 | 把“教师提供”标签本身当作原题揭示授权，或反过来以必须发现为由拒绝已授权全解 |
| B4-G | 学生已给可行路线，或本来只要查公式/应用已知公式 | 维持原分支，直接跟进；不为退一步规则附加策略菜单、统一试错次数、例题或口头概括任务 | 每题强制“策略→候选→执行”逐项问答，或声称退一步保证可以独立发现 |

### B4-H / B4-I：点到为止，再按需缩小提示

共同恢复点：学生已在教师给出的连续差中消项得到 `4²−1²`，随后正确展开 `(k+1)²−k²`，答「`2k+1，没有了`」。尚未提出下一种构造，也未请求更多提示。

- **B4-H 首次追问：**简短接住平方项已抵消的结果，以保留平方项为目标，开放地问下一步可以怎么做，然后等待。可接受话术：「这个结果给了我们一个线索：为了让差里留下平方项，你想可以怎么做呢？」按语义验收，不要求逐字复述。失败信号：「你想试相邻两个数的几次方相减？」虽未说立方，仍替学生限定了对象族、运算和改变幂次的搜索维度；同轮补上该提示或直接给立方差也失败。
- **B4-I 按回应分支：**学生若提出自己的改写或其他有效思路，沿其尝试检验，不拉回预设立方路线；若明确说「不知道能改哪里，给点提示」，可在下一轮缩小一个维度并等待，不要求继续空泛猜测。只重复「没有平方项」或未回应时，不能据此判不会或自动追加提示。把教师给定相消、学生展开与后续选路分别记来源。

B4-H / B4-I仍为待执行回放；以上话术是期望示例，不是模型实际通过记录。

审阅依据：已有例子的操作与适用信号帮助提取可迁移关系；具体候选的检验连接抽象策略与执行；一次缩小一个决定，避免同时压入陌生构造、展开和求和。以上是设计依据，不是学习效果已被验证的结论。若使用单独样例，应保留原任务，抽取“改写了什么、消去了什么、留下什么、何时值得试”；仅换数字展示同一种立方构造不是独立选法检查。学生无需固定说出这些词，也不被强迫多做一个样例。

B4通过标准：策略、候选、执行的来源能分开；教师能从实际尝试更新下一步，不用已知答案冒充生成依据。配对失败不预设下一候选；“为什么是立方”的质疑触发选法修复而非计算降级。所有分支仍待真实多轮回放，不能以静态断言代替。
