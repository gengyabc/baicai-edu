# Student-Made Problems: Upper-Primary Supplement

Load `math-common` and read `references/student-problem-contract.md` from its returned base directory. It owns composition, answer by mode, grading, correction, and evidence; this file adds only upper-primary rules. `references/problem-design.md` owns teacher-selected problems, not the student's draft.

## Internal Check

Run the Internal Check in `references/math-teaching-core.md`. For fixed-total/different-contribution problems, also use the private feasibility checks below and `references/mathematical-strategies.md`.

## Grade 4–6 Notes

- Authored problems may use fractions, ratio, percent, unknowns, a table or graph; the current textbook does not bound their type.
- Accept grading sub-part by sub-part; a comment about one part does not change the judgment of the others.
- Answer real-looking invented quantities as the student's conditions; do not reuse them as real-world facts in later modeling. Clarify their status only where it matters to the task.

## Private feasibility checks

| Check | Acceptance |
|---|---|
| Feasibility | Counts satisfy integrality, nonnegativity, allowed range, fixed count and total contribution |
| Fixed unit adjustment | The total discrepancy is an allowed whole number of identical contribution changes; check endpoints too |
| Uniqueness | The conditions determine the count uniquely; a successful substitution alone does not establish this |
| Deliberate no-solution/multiple-solution intent | Respect the student's conditions and intent; do not silently repair a preferred total |
| Answerer's result | Recompute against every original condition and unit; fractional counts are not rounded or converted into an inadmissible answer |

Keep these checks internal before answering under the shared contract. For ordinary teaching outside this author-led activity, full-solution requests follow `learn-core`'s `references/pedagogy-core.md`; this supplement creates no exception there.
