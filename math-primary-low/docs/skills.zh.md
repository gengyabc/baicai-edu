# 技能、调度与规则所有权

[English](skills.md) | [中文](skills.zh.md)

五个内部技能：一条主线、一个规则所有者、三个子技能。它们都不可由用户调用，也不占用 `/` 入口；`/learn` 与 `/learn-feynman` 经共享生命周期到达本带。本页给出技能清单、调度约定，以及本带自己拥有与向 `baicai-edu-math` 借用的规则。

## 技能清单

| 技能 | 职责 |
|---|---|
| `math-low-session` | 教学主线、恢复焦点、三个子技能的唯一调度者、本轮唯一回合段的合并者 |
| `math-low-core` | 共享规则及按条件加载的参考文件 |
| `math-low-diagnose` | 策略诊断、错题分流、有证据的阶段估计 |
| `math-low-practice` | 保留诊断／对比／变式／连接四个层级，另有非分层巩固与回访；一次一题 |
| `math-low-student-problem` | 学生编题、AI 诚实验算回答、学生检查；找错另行明确标注，费曼模式下的困惑同轮纠正 |

## 调度

- 只有 `math-low-session` 调度子技能。子技能只回传证据与下一动作信号，彼此不互相调用。
- 等待学生时保留原步骤。证据足够且无待答问题时，同轮最多两次子技能调度。
- 仅教学主线合并唯一回合段，由生命周期记录与收尾保存。错题文件由生命周期调用一次 `learn-errors` 读取，学科分支消费结果。
- 这是指令层的集中调度约定，不是运行时调用隔离。

## 本带拥有什么、借用什么

- 学生编题、练习证据、画板协议与手写读取只在 [`baicai-edu-math`](../../math-common/README.md) 写一份；本带只在出现对应分支时按名加载。
- 手写契约由本带核心技能的条件行直接加载，与年级无关且没有本地增补：先读契约，再加载 `learn-read-image`。
- 本包在自己的参考文件里本地保留：CGI 数量关系与儿童策略视角、按目标选故事或非故事格式（故事承载数量意义，计算与等式可用非故事形式）、任务边界自动清板、低年级的算式与故事写法。
- `math-common` 是否加载，不改变本带的 `supported_stages` 与会话所有权。共享包不可用时，本带按自己核心技能的安全兜底继续，不声称已应用共享契约。

## 规则与阶段

规则经 `math-low-core` 的条件指针加载，而不是把参考书摘要放进运行指令。阶段按 CGI 分算术、多位数、分数三条线，仅作策略摘要：不改共享数据结构，也不设内容门槛。

画板入口、本地差异与清板授权见[数学画板](board.zh.md)与[结构化数学画板](../skills/math-low-core/references/structured-drawing.md)；本带可以说什么、做什么见[教学边界](teaching-boundaries.zh.md)。
