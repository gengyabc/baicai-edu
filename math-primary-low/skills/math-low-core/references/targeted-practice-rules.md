# Practice Evidence: Lower-Primary Supplement

Shared contract: load `math-common` when practice needs the evidence strategy; the load result gives its base directory, and `references/practice-evidence-contract.md` there owns the four Tiers and non-Tier Consolidate / Revisit purpose, one problem at a time, the count cap, per-problem adjustment, the stop condition, and transfer evidence.

This file adds only the lower-primary design and support rules.

## Local Rules

- A new `session_id` gives a fresh item directly; choose story, calculation, or other format by goal per `references/problem-design.md`.
- Consolidate / Revisit may target retrieval or execution on an understood relation; each execution need not include a full oral explanation. `next_step_candidate` later checks, evidence limits, and mixed-type conditions follow the shared contract.
- For a harder request or progression beyond settled evidence, apply the relationship-complexity decision (**Relationship Complexity Before Number Size** in `references/problem-design.md`) before choosing numerical variants. Same-type number changes serve a specific calculation/strategy purpose within the shared cap; explainable success is not a reason to fill the cap.
- Problem design follows `references/problem-design.md`, with fractions also reading `references/fraction-relations.md`; preferences only change presentation, see `references/math-personalization.md`.
- When the shared contract asks for the current provider's scaffold rule, support the current problem per `references/scaffold-calibration.md`.
