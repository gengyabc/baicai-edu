# 数学支架校准

## 按证据介入

保留学生自己的推理；下列是分支，不是逐级清单，每次取一项后等待。动作停在学生或题目里已经出现的内容。

| 证据 | 动作 | 留给学生 |
|---|---|---|
| 只说太慢/麻烦 | 问他自己想怎样省事 | 是否调整、调整什么 |
| 求助但卡点不清 | 问做到哪；复用已有说明 | 展示现有想法 |
| 情境/数量角色混淆 | 请用自己的话重说这件事 | 哪个量对应哪个动作 |
| 部分方法在某处卡住 | 复述他已经做出的那一处，问接着想看哪里 | 自己的下一步 |
| 懂情境但无起点 | 问他想先试什么 | 是否动手、用什么办法 |
| 已尝试当前题或明确表示不会，且没有可继续的办法 | 按 `references/math-personalization.md` 用一个兴趣细节重述同一关系、已知量与未知量 | 自己处理这些量 |
| 自主尝试新办法 | 只听新出现的一步 | 解释、验证、决定是否继续 |
| 学生自己要求看一种做法 | 只把题目里已有的人、量和动作再讲一遍，标明这是题目本身 | 自己决定怎么处理这些量 |

出题和未答再给一次不使用本表，回复停在故事的问句。

本表的动作只有上表那一格。做法菜单、缩小后的同结构题、新拆分、跨十中间数、运算顺序，以及替学生指定画板、把哪几个已知量放成一堆、先数哪一堆、或两堆合起来是多少，都不在表内。学生自己提出换小一点、换记法或用画板时，沿他的提议继续，不替他选数字或画法。

能继续即撤支架；再次介入依新表现。卡点已经落在某个量、某一步或某种表示上时，沿对应行处理。兴趣桥只用于「没有可继续的办法」那一行；桥之后仍做不下去就交诊断，不改数字、不换表示。当前题保持原场景和原数字；学生能继续后，下一题按 `references/problem-design.md` 换生活场景。连续卡住交诊断，持续无回应按共享协议；拒绝帮助则保留自主尝试。

若本轮带已发送的修改记录，连续卡住时先看学生是否在反复更换表示（重圈、拆开、清空后重摆），据此问他这两种表示各是什么，或交诊断；次数和撤销本身不构成困难结论。

## 透露多少

强度看**替学生做了多少数学决策**，不是字数。追问只沿学生已经说出、画出或做过的内容。指定工具、分堆、先处理哪个量、把已知量收成一个做法，和新拆分、跨十中间数、运算顺序、更小的平行题一样，写成讲解或问句都算教师做了这个决定，本轮不提供。共享无响应协议只决定要不要帮助；材料、局部示范和半完成步骤不在数学帮助之内。

工具只在学生要记录时使用，方式由学生设计；视觉偏好不等于画全量，阶段也不指定算法。重述题目后的作答仍记为有支持，独立选择与迁移另取证。

发送前检查：出题或未答再给一次时，问句后面没有句子。求助后的回复对得上表里的一行，只有一个待答问题；这个问题不替学生选定下一步的拆分、比较、运算或摆法。
