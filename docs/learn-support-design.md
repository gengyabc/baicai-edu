# Learn 通用学习动力与自主学习支持体系设计

状态：设计已确认，技能协议已实施，真实对话与故障注入验收待运行。确认日期：2026-11-09。

本文件是设计访谈确认后的实施基线。[原讨论稿](<why_learn.md>)保留为探索材料；其中的建议、研究概述和示例字段不自动成为实施要求。领域用语以[术语表](<../GLOSSARY.md>)为准。设计访谈阶段只落设计与术语；后续 `/implement` 已授权技能协议实施。实现不自动安装、更改运行中 profile 或访问学生数据。

## 1. 目标与交付范围

在现有 Learn 中增强价值、信心、自主性、学习策略、持续学习五类支持，最终帮助学习者逐步自主选择、执行和调整学习。五类能力全部纳入交付，不预设必须新增五个同名 Skill。

覆盖小学、初中、高中、大学及高职、成人；以现有小学语文、数学、英语为重点深入验收。全年龄支持包括通用任务教学，不代表现有小学学科包已经具备所有阶段和专业的教学能力。

首要成效是学生在适当支持下进入真实任务，并逐步更自主地完成。意愿自述、实际参与、任务表现分别观察；聊天时长、继续学习次数、说“有用”不单独证明有效。休息、暂停、拒绝或合理放弃都可以是合适结果。

## 2. 已确认的结构

### 2.1 按真实职责组织，而非按年龄复制

| 位置 | 职责 | 接口与约束 |
|---|---|---|
| 通用 Learn | 身份、目标、生命周期、支持规则、证据与保存 | 统一路由和写入所有权，保留既有合法入口 |
| 阶段与情境参考 | 表达、支持程度、家长参与、经验、时间成本等默认规则 | 条件命中才加载，当前任务证据优先 |
| 通用支持方法 | 五类支持的方法选择、适用条件、退出与观察 | 提供方法建议，不独立调度教学或写档案 |
| 专门学科或任务技能包 | 内容、诊断、任务设计与成果评价 | 经同一教学接口承接当前任务 |
| 通用任务教学 | 没有适用专门包时仍提供实际教学 | 随基础能力可用，经同一生命周期记录与保存 |

阶段参考先留在通用体系内，避免为每个年龄段创建空壳包。出现独立教学流程、内容评价规则或维护需要时，再拆独立技能包。

`learn` 保持日常学习主入口，不取消已有 `learn-feynman` 等合法入口。每次只有一个当前任务和一个教学主导者；通用支持方法不创建第二个学习主循环。学科会话决定具体怎样教；通用任务教学在缺少适用专门包时承担同一角色。

### 2.2 学习身份与教学实现分开

保留真实学科或任务身份，另行记录采用专门包还是通用任务教学。不把所有缺包任务归进一个“通用学科”并混用历史。

实施时建立统一的教学实现解析入口，覆盖开始学习、初始化、目标分类、推荐、恢复和实际教学；各处采用一致结果。优先使用适用的专门包，没有时选择通用任务教学。当前按 `<subject>-core` / `<subject>-session` 定位专门包的约定仍可复用，但缺包分支必须更新。

身份规则：

- 已知科目沿用稳定身份；未知或跨领域目标先保留中性任务身份，不强猜科目，不要求学生理解内部命名。
- 任务记录保留原目标、材料、采用的教学实现及证据来源；跨领域任务不复制成多份掌握证据。
- 通用记录可供后来的专门包参考；未经过明确映射与验证，不能自动写入其掌握等级、技能确认或诊断标签。
- 安装新包不热替换未完成任务。先继续原路径或按学生意愿保存/中断，再通过同一生命周期交接；原证据保留来源，不重新解释。
- 通用能力随基础安装可用，不能在缺少专门包后又要求安装通用包才能继续。

具体字段名、任务身份编码及证据存储结构在协议实施时定义；本文件不将示意名称当作已存在的 schema。

## 3. 理论与方法进入通用体系

### 3.1 简洁常驻，具体依据按需加载

| 理论支柱 | 采用的教学机制 | 使用限制 |
|---|---|---|
| 自我决定理论 SDT | 有意义的选择、承认感受、解释任务理由、支持胜任与关系感 | 不用来诊断知识掌握，不将外部目标一概视为无效 |
| 情境期望—价值理论 SEVT | 澄清任务价值、成功期望和现实成本，结合具体情境选择支持 | 不强求每项任务都产生兴趣，不把时间或资源困难说成动机不足 |
| 自我效能理论 | 通过真实完成、可见进步和具体反馈支持成功预期 | 信心自述与独立能力分开，简单任务成功不证明整体能力改变 |
| 自我调节学习 SRL | 支持目标、计划、策略、监控、反思和调整 | 不把计划执行率当作人格评价，不强迫短任务建立完整计划 |

核心保留选择支持所需的原则；具体干预模式、研究出处、年龄/情境做法按需披露。理论只提供可解释机制，不直接充当执行步骤。

### 3.2 五类能力的职责契约

| 能力 | 典型入口 | 方法与复用 | 返回教学的条件 |
|---|---|---|---|
| 价值支持 | 学生询问用途，或明确说与自身目标无关 | 让学生生成兴趣、生活、专业或工作联系；真实小任务检验 | 找到可尝试的理由/任务，或学生不愿继续讨论 |
| 信心支持 | 学生明确担忧学不会，需要澄清与支持 | 复用现有难度调整、渐进支架、小步成功、具体进步反馈 | 完成可观察尝试并据实反馈，或改由知识诊断/休息处理 |
| 自主性支持 | 目标被动、需要理解选择或形成计划 | 有边界选择、目标澄清、行动意图；复用推荐与目标确认 | 学生选择或明确委托下一步，或决定暂停 |
| 学习策略支持 | 想学但方法不清，或现有方法未奏效 | 检索、间隔、自我解释、元认知、认知负荷调节；复用费曼与学科方法 | 在实际任务中尝试策略并观察结果 |
| 持续学习支持 | 学生请求处理拖延、中断或恢复 | 澄清条件、降低启动成本、安排可行行动与恢复 | 形成可行下一步或明确无法投入，不以承诺替代效果 |

方法接口至少表达当前任务、需求依据、学生意愿、约束、建议动作、观察目标与退出条件。一次选择一个主要方法，必要时一个辅助方法。方法建议由当前教学主导者落实，内部动作合并到真实教学轮次，不额外制造学科表现。

英语既有方法调度与专门技能继续复用；跨学科策略规则不与英语会话争夺每轮方法调度权。费曼仍是同一生命周期中的交互模式，不被信心或价值支持覆盖。

### 3.3 研究核验门槛

原讨论稿含未核验的概述、统计数字和不完整链接，不能原样升级为教学效果承诺。设计阶段未做外部核验；实施阶段已补[方法来源与核验限制](<../learn/skills/learn-support/references/evidence.md>)，按实际读到的正文、摘要与权威解释区分证据，不宣称所有原始全文均已核验。

实施每种方法前，补充可追溯的原始论文、系统综述或权威理论来源，注明研究对象、采用机制、适用范围与限制。大学课堂结果不能直接宣称适用于低年级儿童；成人学习实践原则与强实证结论应区分。证据不足时采用保守教学建议，不承诺确定效果。

AI 学习方法作为策略参考：根据目标与风险判断哪些需要亲自理解、哪些可以验证使用、哪些可以委托；同时支持自底向上理解与自上而下实践。

## 4. 触发、执行与退出

1. 先遵守现有安全、结束、保存恢复与推荐选择闸门。明确结束优先于任何持续学习支持。
2. 无明确需求或可信线索时，继续当前教学，不加动机问卷或固定开场。
3. 出现线索时，用最少必要的澄清区分目标适切性、基础/方法、学习条件与动力需求；沉默、短答、一次错误、画板修改次数都不能单独证明低动机。
4. 选择一个主要支持目标，结合真实任务实施。支持期间保留当前目标、材料、模式、待答问题与必要恢复状态。
5. 分别观察自述、参与和任务表现。无变化时重新判断任务与条件，不机械叠加干预。
6. 学生拒绝讨论时立即停止追问，按其意愿继续任务、换目标或结束。拒绝本身不是负面学习证据。
7. 当前任务中逐步退让支架；遇到新困难可以增加支持，不按使用次数机械递减。

支持方法不自动授权更换任务、跨科、切换模式、设置提醒或操作画板。流程选择使用既有可点击提问规则；让学生思考的教学追问保持普通文字。

## 5. 全年龄与学习情境适配

教育阶段与学习情境是可选配置，不是能力标签。保留旧 `grade`，兼容已有小学年级段；成人或阶段未知时不强填小学年级。旧档案无需批量迁移即可使用，新字段缺失按未知处理。

| 阶段/情境 | 默认关注 | 校正原则 |
|---|---|---|
| 小学低段 | 具体体验、短任务、成功体验与必要陪伴 | 不推断只能游戏化，也不由家长替代学生作答 |
| 小学高段 | 兴趣、小目标、自我检查与逐步自主 | 根据当前能力增减支架 |
| 初中、高中 | 目标认同、策略、同伴/考试情境与成本 | 不把压力、基础缺口归为态度问题 |
| 大学及高职 | 专业关联、真实项目、自主规划与 AI 协作 | 无专门课程包也可依材料教学，专业结论按依据验证 |
| 成人 | 已有经验、真实用途、可支配资源与训练迁移 | 不假定成人天然自主，也不以职业年龄代替能力证据 |

职业起步、提升、转型、资深发展与兴趣/退休学习作为可组合情境，不按年龄强制归类。成人工作应用与现有读写迁移等学科活动语义不同，不能直接复用现有 `activity: transfer` 冒充训练迁移。

家长和教师提供环境与支持，不自动拥有查看全部私人讨论的权限。成人安全支持适配可信任的人及当地专业资源；未成年人保留可信任成年人支持。危机处理优先，危机细节不进入学习日志或档案。

## 6. 通用任务教学

围绕学生材料或真实目标：明确当前目标及评价要求 → 拆成可完成的小任务 → 按需解释或示范 → 学生尝试 → 反馈、检查与下一步。无需先开展动机谈话。

- 有教材、题目、文档或作品时，先读取已提交材料；不声称看过未读取或未提交的内容。
- 目标或必要材料不足时只澄清当前步骤所需信息，不强制完整背景问卷。
- 无专门诊断词表时使用中性观察，未知水平保留未知，不伪造领域标签或小学等级。
- 事实不确定时查证或说明不确定；缺包本身不拒教，但高风险判断仍遵守安全限制，并可转为解释原理、检查依据与寻找专业帮助。
- 通用路径不能绕过确认答案、学生独立尝试和证据规则，也不能用 AI 产出替代学生学习。

## 7. 证据与数据

### 7.1 能力归属

分别记录独立能力、支持下表现、AI 协作能力及观察条件；观看 AI 结果只说明接触，不证明掌握。三类不是单一高低等级，按当前目标验证。

独立计算要求没有关键步骤提示；AI 数据分析协作可评价学生发现错误、验证和修改的能力，无需一律强制手写所有代码。自主选择求助不等于缺少自主性。

保留现有掌握确认门槛；支持成效不能自动更新掌握、诊断或里程碑。学生愿意继续只是参与证据，跨任务复现才可能提供更强能力证据。

### 7.2 临时状态与长期事实

会话日志可扩展必要的支持状态：需求假设、依据及来源、当前方法、观察目标、实际结果、恢复位置。明确区分学生自述、观察事实与教学推断；不存未发送材料。具体结构随 schema 一起确定。

长期默认只保存少量、可追溯且有后续教学价值的事实：

- 当前情绪、困境和支持假设默认停留在临时状态；敏感职业、家庭和情绪细节不自动长期保存。
- 多次观察到某支持在具体情境有效时，可保存来源、日期、适用情境及变化，不生成固定心理标签；重复次数不机械等同于稳定模式。
- 学生明确设定的长期目标与支持偏好可跨学科使用；系统从一次表现推断的低信心或拖延判断不跨科传播。
- 后续使用旧观察时检查时效、情境与学生更正；无法判断是否仍适用时作为历史事实，不当作当前状态。
- 原有科目范围的 `motivation_signals` 不自动迁移为共享心理画像；旧无来源条目只能保守参考。

共享目标/偏好由既有建档、档案修改协议扩展后的指定写入者处理；支持方法不直接写共享档案。涉及学生更正、删除时沿用现有安全清理流程。

### 7.3 纯支持讨论

没有学科作答时仍可保存最小会话恢复状态，但不生成虚假学科 segment。区分“恢复状态已写入”与“长期计划已保存”。

学生要求保存明确的计划时，在同一生命周期内形成非表现支持摘要；它与学科表现分开，不参与掌握、水平、诊断或技能确认。结束时清理临时支持，避免下次无意恢复旧讨论。支持转入教学不额外制造一次学科尝试。

当前空 segments 的 finalize 是 no-op，尚不能完成上述长期计划保存。实施必须同步扩展输入、准备计划、写入集合、幂等标记及清理语义，先明确计划记录的逻辑隔离与物理存放位置，再启用该分支；沿用唯一保存入口，不另造旁路写入器，不宣称跨文件事务。

## 8. 推荐、兼容与失败处理

- 学科内候选内容、难度与排序仍归学科推荐规则；通用层提供已澄清的目标、价值、信心支持需求与成本信息，不自行覆盖学科排序。
- 通用教学可以帮助探索跨领域目标；这是目标探索，不是把不同科目的表现混排。学生确认前保持原任务，确认后由生命周期完成保存和切换。
- 选择、跳过、拒绝均不生成学科表现；中文推荐理由、候选恢复及授权规则保持兼容。
- 旧包缺少新支持字段仍可教学；可选方法加载失败时回到既有教学或通用任务教学，保留目标和材料。
- `finalize_plan` 未完成时先恢复保存，不能以缺包回退或支持介入绕过它；提交失败与日志清理失败分别报告。
- 数学画板遵守现有任务切换授权；支持讨论、推荐卡或加载方法本身不授权清空、不读取未提交画板、不修改量级。
- 不自动创建提醒或计划任务；学生明确要求时才进入相应授权流程。

## 9. 当前差距与实施顺序

以下是待实施清单，不是对现有能力的描述。

| 阶段 | 工作与主要落点 | 完成条件 |
|---|---|---|
| 1. 协议基础 | 扩展 `learn-start`、`learn-data` 的身份/阶段、教学实现解析、缺包处理、支持状态、支持摘要与保存接口 | 旧档案/包仍可用；缺包可进入通用教学；纯支持能恢复且不伪造表现；计划保存和故障重放有明确协议 |
| 2. 通用教学与五类支持 | 为通用路径提供完整教学契约；在 `learn-core` 加按需触发与方法接口；核验理论来源并落实五类方法 | 每类具备触发、可执行动作、观察与退出；单一主导者；理论适用限制可追溯 |
| 3. 周边接入 | `learn-recommend`、`learn-profile`、费曼/学科会话及阶段情境参考 | 推荐不越权；展示中性事实；跨科目标/偏好由指定写入者维护；无双重调度 |
| 4. 场景验收与精简 | 小学重点深入，全阶段覆盖；更新调用图、契约测试与安装说明（如受影响） | 下表全部验收；重复规则归并到唯一所有者；普通轮次不加载全部方法 |

实施前基线限制：入口必填 1–6 年级；学科契约缺包即停止；支持状态未定义；`motivation_signals` 只在科目记忆中；空表现保存不写文件。实现后的权威协议见[学习入口](<../learn/skills/learn-start/SKILL.md>)、[学科契约](<../learn/skills/learn-data/references/subject-contract.md>)、[会话结构](<../learn/skills/learn-data/references/session-schema.md>)和[保存协议](<../learn/skills/learn-data/references/finalize-session.md>)。

设计不批量改写旧档案、不访问学生私有材料、不自动安装或更改插件。新增字段、内部技能名、存储布局和技能包依赖在实施时随契约测试一起明确，不能由教学轮次临时发明。

## 10. 验收矩阵

| 场景 | 必须观察到的行为 |
|---|---|
| 小学已有目标、学习顺利 | 直接推进任务，无强制动机问卷或价值讨论 |
| 小学生说“我笨，学不会” | 澄清与当前任务支架；真实尝试后反馈，不贴标签、不虚报掌握 |
| 只短答、沉默或答错一次 | 保留未知；最小探查，不生成低动机/低能力长期结论 |
| 学生不知道所学用途 | 自己生成或尝试联系，拒绝讨论后可继续正常教学 |
| 初中生只因老师要求学习 | 承认外部要求，提供有意义选择，不强求内在兴趣 |
| 高中生努力但无进步 | 区分基础、策略和成本，真实任务试策略，不单纯劝努力 |
| 高职/大学生缺少专业认同 | 从材料或项目找到可尝试任务，专业结论有依据、可验证 |
| 成人转型且无专门包 | 通用任务教学继续；尊重经验与时间成本，不要求小学年级 |
| 资深或退休学习者 | 按实际目标和能力教学，不机械功利化或幼儿化 |
| 学生认为有 AI 不必学基础 | 按目标澄清理解与委托要求，独立能力和协作验证分开评价 |
| 学生“没时间”或决定休息 | 调整任务/条件或正常结束，不把现实限制当意志缺陷 |
| 纯支持后保存/中断/结束 | 恢复最小上下文；显式保存中性计划；无假学科表现；结束清临时状态 |
| 新专门包安装/切换 | 原任务不热替换；旧通用记录不自动成为专包掌握等级 |
| 跨领域推荐 | 探索与选择分开；跳过不授权；旧任务保存成功后才切换 |
| 保存中途失败或清理失败 | 重放同一计划不重复计数；仅清理失败不误报为学习记录未保存 |
| 学生更正目标、偏好或旧观察 | 后续使用更新事实，不继续引用旧心理判断 |
| 数学画板、费曼、语文迁移、英语复习 | 既有任务授权、模式、证据与单轮记录规则不受支持方法破坏 |
| 未成年人或成人出现危机线索 | 安全优先，按身份支持求助，危机细节不写学习记录 |

验证分层：

1. 静态检查：运行 [技能检查脚本](<../scripts/check-skills.mjs>) 与[协议测试](<../scripts/skill-contracts.test.mjs>)；新增技能和契约时同步更新准确的集合与守卫。
2. 协议情景回归：覆盖旧日志、缺包、纯支持、推荐、模式、保存失败重放和证据隔离，明确哪些只是文本守卫、哪些实际执行了读写模拟。
3. 对话验收：按矩阵观察实际输出、学生选择与记录，不用静态通过代替教学验证。使用合成材料，真实学生材料另行取得授权。
4. 成效观察：分别看任务参与、策略使用、独立完成/解释与 AI 验证，不承诺纵向研究结果；正式研究及额外数据收集另设授权与保留规则。
