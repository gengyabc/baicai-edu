# 数学表征支架研究：教师供图与学生生成图示

核查日期：2026-11-14。用途：为数学技能及 math-board 的后续设计提供依据；本笔记不修改技能或实现。不是系统综述，不声称穷尽研究。

## 1. 结论与证据边界

**不采用“教师先画普遍最优”，也不采用“学生必须先画”。** 较稳妥的是：根据本次目标、学生对相关数学关系及表征的先验知识、可观察的使用困难，选择教师提供、部分完成或学生生成；学生要解释并使用表征，而不只是照抄；支持可逐步减少，也可恢复。[S1–S6]

应拆开三个问题：

1. **谁产生表征**：教师提供、师生共建、学生生成。
2. **图暴露了什么**：题目已知条件、表示约定、解题结构、关键推断或完整解答。即使未写答案，供图也可能泄露选法。
3. **要培养/测查什么**：理解数量关系、学习读图、学习构图、选择方法、计算、迁移。会读给定图，不等于能独立选图；会按提示摆出，不等于独立建模。

现有证据对“有目的地选择并教授表征”的支持，强于对“谁必须先画”的支持；**没有核查到直接证明本产品只读教师面板、某种画板工具或固定渐隐轮数更优的研究**。以下决策表是保守设计推论，不是经过验证的个体化算法。

## 2. 核查到的主要证据

### S1. IES / WWC，2021：小学数学困难干预指南

一手指南：[Assisting Students Struggling with Mathematics: Intervention in the Elementary Grades](https://ies.ed.gov/ncee/WWC/Docs/PracticeGuide/WWC2021006-Math-PG.pdf)，Recommendation 3，印刷页 21–28；证据说明见 Appendix C。

- 原建议是使用“经过良好选择的一组具体与半具体表征”，并明确连接数学符号。该建议标为 **strong evidence**：28 项研究，其中 19 项无保留、9 项有保留地符合 WWC 群组研究标准。
- 指南既有教师示范，也要求学生有充分且有意义的使用机会，用表征解释自己的思路；支持可以通过示范并讲述，也可以通过学生讨论、呈现自己的模型提供。
- 印刷页 27 的障碍建议很明确：**只有学生能准确进行抽象操作时才淡出具体/半具体表征**；若概念不理解，不宜淡出；之后仍可回访表征。不能将“到某年级”或“用过一次”当撤除条件。
- 指南承认屏幕上的虚拟表征，但这不等于证明任意数字画板与实体操作等效。

**可靠程度：对目标人群下的表征教学建议高；对教师先画/学生先画的直接比较不足。** 指南的整体证据评级不自动赋予其中每条建议、示例、UI 或顺序相同的因果证据强度。研究主要是小学数学困难干预，不能不加说明推广到所有学生、所有几何任务。

### S2. IES / WWC，2007：图文结合、例题与练习

一手指南：[Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/WWC/Docs/PracticeGuide/20072004.pdf)。Recommendation 2（印刷页 9–12）、3（13–15）、4（15–19），均为 **moderate evidence**。

- 将完整例题学习与解题练习交替；随熟练度增加，减少例题、增加独立解题。
- 将表达关键关系/过程的图与语言说明结合，说明尽量接近对应图形；明确连接具体与抽象表征。
- 这支持“给相关且可解释的图”，不支持堆叠装饰图、长篇说明，也不证明动画必优于静态图。指南指出合适的静态图序列可与配音动画同样有效。

**可靠程度：中等，且跨学科、较多实验室研究。** 不能把图文结合效应解释为教师预画图优于学生构图，更不能从一般多媒体证据得出本产品已降低认知负荷。

### S3. Cromley、Du、Parpucu Dane，2020：学生生成图示的元分析

原研究：[Drawing-to-Learn: Does Meta-Analysis Show Differences Between Technology-Based Drawing and Paper-and-Pencil Drawing?](https://doi.org/10.1007/s10956-019-09807-6)。本次可完整核对的是[作者所属大学研究记录中的原论文摘要](https://experts.illinois.edu/en/publications/drawing-to-learn-does-meta-analysis-show-differences-between-tech/)，未取得可审阅的方法全文。

- 涵盖 53 项研究、166 个效应、8,111 名参与者，研究的是**有指导的**学生生成静态图示（含完整或部分图像）。
- 摘要报告综合效应 g = 0.69；事实、推论、迁移分别为 0.85、0.44、0.22。
- **0.69 混合了“画图 vs 不画”和“不同画图条件之间”的比较**，不能称为“学生画比教师给图好 0.69”，也不能视为小学数学的专属效应。

**可靠程度：存在积极汇总证据，但本次核查深度限于作者机构摘要，适用性中等/间接。** 不据标题宣称数字绘图优于纸笔；未核对全文的调节变量不做结论。

### S4. Tolsberg、Põldre、Kikas，2022：小学教师指导学生生成图示

原研究全文：[Learner-generated drawing as a learning strategy](https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2022.962067/full)。爱沙尼亚 8 所学校，二、四年级；干预组 190 人、对照组 203 人。18 节课教学、练习与反思三种学习策略，绘图是其中一种。

- 干预后学生生成图示，尤其结构图示的情况增加：说明年幼学生也能经教学学习构图，不应因低年级直接剥夺构图机会。
- **增加画图不等于已经证明解题收益**。这是多成分干预，不是教师给图与学生画图的纯比较；绘图类型与答题正确性的关系不能直接当成因果。
- 前测用平板、后测用纸笔；作者明确承认媒介变化可能影响绘图频率。不能据此声称数字画板带来学习收益，或“二年级必须画、四年级不必画”。

**可靠程度：小学情境直接，支持“可教会构图”；对单一构图策略的因果效果及顺序优劣有限。**

### S5. Ayabe、Manalo、de Vries，2022：教会何时、如何选图

原研究全文：[Problem-appropriate diagram instruction for improving mathematical word problem solving](https://pmc.ncbi.nlm.nih.gov/articles/PMC9574201/)。67 名日本初中生，约 14 岁；对线图、表格、坐标图分阶段教学，采用改编多基线设计，不是平行组随机试验。

- 教学同时涉及图的用途（是什么）、如何构造（怎么做）、哪些问题适合（何时用），并由学生个人练习构图。之后合适图示使用与解题表现改善。
- **认知负荷结果并非一致、即时下降**：线图教学后相应问题的自评负荷先上升，后来下降；表格结果较一致；坐标图也存在练习效应等其他解释。不能只摘摘要的“负荷下降”。
- 数据支持“教会选图和用图”比一句“画个图”更有依据；不直接支持教师永远先画，不直接推广到小学或某个画板界面。

**可靠程度：数学情境的原始干预研究，中等且有设计/外推限制；负荷是自评，不是实时测得的工作记忆容量。**

### S6. Kalyuga、Ayres、Chandler、Sweller，2003：先验知识与专家反转

原论文：[The Expertise Reversal Effect](https://doi.org/10.1207/S15326985EP3801_4)；[作者机构库记录](https://ro.uow.edu.au/articles/journal_contribution/The_expertise_reversal_effect/27724950)。本次阅读仓库已有的机构库论文全文。

- 这是一篇实证研究综述/理论整合，**不是元分析，也不是一次小学绘图试验**。它汇总说明：对新手有帮助的支持，在相关知识较充分时可能冗余，效益消失甚至反转。
- 解释是：读图、跨材料整合、构图均可能占用认知资源；既有知识能改变负担与收益。因此，应依据**当前任务相关知识**调整支持，而非按年龄、年级或笼统“能力”贴标签。

**可靠程度：作为一般调节机制依据较强；作为某学生/某图应该何时撤除的直接证据不足。** 不能把一次错误、沉默、拖动慢直接诊断为认知超载。

### S7. Sinha、Kapur，2021：先尝试再教学不是一概无效

原元分析：[When Problem Solving Followed by Instruction Works: Evidence for Productive Failure](https://doi.org/10.3102/00346543211019105)。出版站本次遇到访问验证；阅读仓库已有的同 DOI 全文核对。

- 53 项研究、166 个比较，整体 PS-I（先解题后教学）相对 I-PS（先教学后解题）g = 0.36，95% CI [0.20, 0.51]；遵循 productive failure 设计原则时效果更强。
- 作者同时报告：二至五年级子组呈相反趋势、偏向 I-PS；这并不建立年级断点，子组比较也不能直接当作个体处方。
- **教学顺序与图示作者是不同变量。** PS-I 有后续整合教学，不是让学生无期限猜；I-PS 也不意味着必须教师画好每张图。因此该文主要用于反对普遍化断言，不作为画板顺序直接证据。

**可靠程度：有关教学顺序的高价值元分析；对本题为间接证据，且存在人群/设计调节。**

## 3. 可执行的条件决策（设计建议，不是实验结论）

| 本次证据/目标 | 保守起手 | 学生必须保留的数学工作 | 何时调整 |
|---|---|---|---|
| 明确新授；不熟悉相关关系或表示约定 | 可供一张简短、准确、目标相关的示例图，连到口头说明/式子；必要时先用另一道例题 | 解释单位、指出对应关系、做一个非照抄的选择/变化 | 能解释并使用后，改为部分完成或新题自行选择；不强制“先错一次” |
| 数学关系懂，但画图/工具操作阻塞 | 可给空框架、已知条件图或允许口述/纸笔 | 决定未给的关系、分组或计算；不把操作障碍当概念不懂 | 工具熟悉后让学生自行表达；不要强制重画已理解的图 |
| 目标就是构图/选表征/建模，且已有必要基础 | 学生先试；允许自选画图、表、式子 | 选择哪些量、关系、图种并解释用途 | 卡在表示约定时只补一处；需要示范可换一道例题，不替学生完成被测能力 |
| 当前任务为独立测查或已约定自主推导 | 不预先提供泄露目标关系/方法的图 | 保留选法和关键推断 | 若给支持，明确本次变成受助；另用新题无提示检查 |
| 已熟悉关系且能不用图解决 | 不要求为了使用画板而重画；可让学生解释或做变式 | 保持真实推理，而非仪式化绘图 | 当新题更复杂、学生愿意或关系理解不稳时恢复表征 |
| 先验知识未知、且会改变起手 | 一次轻量探查，例如解释图中“一份”代表什么；或问愿先试还是看例子 | 学生真实表达 | 不先安排一整套诊断，不以年级替代证据 |

**渐隐必须分两条线**：

- 撤除教师代做的程度：完整示例 → 部分框架/一处提示 → 自行选择与构图。这是合理支架设计，不是规定所有人必经的直线阶梯。[S1、S2、S6]
- 撤除图示这种表征：不能因为能自行画图就要求不用图；只有当相应抽象理解和操作确实稳定时才考虑减少，之后仍允许回访。[S1]

不设“连续答对两次就撤图”等研究未验证阈值。判断同时看学生是否解释数量/单位与关系、能否在新题中自主选择和使用，及需要的支持。一次成功只支持局部调整，不等于长期掌握。

## 4. 对 math-board 的设计边界

以下是证据启发的产品建议，不是论文已经验证的 UI 优效：

1. **区分教师参考与学生作业。** 教师图可以独立、明确标为参考，不能混入学生作品或算成学生自主建模。只读与分区有助于来源归因，但“双面板”本身可能增加视线切换；说明贴近对应部位，避免同时堆太多内容。[S1、S2]
2. **先决定图要承担的角色，再决定谁画。** 给定条件图、构图示例、解题图不是一回事。一个条形图的切分、辅助线或分组，即使没有数值答案，也可能已经给出被测关系。不能仅以“没写答案”认定没有泄题。
3. **不要要求学生照抄教师图作为学习证据。** 请其解释、改变一处条件、补一处真实未知关系，或在新题自己选择；分别记录给定、提示、独立的来源。图画得漂亮、对象多、拖动次数多不是理解指标。[S1、S4、S5]
4. **提供替代通道。** 画板是可选思考工具，不是数学表现的唯一入口。不会操作时可口述、算式或纸笔；“没有画图”不等于没有思考。[S4、S6]
5. **守住提交边界。** 仅阅读学生已经发送的快照和说明，不读取未提交草稿、不代提交、不覆盖学生作品。学生自述不作工具授权；教师供图不构成修改学生设置、清空或发送的授权。
6. **数量与几何分开。** 数量板的一图代表几要有明确单位约定；几何快照只作为学生表达材料，不据坐标测长度/角度、不判平行/垂直/相等/共线，不从画得像不像推断数学正确性。研究支持不了超出当前系统能力的几何判定。

## 5. 后续验证：只作待检验假设

若未来评估产品，不只比较即时正确率或画图数量。可在同一目标与相近起点下比较“给图+解释”“部分框架”“指导生成”，并分开考察：读图、独立构图/选法、新题迁移、延迟保持、时间/操作负担与学生体验。评估题要撤去会泄露被测方法的参考图；不将受助成绩计为独立。小规模观察只能发现可用性问题，不能宣称学习效果因果。

当前证据不足以宣布某种顺序、固定年级策略或单一画板 UI 普遍最优；最可维护的规则是：**以目标和相关知识选支持；教会图的意义与用法；让学生承担真实判断；依据表现渐隐并允许恢复。**
