# 高年级数学：策略教学与递归先修学习

- 状态：设计已确认；后续 `/implement` 已授权源规则与保存协议实施，当前正在验收。
- 确认日期：2026-11-12。
- 适用：四至六年级的广泛学习者，非竞赛培养优先；年级不是内容上限。
- 验收入口：实施或审阅方法教学、递归先修、计划保存与恢复时，读取[验收场景](<acceptance.md>)。
- 术语：[领域词汇](<../../GLOSSARY.md#数学策略与先修学习>)。

## 1. 目标与范围

目标是让学生在陌生问题中更独立地选择、监控、解释和迁移数学方法。题型用于组织案例，不以题型数量或经提示后的答对数量证明改进。

首批贯通三类方法：假设调整、有序枚举、余数与周期。每类覆盖：题目结构 → 数学思维方法 → 有证据的局部思维障碍 → 教师引导动作 → 理由检验与迁移。

最初文档轮只交付设计、术语与待执行场景，不改运行时 Skill、共享数据协议、安装配置或学生记录。后续用户明确调用 `/implement` 授权实施运行时源规则与共享保存协议，并确认三条测试边界：技能入口契约、任务链保存恢复契约、隔离虚构学生旧/新多轮回放。此次仍不修改真实学生数据、不安装或发布。此前“不新增状态字段”的限制已针对可靠递归恢复重新打开，但仅允许后续实施增加必要的会话级恢复信息，不增加长期能力标签。

后续实施不预先承诺四份 reference，也不为十二类题型或理论名称新增独立 Skill。先验证三类方法的闭环，再决定扩展。不引入图数据库、独立调度器或自适应评分系统。

## 3. 组织原则

- 复用 Pólya 主线，借 Schoenfeld 的资源、启发式、控制视角检查行为；理论名称没有新增模块的否决权。CGI 继续用于接住学生实际策略，变式用于检验结构和适用边界。
- 方法索引与知识图谱分工：前者回答“可以怎样思考”，后者回答“需要哪些概念与工具”。方法、知识点、题型多对多关联，允许学生采用其他有效路线。
- 障碍须依据作答、解释或操作证据。unknown 不等于缺失；漏列可能来自分类不完整，也可能是抄漏，先用最小追问区分。
- 学生监控围绕关键决策或实际停滞：这次尝试获得了什么、何处失效、为何继续或调整。无需每一步汇报，也不因一次困难就换策略。
- 一个主要思考任务、一个当前待答问题；保留父层问题用于恢复，不同时向学生抛出整条依赖链的问题。
- 具体思考问题用普通文字；目标调整、继续或结束等过程选择沿用可点击的流程选择协议。推荐未被接受不构成目标切换授权。

### 方法索引的最小内容

记录适用结构线索、必要概念与前置工具、学生已有证据、常见局部障碍、最小引导入口、方法理由、失效边界和迁移案例。学生不必说出方法名称。索引不是看到“鸡兔”“周期”等关键词就指定策略的路由表。

| 首批方法 | 结构与前置工具线索 | 典型障碍与引导 | 理由与边界 |
|---|---|---|---|
| 假设调整 | 固定总数、不同单件贡献；能比较差量、理解替换 | 已会全设一种时沿其路线；不会开始时研究简化情形，不强制方程 | 差量为何对应替换数量；贡献差不固定时原来的线性调整可能失效 |
| 有序枚举 | 有限选择与约束；能按属性组织对象 | 定位分类依据、漏支或重复，避免反复讲乘法；先让学生说明一个对象归哪类 | 分类是否覆盖且互斥，顺序是否区分；分步乘法需检查各步选择数和计数单位 |
| 余数与周期 | 重复状态与循环长度；理解整组、余数和位置对应 | 区分不会求余数、没识别周期、只凭样本猜测；缺工具进入子任务 | 重复的结构理由、完整周期、起点与余数 0 的对应；有限前缀不能确定唯一后续 |

## 4. 递归先修教学流程

### 4.1 识别与进入

1. 从当前解题证据确定最邻近的路线关键缺口；仅不熟悉术语、口头说没思路或一次错误，不足以认定缺工具。已有工具但不知为何用，先修复策略选择桥梁。
2. 确认工具缺失后，记录父任务的原题、已建立关系、支持来源、学习目标与待答位置，再进入最小工具学习子任务。不是在父题里直接展示工具就算修补完成。
3. 当前 session 统一调用适用技能或按已加载技能的教学规则推进；leaf 返回证据和建议，不任意互调。没有专门工具 Skill 时，使用现有适用教学能力，不逐知识点新建技能或为了先修缺口换 band/provider。技能加载是指令加载，不虚构函数调用栈。
4. 子任务若仍缺先修工具，重复上述判断。只展开与当前路线实际相关的依赖，不做完整课程摸底。

完成条件：当前活动子目标、父层返回位置、已确认缺口和待探测依赖均可辨认，只有一个当前待答问题。

### 4.2 正常教学与返回

- 学生具备子任务所需工具时停止拆分，适用技能正常教学；可使用探究、示例、解释和练习。这不等于禁止一切讲解，也不恢复“父题中缺工具就直接教完”的默认捷径。
- 示范、构造和关键提示明确归因；支持下完成不写为独立发现。
- 用新的适当任务观察学生独立使用工具。口头说懂了、复述示例或完成教师留下的算术空格，不足以返回。
- 达到当前子任务约定的使用条件后，只返回上一层；重新看该层剩余障碍，再决定是否能继续返回。会用工具不等于会选择它。
- 工具子任务独立成功只是局部就绪证据，不自动触发长期掌握、阶段提升或父题成功。

完成条件：返回有实际证据；父层原题和未解决的策略选择得到恢复，没有越层宣称完成。

### 4.3 缺口过大、递归过深或持续停滞

“过大/过深”依据实际依赖与教学负担：补工具时出现多项未掌握先修，或子任务需要较完整学习，原题已难形成可理解进展。不凭年级、一次错误或固定层数自动判定。重复同一缺口且无新证据时，检查先修判断、表示方式和路线，不能继续空转。

先记录当前原目标、活动子目标与返回链，将难以继续推进的目标搁置，具体说明缺口并建议把近期目标改为学习子问题。这里的搁置不自动取消原目标，也不自动开始未经选择的新任务。

- 学生接受：明确是“先学子问题，之后返回”还是“放弃原题，改学新目标”。前者保留返回链；后者结束原任务，不自动回到原题。
- 学生拒绝调整目标：告知可能需要较长先修学习、暂不能保证解决原题的风险；保留原目标，继续最小递归补缺、正常子任务教学和停滞检查。不能跳过先修直接揭示父题答案，也不能因拒绝而无限下钻。
- 学生同时拒绝必要子问题：重新协商可行路径，允许暂停或结束，不假定工具已学会。
- 再次无进展：先检查和协商，不机械重复同一建议或调用。

完成条件：目标状态与学生选择一致；风险已说明，继续路径有具体下一步，或明确停在等待选择/暂停/结束处。

## 5. 学习计划与恢复

识别到递归学习路径，尤其需要搁置目标或跨次学习时，向学生提供并保存可读学习计划，再按计划推进。最小内容：

- 原目标及其保留、搁置或放弃状态；当前活动子目标。
- 已确认缺口与证据，以及尚待探测的依赖，二者分列。
- 暂定学习顺序、每一步的工具使用条件、返回父任务的条件。
- 已完成的局部学习、支持条件、下一步和必要材料引用。

计划是动态依赖路径，不是必修清单。新证据表明已会的依赖可跳过；新缺口出现时更新路径并解释。计划中安排了某工具不证明它已掌握。保存内容应为必要的中性学习信息，不保存模型私下路线推演。

### 保存与恢复要求（待协议实施）

| 责任 | 必须满足的契约 |
|---|---|
| 教学 session | 决定当前子任务、适用技能、证据与计划更新；唯一合并本轮表现，父题不因子题正确而完成 |
| lifecycle / learn-data | 执行状态与计划写入，保证中断恢复、重试和 finalize 后续接；子技能不直接改长期档案 |
| 会话恢复信息 | 每层保留目标、原题/材料引用、已有回答、待答位置、必要支持与返回条件，以及当前活动层；只有活动层接受新回答 |
| 跨次计划 | 保存可读计划及可靠恢复所需的关联；不能仅靠会被 finalize 清理的 context 或一行 next_step 恢复多层任务 |
| 证据归属 | 子目标实际表现与父题选择能力分开；维持每轮一个合并 segment，纯计划/选择/讲解无表现时不造 segment；不增加长期障碍标签 |
| 保存反馈 | 区分“计划已提供”“会话位置已记录”“长期保存成功”；失败如实说明，保留可重试状态，不声称已保存 |

当前长期计划的 support_events 只接受学生明确保存请求；本设计新增的“提供并保存递归计划”不能伪造 student_requested_save。未来需在共享写入协议中明确新增授权条件与生命周期，再实现自动计划保存。当前工程用户对功能的授权，不是假想学生的一次保存请求。

本设计确认所需行为，不冻结最终 JSON 字段名、存储文件或 scope 映射。后续必须设计：父/子局部标识、证据归属、版本兼容、幂等写入及 finalize 清理后的恢复来源；这些是实施子决策，不能用本规格冒充已存在的协议。新旧字段兼容时，旧日志按现有位置继续，不补造不存在的父任务。

## 6. 迁移与验收

近迁移检验换数字/故事后能否识别同一结构；边界辨别检验关键条件变化后原方法是否仍适用。按任务需要选择，不强制每道题结束都开始新任务。未独立检验即保留迁移未知，复述教师总结不算迁移。

验收以[场景与回放协议](<acceptance.md>)为准。三类方法各含无思路、已有有效部分思路、结果正确但不能解释三个起点，旧/新规则做多轮对照；另覆盖递归、计划和恢复异常。检查是否接住学生路线、支架理由、关键提示来源、学生监控与方法边界，而非只看最终正确。

证据分层：静态接线与格式检查；模型合成多轮回放；真实学生教学观察。后一层不能由前一层替代，合成学生也不证明真实学习效果。
