## NODE C0（学生：黑白一样多应该都行。）
你说“黑白一样多就都行”，可每块骨牌只盖一黑一白，这只说明黑白数必须相等。相等就够了吗？挑个小小的区域试试看。

## NODE C1（学生：每块盖一黑一白，所以必须一样多。）
对，每块盖一黑一白，所以黑白数不等就一定铺不成。但“必须”不等于“足够”：黑白相等的区域，每一格都一定有邻格可配吗？

## NODE C2（学生：这个删格后的区域不行，但我说不清怎样算反例。）
反例要两头都成立：黑白数相等，这块区域却真铺不成。先查第一头——这个区域的黑白格数相等吗？

## NODE CB1（学生：两个三角形分开的，每个点都是偶度，为什么不能一笔画？）
一笔画不能抬笔，所以这一笔得从第一个三角形走到第二个三角形。两个三角形分开，笔怎么过去？

## NODE CB2（教师反例后学生复述：因为(1,1)没邻居。）
对，这就是结论失败的那一头。另一头呢：这个区域黑白格数仍相等，那“相等”是必要条件还是充分条件？
