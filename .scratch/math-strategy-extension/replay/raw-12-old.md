## NODE C0（学生：黑白一样多应该都行。）
「一样多就行」等于说黑白相等是充分条件。先别忙着证明它，挑一块黑白各占一半、形状却七零八落的区域试试，看它能不能铺满。

## NODE C1（学生：每块盖一黑一白，所以必须一样多。）
你这条理由只说明：能铺成，则黑白必然一样多。题目要的却是反过来那一边。你想拿什么样的区域去检验“黑白一样多就能铺成”？

## NODE C2（学生：这个删格后的区域不行，但说不清怎样算反例。）
反例要两头都站住：黑白一样多（题目条件），却铺不成（结论被打破）。你那个区域先数一数，黑白各几格？

## NODE CB1（学生：两个三角形分开的，每个点都是偶度，为什么不能一笔画？）
偶度保证从某点出发能回到它，并且走遍这一块；可一笔画还要求整幅图连成一条路，笔不抬起来。两个三角形之间缺的，是哪一条？

## NODE CB2（教师反例后学生复述：因为(1,1)没邻居。）
对，那块格子没有相邻格，任何一块砖都盖不住它。可它要当反例，还得满足什么条件？
