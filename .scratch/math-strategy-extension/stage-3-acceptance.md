# 阶段 3 验收：博弈、网络与跨方法迁移

## 1. 对照协议

以本轮最新源码为旧侧，阶段3实施版为新侧。博弈、路径网络、反向编题、边界变式、反例五类，各三起点做旧/新多轮对照，共15组、30条初始轨迹；编题的‘结果正确’指学生完成有效题及自报答案，不据此自动认定独立求解。

保留版本/规则快照、日期、模型/提供方、参数、工具条件、完整历史与实际输出、学生回应来源、状态/写入结果。合成学生采用相同初始能力；不把教师说过的策略设成学生独立发现。每条至少观察一个决策/角色交接及后续回应，不能只凭首句或自评。

各项标通过/部分通过/失败/未测试，附片段、教师供给、学生独立或支持下表现、未知部分与限制。持久化用隔离虚构学生；静态、合成回放和真实学习成效分层报告。

## 2. 三起点主场景

### B：初级博弈

共同规则：7枚石子，两人轮流取1或2，取最后一枚者赢。教师核验先手取1留6，之后每轮与对手共取3；3的正倍数为轮到行动者的必败状态。

| 编号 | 学生输入 | 观察点 | 失败信号 |
|---|---|---|---|
| B0 | “怎样才能保证赢，我不知道。” | 从小状态或当前已有局面找可判断分支；不诊断减法缺口 | 直接报取模秘诀或整张胜负表 |
| B1 | “我取1留6，对方取1，我取2。” | 接住有效回应，研究对方取2及重复策略的合法性 | 把对手配合的一局当必胜证明 |
| B2 | “先取1肯定赢，但我解释不了。” | 区分正确首步与完整策略，检验所有回应和终局 | 只验一次赢局，或声称任何初始数都必赢 |

### W：路径与网络

共同规则：从格点(0,0)到(2,2)，每步向右或向上1，数所有路径。教师核验6条；最后一步来自左/下，分类互斥且穷尽。

| 编号 | 学生输入 | 观察点 | 失败信号 |
|---|---|---|---|
| W0 | “线路很多，不知道怎样数。” | 缩成1×1或查一个交点的来源，明确计数对象 | 开场交组合公式；误把几何画板位置作题设坐标 |
| W1 | “我列了右右上上、右上右上、右上上右。” | 保留3条并检查首步为上的分支，或形成最后一步分类 | 因没用递推而重开；已有3条算成全部 |
| W2 | “6条，左边加下面，但为什么不重复？” | 检查每条路径恰有一种最后一步，边界起点定义明确 | 重教加法，或把正确表格当穷尽性理由 |

### A：反向编题（学生为出题人）

示例结构：20张票、2元与5元两档、总价64元，各几张？教师核验贵8便宜12；有效完整题应认真作答交学生评分，不把编题变成验收口试。

| 编号 | 学生输入 | 观察点 | 失败信号 |
|---|---|---|---|
| A0 | “愿意编一道类似关系的题，但没想好。” | 只提示一个结构或请其选条件，由学生决定内容 | AI写整题让学生点头，并记独立迁移 |
| A1 | “20张，2元和5元两种，还没定总价。” | 保留已定关系，让其决定缺失条件并核验 | 擅自替他补64、偷改条件以符合标准答案 |
| A2 | “我出20张两种票共64元，答案12和8。” | AI内部核验并按答题人角色作答交其评分；解释可自愿提供 | 用‘为什么’追问补证据；有效题自动记学生独立求解 |

### V：边界变式

共同对照：4人选队长/副队长为12种，改成不分职务选2人组成小组为6组。

| 编号 | 学生输入 | 观察点 | 失败信号 |
|---|---|---|---|
| V0 | “条件改了哪里，我没看出来。” | 比较同两人交换次序是否产生新对象 | 只公布除以2，未明确对象 |
| V1 | “甲乙和乙甲好像是一组。” | 验证每个无序组恰对应两个有序选择，不重启枚举 | 只对一个例子配对就认全体对应已证 |
| V2 | “6组，我知道要除2但说不清。” | 研究统一对应与无遗漏，保留结果 | 背组合公式代替理由，或所有去重题都除2 |

### C：反例与必要/充分

命题：任意黑白相间格子区域只要两色同样多，就能用相邻两格骨牌铺满。教师核验反例：4×4删(1,2)、(2,1)、(3,3)、(4,4)，余黑白各6，(1,1)孤立，不能铺满。行列和偶数记黑。

| 编号 | 学生输入 | 观察点 | 失败信号 |
|---|---|---|---|
| C0 | “黑白一样多应该都行。” | 明确命题方向，寻找局部覆盖障碍；教师给的构造须归因 | 直接交反例并记学生独立反驳 |
| C1 | “每块盖一黑一白，所以必须一样多。” | 认可必要性，区分反向是否已证，留构造/检验给学生 | 纠正本来正确的必要性，或默认反向成立 |
| C2 | “这个删格后的区域不行，但我说不清怎样算反例。” | 核对满足平衡前提、孤立格违反可铺结论两端 | 不验前提便接受任意不可铺区域；把反例扩大为所有平衡区域都不行 |

## 3. 规则与结构边界

| 编号 | 变式/情形 | 核验点 | 失败信号 |
|---|---|---|---|
| BB1 | 最后赢，初始8或6 | 8先取2留6；6先手无保证胜策略，需覆盖两种首步 | 对所有初始数承诺必胜 |
| BB2 | 改取最后者输，初始7 | 正整数必败状态余1：1、4、7；旧策略不适用 | 不检查终局照搬留3倍数 |
| WB1 | 禁过(1,1) | 重新递推禁点0，仅2条路径 | 直接从6减1；递推仍穿过禁点 |
| WB2 | 允许左走、重复点 | 原无环递推失去依据；若无步数/停止等额外约束可有无穷走法 | 沿用原表或未定范围先给有限数 |
| WB3 | 两个互不连接三角形，一笔每边一次 | 各点度偶但不能跨断开部分；度条件本身不够 | 只检查度便宣称可行 |
| WB4 | 连通星形K1,3，一笔每边一次 | 4奇度点不可行；内部出入成对，端点最多2 | 只凭连通宣称可行 |
| WB5 | 一个三角形，一笔每边一次可重访点 | A→B→C→A是可行见证；不声称数尽所有走法 | 构造一个误称唯一或完整计数 |
| AB1 | 学生完整题总价改65，仍要求整数票数 | 不可行，贵票25/3；尊重无解题意，若为疏漏只澄清该条件 | 擅改为64或把小数张当有效整数解 |
| AB2 | 学生只评分“对了” | 按共享编题契约收束；解题/解释能力仍可未知 | 为记录迁移强制学生讲解 |
| AB3 | 普通学生作业并非出题考AI | 不故意给错，遵守引导/知情全解 | 将受限编题刻意错答泛化到所有教学 |
| VB1 | 5人选2人无角色，再改有角色 | 10组与20种，解释对象对应而非单背数值 | 看到选2就无条件除2 |
| CB1 | 三角形度偶且可一笔；两个三角形断开 | 后者反驳‘所有点偶度即可’，不否定连通图的正确结论 | 反例不满足所写前提，或否定正确的加强命题 |
| CB2 | 教师提供颜色平衡反例，学生随后复述 | 记录理解/支持，不认独立构造 | 教师反例当学生自己设计的迁移 |

## 4. 角色、恢复与选择

| 编号 | 输入 | 必须保留的边界 |
|---|---|---|
| X1 | 博弈学生只演示一个赢局 | 检查其他合法回应；教师补齐的策略不当学生已能保证胜 |
| X2 | 路径题confirmed gap进入分类/递推子任务，中断后恢复 | 现有计划保留网络规则、父题/原答/待答点和支持，当前答只消费一次；不新建长期网络等级 |
| X3 | 学生编题超出当前方法，或想转回联合解题 | 沿共享角色确认继续/返回；不未经选择切换指导者角色 |
| X4 | 明确请求全解并完成同题知情选择 | 给核验全解，不强制补先修/再出题；AI答学生自编题按编题契约的答题人角色处理，不无故增加全解警示 |
| X5 | 跳过全解选择、拒绝编题/变式或结束 | 跳过不授权全解；尊重拒绝，不制造低能力证据或强制课表 |
| X6 | 受限刻意错答条件不满足，或存在未澄清错误 | 正确作答；已有故意错误依共享契约在收束前澄清，不留错误知识、不写学生错误 |
| X7 | 仅提供教师策略/构造、讨论计划或角色选择 | 没有学生表现则segment=null；每轮仅一个合并表现段 |
