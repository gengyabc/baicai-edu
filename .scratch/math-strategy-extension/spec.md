# 高年级数学思维方法扩展

Status: ready-for-agent

- 日期：2026-11-12。
- 范围与测试边界：已由用户确认；本次为规格发布，不是运行时实施授权。
- 进度：详细设计及数学示例已审阅；三个阶段尚未实施，新增行为场景均待执行。

## Problem Statement

现有高年级数学教学已经具备常规知识点、Pólya 解题主线、关系推导、证明、学生编题，以及假设调整、有序枚举、余数周期三类方法；递归先修学习、耐久学习计划和知情全解选择也已实现。

但面对几何转化、数论结构、存在性、极值、不变量、博弈和网络等陌生问题时，通用方法名称与证明规则还不足以稳定支持具体教学。学生可能会计算却不知道从哪里开始，已有有效思路却被教师预设路线覆盖，或答案正确却无法解释完整性、必要性和适用边界。

用户需要继续补齐具体数学方法的教学支持，而不是扩大题型套路库、重新建设通用教学框架，或把学生遇到的一次困难固化成长期能力标签。

## Solution

以“题目结构 → 数学思维方法 → 局部思维障碍 → 教师引导动作 → 理由检验与能力迁移”组织剩余教学材料，分三阶段交付：

1. **基础补齐**：几何分割拼补、等积与辅助构造；递推与结构规律；整除、质因数与奇偶。
2. **非套路拓展**：逻辑约束；抽屉与存在性；极值优化；不变量与染色。
3. **综合与迁移**：初级博弈；路径与网络构造；跨方法反向编题、边界变式与反例。

每阶段均提供可条件加载的教学规则、核验后的案例和独立验收。学生可从实际问题进入任何适用方法；阶段划分是工程交付顺序，不是必须依次完成的课程。

面向四至六年级的广泛学习者，以陌生问题中的策略选择、监控、解释与迁移为目标，非竞赛培养优先。继续使用现有教学负责人、递归先修、学习计划、学生编题角色和知情全解机制，不要求学生记住方法名称，也不把每道题结束都变成强制迁移练习。

## User Stories

### 进入任务与选择方法

1. 作为学生，我希望教师从我的实际题目和学习目标出发，以便不被迫完成一套无关的奥数课程。
2. 作为学生，我希望用熟悉的语言、图示或操作理解高阶问题，以便年级和术语不成为探索内容的门槛。
3. 作为学生，我希望自己可行的解法被认真核验和接续，以便不因不同于标准路线而被迫重来。
4. 作为学生，我希望不知道从哪里开始时得到可行动的结构线索，以便保留自己作出关键推理的机会。
5. 作为学生，我希望已完成的有效部分被保留，以便下一步只处理真正阻碍进展的地方。
6. 作为学生，我希望答案正确但解释不足时得到针对理由的帮助，以便不用无意义地重复全部计算。
7. 作为学生，我希望能比较尝试带来的进展，以便逐渐决定继续、调整还是更换策略。
8. 作为教师，我希望区分理解、表征、策略、执行和论证上的局部障碍，以便按证据选择教学动作而非给学生贴标签。
9. 作为教师，我希望方法与知识点形成多对多关联，以便同一方法能迁移到不同题型、同一道题能容纳不同路线。

### 几何转化与构造

10. 作为学生，我希望把不规则区域关联到可计算的整体或部分，以便理解分割和补全的目的。
11. 作为学生，我希望解释每个面积计算项对应的区域，以便检查覆盖、遗漏和重叠。
12. 作为学生，我希望知道某条辅助线为何值得考虑，以便不只模仿无法解释的神奇构造。
13. 作为学生，我希望区分面积保持与形状、周长保持，以便不把等积关系过度推广。
14. 作为学生，我希望依据明确的底、高、平行和垂直条件推理，以便示意图外观不误导结论。
15. 作为教师，我希望文字定义、纸笔或已提交图片都能承载几何学习，以便不依赖画板尚不具备的测量能力。

### 递推与结构规律

16. 作为学生，我希望把新增部分与已有部分联系起来，以便从生成动作理解递推关系。
17. 作为学生，我希望保留正确的逐步计算方法，以便不因尚未找到通式而被判为没有进展。
18. 作为学生，我希望区分有限样本中的猜想与给定规则的必然结果，以便不把猜下一项当作证明。
19. 作为学生，我希望说明通式中每一部分数的是什么，以便公式来自结构而不是记忆。
20. 作为学生，我希望改变起点或生成条件后重新检查关系，以便理解原规律的适用范围。
21. 作为教师，我希望按目标区分递推、闭式和一般性论证，以便不强制不需要的符号或形式归纳。

### 整除、质因数与奇偶

22. 作为学生，我希望用乘法结构和因子配对寻找约数，以便解释为什么没有重复或遗漏。
23. 作为学生，我希望在质因数分解中看出缺少哪些因子，以便解决最小补因子问题。
24. 作为学生，我希望区分一个乘数可行与它确实最小，以便不把成功试验当作最优证明。
25. 作为学生，我希望用配对或一般表达说明奇偶性质，以便不依赖少数例子的观察。
26. 作为学生，我希望检查1、2、平方因子等边界，以便避免错误的数论概括。

### 逻辑、存在性与极值

27. 作为学生，我希望把多个条件组织为可检查的候选关系，以便有依据地排除不可能情况。
28. 作为学生，我希望题目多解、无解或条件不足时得到真实说明，以便不被强造的唯一答案误导。
29. 作为学生，我希望区分找到一个合法分配与证明它唯一，以便理解存在性和穷尽性的不同要求。
30. 作为学生，我希望用类别容量理解某种重合为何必然发生，以便不只是套抽屉原理公式。
31. 作为学生，我希望区分至少能保证多少与实际恰有多少，以便不夸大存在性结论。
32. 作为学生，我希望缺少真实分配信息时教师承认无法指出具体对象，以便存在证明不会变成虚构名单。
33. 作为学生，我希望先明确整数、正值、形状和其他限制，以便优化的是题目真正允许的对象。
34. 作为学生，我希望同时给出界和达到它的构造，以便说明一个值确实是最大或最小。
35. 作为学生，我希望区分可达最值与只能无限接近的界，以便条件改变后不会照搬旧答案。

### 不变量与染色

36. 作为学生，我希望研究每种合法操作改变和保留了什么，以便建立不可能性判断。
37. 作为学生，我希望知道染色服务于哪种覆盖关系，以便理解染色而非记忆一种配色技巧。
38. 作为学生，我希望对所有合法操作类型检查保持性，以便有限几次尝试不会冒充一般证明。
39. 作为学生，我希望区分必要条件成立与目标确实可达，以便不会把颜色平衡自动当作可铺证明。
40. 作为学生，我希望规则加入新操作时重新检查不变量，以便不把旧结论用于已经改变的问题。

### 博弈、路径与网络

41. 作为学生，我希望在研究策略前明确行动、终止和胜负规则，以便知道自己到底要保证什么。
42. 作为学生，我希望从小状态和终局倒推，以便形成可解释的行动策略。
43. 作为学生，我希望考虑对手的全部合法回应，以便区分一次赢局与真正的必胜策略。
44. 作为学生，我希望初始局面不存在保证获胜策略时得到诚实说明，以便不会被承诺无条件必胜。
45. 作为学生，我希望最后一步胜负规则改变后重新分析，以便理解策略依赖哪些条件。
46. 作为学生，我希望明确路径的方向、起终点和重复限制，以便路线计数有清楚的对象。
47. 作为学生，我希望用互斥且穷尽的最后一步分类理解路径递推，以便知道为何没有重复或遗漏。
48. 作为学生，我希望区分构造一条合法路线与数出全部路线，以便不把可行见证误当完整计数。
49. 作为学生，我希望分别检查网络的整体连接与局部条件，以便不把单个必要条件误当充分条件。

### 编题、迁移与学习选择

50. 作为学生，我希望自愿选择反向编题，以便用自己决定的条件和情境表达数学结构。
51. 作为学生出题人，我希望AI认真答题并由我评分，以便编题不会暗中变成教师对我的验收口试。
52. 作为学生，我希望编题中的矛盾或缺失条件被局部指出，以便保留我对问题的主导权。
53. 作为学生，我希望区分换故事的近迁移与改关键条件的边界检验，以便知道自己理解了结构还是只熟悉外壳。
54. 作为学生，我希望构造的反例明确满足前提且违反结论，以便真正检验一个命题而不是随意举例。
55. 作为学生，我希望能拒绝编题、变式、暂停或结束，以便学习计划不是必须完成的考核清单。
56. 作为学生，我希望确认缺少工具时先学习相应子问题，以便不在原题里被直接塞入多个陌生工具。
57. 作为学生，我希望先修过深时保留原目标并协商近期目标，以便可以作出知情选择而不丢失学习位置。
58. 作为学生，我希望中断、保存和继续后恢复当前子任务及父任务位置，以便不重复回答或复活已经放弃的目标。
59. 作为学生，我希望明确请求完整解答后能了解取舍并选择，以便保留获得全解的权利而不被强制先修或练习。
60. 作为学生，我希望教师提供的构造、答案和提示与自己的表现分开记录，以便学习档案真实反映我独立做到了什么。
61. 作为维护者，我希望各阶段独立接入和验收，以便不需要重构所有教学流程才能补充一种方法。
62. 作为维护者，我希望沿用现有高层教学回放和契约测试，以便不为每个方法建立新的测试接口。
63. 作为维护者，我希望未测试、部分通过和失败都保留真实记录，以便文档完成或静态通过不会被误报为学习成效。

## Implementation Decisions

1. 分为基础补齐、非套路拓展、综合与迁移三个可独立实施的阶段；具体专题及数学案例由配套详细设计约束。阶段不是学生固定课表，不要求完成前阶段后才允许探索后阶段。
2. 保留四至六年级的表达与负荷适配，非竞赛培养优先；年级、陌生术语或一次错误不决定内容上限或能力类型。
3. 扩展现有高年级核心的条件加载与数学思维方法索引；仅在任务结构、当前障碍或解释需要匹配时读取专题材料。
4. 以少量 reference 承载几何、数论、组合约束和非套路推理的职责；既有初步代数承载适合的递推增补，既有编题增补承载迁移设计。最终拆分可按职责合并，不按题型注册独立 Skill。
5. 每类方法都包含结构线索、必要概念与前置工具、可区分的局部障碍证据、最小教师动作、理由与完整性检查、教师核验案例、近迁移和失效边界。
6. 方法索引与数学知识图谱分别回答怎样思考、需要什么工具，多对多关联；既有假设调整、有序枚举和余数周期维持唯一规则来源，不重新复制。
7. 复用既有 Pólya、推导和证明流程。专题补充具体可见线索和数学边界，不再创建平行教学循环或以理论名称为独立模块。
8. 保持当前 session 为唯一教学负责人和 leaf 调度者。新方法不新增 act、submode 或调度节点，不允许 leaf 任意互调；保持既有同轮调度上限与等待规则。
9. 每轮只推进一个连贯思考任务并保留一个当前待答问题；先接学生已有关系和有效路线，之后才选择支架，不重写其原解题历史。
10. 局部思维障碍是可修正的教学判断，不替代已有诊断枚举，不新增长期学生类型、方法评分、掌握概率或综合等级。
11. 学生策略监控在关键决策或实际停滞时取证：尝试建立或排除了什么、下一步为何继续或改变。教师重规划本身不能写成学生监控能力。
12. 未知工具先做会改变教学决策的最小探查；确认工具缺失后复用已实现的递归先修教学，保留父题、进入最近工具子任务、必要时递归，并依独立使用证据逐层返回。
13. 工具子任务内正常教学仍可使用示例、解释、探究和练习；局部工具就绪不自动证明父题策略选择或长期掌握。
14. 递归过深、搁置、目标协商、拒绝后的风险说明、暂停与结束，全部沿用现有计划机制。有效替代路线可解除不再必要的依赖，不强制补完整章知识。
15. 复用现有耐久学习计划、活动任务投影、保存授权、幂等重试及终止标记；新专题不新增数据协议字段、第二任务栈或新的长期计划集合。
16. 继续遵守引导优先与知情全解选择：明确索要全解时先警示并等待同题选择，确认后提供核验全解，不要求先出现困境、补完先修或完成强制练习。提示请求、含糊肯定和跳过不能扩大为全解授权。
17. 学生出题考AI时沿用共享编题契约的答题人角色，不额外套用教师向学生出题的全解门。AI认真求解、交学生评分，受限刻意错答的许可与澄清义务保持不变。
18. 教师给出的辅助线、染色、反例、公式和关键策略均明确来源。每轮至多一个合并表现段；只有实际学生表现才产出证据，纯计划、选择或教师演示不产生独立能力记录。
19. 几何只依据题设及已读取材料中的明确关系；允许文字、纸笔图、表格和提交图片，不从示意外观或画板位置、大小推断长度、面积或几何证明。
20. 递推区分生成规则、初始状态、逐步计算和一般理由；有限前缀不足以唯一决定后续，递推可用不等于已经得到闭式或证明。
21. 数论任务明确正整数等范围，检查约数配对、重复和穷尽、质因数结构、最小性及1和2等边界；不默认需要形式定理或指数记法。
22. 约束任务区分无解、唯一解和多解；存在任务区分保底下界、精确数量与具体对象识别；优化任务同时检查界与达到该界的可行构造。
23. 不变量覆盖全部合法操作；颜色平衡等必要条件不视为充分条件。规则改变后重新核验保持性，不能靠多次试验代替一般理由。
24. 博弈明确终局、合法行动及对手所有回应；网络明确点边、方向和重复限制。构造可行对象、完整计数和证明必胜是不同目标。
25. 近迁移、边界辨别、反向编题与反例按目的分别取证，允许拒绝；有效题目不自动证明学生会独立求解，教师代编也不能成为学生迁移证据。
26. 数学方法内容保留在高年级 band，共享层继续只承担既有学科无关协议；本扩展不暗中改变低年级或其他学科的教学默认行为。
27. 运行时材料保持自包含；本规格和外部理论材料仅供工程设计，不成为教学运行时必读依赖。

## Testing Decisions

### 已确认的主要测试边界

1. **以现有教学入口的多轮回放作为主要边界**：从学生输入推进教学，观察学生可见回复、任务续接、证据归属和实际保存结果。复用既有入口，不为每个方法新增调用接口或新的测试框架。
2. 测试关注对外行为：是否接住学生策略、支架是否有理由、是否提前替做关键推理、是否检查方法边界、角色与选择是否被尊重。接受不同但有效的解释、路线和措辞，不匹配固定话术或私下推理过程。
3. 每类方法都覆盖无思路、已有有效部分、结果正确但解释不足三个起点。基础阶段9组旧/新配对、非套路阶段12组、综合迁移阶段15组，共36组、72条初始轨迹；另运行配套边界与交互场景。这是工程回放覆盖，不是学生题量配额。
4. 旧侧采用本轮已有三方法、递归计划和知情全解的版本，新侧采用对应阶段实施版；固定规则快照、模型与参数。至少推进一次策略决策或理由检查及后续学生回应，保留实际分叉，不能拼接成统一成功历史。
5. 数学行为必须检查命题范围、有限样本与一般理由、存在与唯一、必要与充分、可行与最优、单局获胜与必胜、构造与完整计数等区分。教师核验答案不提前放入学生独立开题。
6. 跨模块只复用既有递归与计划回放夹具增加代表性场景：工具子任务、单层返回、保存中断后的续接、回答只消费一次、已终止目标不复活。不得另造耐久任务模型以方便新专题测试。
7. 同一高层边界覆盖知情全解、学生编题角色和退出选择：首次明确全解请求先警示、确认后不附加强制先修；学生出题由AI答题交其评分；跳过不授权，拒绝迁移不记能力不足。

### 辅助检查与既有先例

8. **沿用现有技能静态检查与契约回归**：验证条件入口可达、引用自足、既有规则单一来源、无新Skill或协议字段，以及递归计划和知情全解守卫不回退。文本断言只用于这些架构契约，不把准确的提示词排列当教学行为。
9. **数学案例核验**：复用算术、有限枚举、构造验证与人工论证审阅。核验充分条件、反例前提、穷尽性、最小性和对手全回应；小规模枚举只能检查样例，不能替代一般证明。

11. 合成学生和写入操作使用隔离虚构数据；保留版本、日期、模型/提供方、参数、工具条件、完整实际历史、状态与保存结果、教师供给、学生表现归属和限制，不读写真实学生档案。
12. 每项只按实际记录标通过、部分通过、失败或未测试。静态通过、数学核验、模型合成与真实学生学习效果分层报告；不要求新版一定优于一个已合格的旧回复，也不因阶段1通过而宣称后两阶段通过。
