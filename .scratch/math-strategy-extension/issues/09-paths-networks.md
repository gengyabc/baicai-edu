# 09: 路径计数与网络构造

Status: ready-for-human
Blocked by: None (can start immediately)

**What to build:** 学生明确路线对象与规则，用最后一步分类组织路径计数，或构造并验证可行网络路线，区分局部必要条件、完整计数与存在见证。

## Acceptance criteria

- [x] 按路径/网络实际结构条件接入现有方法索引与核心，不强制普通题转图论，不新建Skill或把本专题省略出已确认范围。
- [x] 明确点边、方向、起终点、障碍和重复限制；从(0,0)到(2,2)只右/上时6条，左/下来源分类互斥且穷尽，边界起点定义一致。
- [x] 禁过(1,1)后仅2条；允许左走及重复点时不照搬无环递推，先检查是否有长度/终止限制及无穷走法可能。
- [x] 一笔每边一次可重访点时，两个断开三角形说明偶度不充分，连通星形K1,3说明连通不充分；合法三角形路线只证明可行，不自动证明唯一或计数穷尽。
- [x] 保留学生已列合法路线，遗漏时定位未覆盖分支；教师不直接给组合公式，题设格点不等于画板布局坐标。
- [ ] 完成阶段3路径W0–W2三起点各一组旧/新多轮对照及WB1–WB5边界，区分构造目标与数全目标。
- [x] 先修分类/递推缺口进入现有工具子任务，保存和恢复保留父题规则及原答；知情全解与退出、每轮一个合并表现段保持现状，不造网络能力等级。
- [x] 数学案例、条件接线及现有静态/契约回归留可复核结果，实际回放保留版本和输出，未执行或不支持分支不报通过。
