# 10: 学生反向编题闭环

Status: ready-for-human
Blocked by: None

**What to build:** 愿意编题的学生保留结构并自主决定场景、数量和条件，AI按答题人角色核验作答、交学生评分；编题、求解、评分和迁移分别取证，不将活动变成教师口试。

## Acceptance criteria

- [x] 在现有编题增补和题目设计中接入方法内核提示，复用共享编题契约与原leaf；学生可拒绝，阶段3不以全部专题学完为准入条件。
- [x] 学生未成题时只帮助决定当前一个关系/条件，不代编完整题让学生点头；完整有效题直接认真作答交学生评分，不无故增加全解警示。
- [x] 核验20张票、2元/5元、64元时贵8便宜12，65元不满足整数张数；缺条件只澄清该处，尊重有意多解/无解，不偷改成标准题。
- [x] 学生评分“对了”可收束，不为补迁移证据追问完整解释；有效题和自报答案不自动成为独立求解证据。
- [ ] 超出焦点或求助时按既有角色选择确认继续/返回；普通学习者全解请求仍走同题知情选择，编题答题角色不颠倒。（规则已写，实际角色交互未回放）
- [ ] 受限刻意错答仅在共享契约许可条件下使用，收束前澄清；不泛化到学生作业、不将AI错误记为学生困难。
- [ ] 完成阶段3编题A0–A2三起点各一组旧/新多轮对照及AB1–AB3、角色交互边界，分别记录学生构题、教师帮助与评分表现。（A0–A2/AB1–AB3 合成回放两侧均无失败信号；X3/X4/X6/X7 与真实运行时未测）
- [x] 条件接线、既有静态/契约回归及代表性恢复/退出通过实际检查（恢复/退出仅静态复核）；每轮至多一个合并表现段，不新建迁移评分或数据字段，未执行项保持未测试。
