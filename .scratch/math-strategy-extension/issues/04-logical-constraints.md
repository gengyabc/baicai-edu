# 04: 逻辑约束与解的完整性

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 学生把多个条件组织为可检查的候选，依据条件排除、传播并验证结论；教师真实区分唯一解、多解、无解与条件不足，不强造标准答案。

## Acceptance criteria

- [x] 通过现有条件入口和方法索引按需接入约束教学，复用有序枚举与证明，不新增独立Skill、调度节点或长期障碍枚举。
- [ ] 明确对象、取值、互异/可重复和量词；排除须有依据，未探索的空格不当作已排除。
- [ ] 三人三色各用一次、A非红、B非蓝、C红的任务得到唯一A蓝B绿C红，并分别说明满足条件及排除其他候选。
- [ ] 删除C红后保留三解，原题另加A红时说明无解；不偷补条件或只代回一个候选就声称唯一。
- [ ] 已有有效部分优先接续；学生只漏用互异条件时处理该处，不重教整题或无依据退回计算。
- [ ] 完成阶段2逻辑L0–L2三起点各一组旧/新多轮对照及LB1–LB2边界，观察一次实际排除/完整性决策及后续回应。
- [ ] 工具确认缺失时沿既有递归和恢复推进，保持同题知情全解与退出选择；教师表格/推理与学生表现分别归因，每轮一个合并表现段。
- [ ] 数学案例、条件接线及现有静态/契约回归完成并留记录；实际模型回放、有限枚举和真实学习效果分层报告。
