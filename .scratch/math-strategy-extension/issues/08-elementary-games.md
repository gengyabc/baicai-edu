# 08: 初级博弈与必胜策略

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 学生从明确规则与小状态倒推，解释策略如何覆盖对手全部合法回应，区分一次赢局、正确首步与完整必胜保证，并识别初始必败或规则改变的情况。

## Acceptance criteria

- [ ] 通过现有入口按有限终止、确定、完全信息的轮流博弈结构加载专题；不新增Skill、独立调度器或博弈等级。
- [ ] 先明确允许行动、终止和胜负；7枚每次取1或2、最后赢时取1留6，覆盖对方取1/2及后续合法性和终局，不能只展示配合赢局。
- [ ] 初始6枚最后赢时说明先手无保证胜策略；初始8取2留6；最后输的规则下1、4、7为必败，重新分析而非照搬留3倍数。
- [ ] 接住学生有效首步和已验证分支，只追未覆盖回应；无思路从小状态探查，不据此诊断不会减法。
- [ ] 确认缺工具走已有子任务，策略可达后正常教学；教师给出的状态表/关键回应明确归因，正确首步不自动确认为完整策略掌握。
- [ ] 完成阶段3博弈B0–B2三起点各一组旧/新多轮对照及BB1–BB2边界，观察实际对手分支决策，不匹配固定口诀。
- [ ] 知情全解确认后提供核验策略而不强制先修或验收练习，拒绝/结束优先；恢复沿既有计划，不多记表现段或复活放弃目标。
- [ ] 核验数学案例、条件可达和现有静态/契约回归，保留实际历史、环境与限制；不把有限胜负表核验写成真实学习效果。

## Comments

按已确认的三阶段扩展规格发布。归属综合与迁移阶段；已有周期、枚举和证明能力可复用，不以新不变量票为必需依赖。
