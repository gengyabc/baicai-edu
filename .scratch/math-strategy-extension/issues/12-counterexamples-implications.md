# 12: 反例构造与命题方向

Status: ready-for-human
Blocked by: None

**What to build:** 学生针对明确命题寻找或检验满足全部前提却违反结论的对象，区分必要与充分、原命题与反向，并知道没有找到反例并不证明命题成立。

## Acceptance criteria

- [x] 经现有证明、题目设计与方法入口接入反例增补，不重建一般逻辑流程或独立Skill；学生可自愿构造，也可理解已给反例。
- [x] 首先明确全称范围与前提/结论方向；保留学生正确的必要条件理由，只追反向是否已证，不把找不到反例当证明。
- [x] 核验4×4按行列和偶数为黑，删(1,2)、(2,1)、(3,3)、(4,4)，余两色各6且(1,1)孤立；反驳一般区域颜色平衡即可铺满，不否定平衡的必要性。（有限枚举精确核验）
- [x] 两个断开三角形能反驳只要求所有点偶度的一笔画命题，不能拿它否定附有连通前提的正确加强命题。（有限枚举精确核验）
- [x] 学生只报不可铺时检查前提与结论两端；教师提供的完整反例记支持/理解，不当学生独立构造，也不把所有平衡区域都判不可铺。（规则层）
- [ ] 完成阶段3反例C0–C2三起点各一组旧/新多轮对照及CB1–CB2，至少观察一次命题方向或反例有效性决策及后续回应。（合成回放已完成：C0–C2/CB2 两侧通过，CB1 旧侧通过、新侧部分通过；真实运行时与学生效果未测）
- [ ] 使用既有工具子任务、保存恢复、同题知情全解与退出边界；不强制补完逻辑课程或继续出反例，不新增长期类型或多余表现段。（规则与静态守卫已写，实际交互未测）
- [x] 数学核验、条件可达及已有静态/契约回归留记录，实际轨迹注明模型环境和提示来源（无真实轨迹，如实记为未测试）；有限示例、合成回放与真实效果分别报告。
