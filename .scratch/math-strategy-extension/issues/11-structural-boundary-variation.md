# 11: 关键条件变式与方法边界

Status: ready-for-human
Blocked by: None

**What to build:** 学生在同意的对照任务中辨认承重条件改变，说明原推理哪一步仍成立、哪一步需调整；近迁移与方法边界分开取证，不把变式变成机械换数或强制练习。

## Acceptance criteria

- [x] 增补现有题目设计和方法入口，按结构边界检验需求进入；复用既有变式、证明与策略监控，不新增Skill或另一教学流程。
- [x] 每次主要改变一个承重条件，保留其他条件和有效关系；区分原方法不能直接搬用与题目不能解决，接受可核验替代路线。
- [x] 4人选队长/副队长12种，改为无角色小组6组；每个无序组恰对应两个有序选择须说明，不用一个例子代替全体对应。（逐组 6/6 已数学核验）
- [x] 5人无角色选2人10组、有角色20种；先定义计数对象再决定是否去重，不对所有选择题机械除2。
- [ ] 近迁移答对、复述教师总结或教师直接指出变化都不自动证明独立边界辨别；拒绝变式可返回原题或结束，不降低能力判断。（规则已写，行为未观察）
- [ ] 完成阶段3变式V0–V2三起点各一组旧/新多轮对照及VB1，已有枚举方法即可演示，不等待其他新专题。（未测试，无回放环境；VB1 仅数学核验）
- [ ] confirmed gap走既有子任务，保存/恢复保留原比较条件与提示来源；知情全解、学生自主选择和每轮单一表现段不回退。（规则与静态守卫已写，实际恢复/全解交互未测）
- [x] 核验例题、条件接线、既有静态/契约回归和真实回放留痕（无真实回放，如实记为未测试），学生监控与教师决策分清，未测试和失败如实记录。
