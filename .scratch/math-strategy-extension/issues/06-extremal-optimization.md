# 06: 极值、界与可达构造

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 学生在明确的可行范围内比较方案，同时说明不可能更优和某个方案确实达到界，理解最值与只能接近的界之间的区别。

## Acceptance criteria

- [ ] 经现有条件入口按求最大/最小的结构加载增补，复用枚举、推导与证明，不强制新增代数不等式课程或Skill。
- [ ] 先明确正整数/正实数、单位、允许正方形等限制；沿学生枚举或平衡调整路线检查全局性，不把局部改善当最优。
- [ ] 正整数长宽、周长20且允许正方形时最大25由5×5达到；覆盖短边1至5或给出可达的一般界理由，单一构造不足以证最大。
- [ ] 周长24最大36；周长20禁正方形最大24；周长20正整数最小9，正实数无最小值且0不可达，不能把不可达界当实际最值。
- [ ] 正确结果缺解释时只补上界/穷尽或可达性中缺失的部分；教师提供的关键比较与学生选择分别记录。
- [ ] 完成阶段2极值E0–E2三起点各一组旧/新多轮对照及EB1–EB3边界，不以算出最大样例替代完整理由。
- [ ] 复用确认工具缺口的子任务、独立使用后单层返回、知情全解与退出；每轮一个合并表现段，不新增方法评分或计划结构。
- [ ] 运行数学核验及已有静态/契约回归，保存实际输出和限制；未回放、部分通过与失败不写为已验证学习改善。

## Comments

按已确认的三阶段扩展规格发布。归属非套路拓展阶段；本票可用既有面积工具与有限枚举独立实现，不被新几何票人为阻塞。
