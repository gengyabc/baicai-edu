# 13: 全量整合验收与跨方法续接

Status: ready-for-human
Blocked by: 01 几何分割、拼补与辅助构造; 02 递推与结构规律; 03 整除、质因数与奇偶结构; 04 逻辑约束与解的完整性; 05 抽屉与保底存在性; 06 极值、界与可达构造; 07 不变量与染色; 08 初级博弈与必胜策略; 09 路径计数与网络构造; 10 学生反向编题闭环; 11 关键条件变式与方法边界; 12 反例构造与命题方向

**What to build:** 将所有专题整合到同一高年级教学入口后，学生能在实际需要时联结方法、学习必要工具并继续原任务，跨方法与活动的续接不丢题、不混淆角色或能力证据；交付全量可复核验收，而非再建一层教学框架。

## Acceptance criteria

- [ ] 01–12各自已交付完整条件接线、数学核验和局部验收；整合候选reference时每条匹配条件仍可达、规则单一来源，现有三方法不回退。
- [ ] 核对合并顺序按[导航](<../tickets.md#分批合并>)中的共享面分组执行，每个批次合入后既有静态/契约回归保持通过；未合并到公共入口的专题不得宣称已接入运行时。
- [ ] 核验各票子代理与 worktree 交付记录：每票报告标明本 worktree 结果、合入版本、所用规则快照及未合入状态，共享规则源未被多份重叠实现，无跨票私造调度或协议。

- [ ] 验证代表性的面积与优化、数论与不变量、递推与路径等跨方法联结；不强制每题用多法，不把教师换法记为学生策略监控。
- [ ] 跨专题confirmed gap复用同一session及现有任务链，独立使用工具后单层返回；保存中断续接只消费一次新回答，原题、原答、支持来源和待答点仍可恢复，终止目标不复活。
- [ ] 指导学习转学生自愿编题再返回时，出题人/答题人角色、模式和原任务位置一致；AI答学生题不误触学习者全解门，明确全解请求仍先警示后同题选择。
- [ ] 过深、拒绝调整、拒绝子任务、跳过、暂停及结束沿原规则处理；不增加全局字段、新任务栈、方法等级、低年级默认改动或画板授权。
- [ ] 每轮至多一个合并表现段，子任务工具使用与父题选法分开，构造可行/计数穷尽/最优/必胜等目标不混淆；纯教师演示或过程选择不造表现。
- [ ] 汇总三个阶段共36组旧/新配对、72条初始轨迹的实际结果及边界覆盖表；复用各票已留证据，不重跑无实质集成风险的局部用例，不把不同版本拼成一次全通过。
- [ ] 对全量集成版本运行现有技能检查与契约回归，并复用既有高层教学和持久化夹具追加跨专题场景，不新增测试接口或重复建设框架。
- [ ] 列出通过、部分通过、失败和未测试项及各自版本与限制；真实学生效果、安装集成仍无证据则保持未知。不得将本验收作为自动安装或发布授权。
