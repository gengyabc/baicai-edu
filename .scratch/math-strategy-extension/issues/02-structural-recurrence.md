# 02: 递推与结构规律

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 学生从明确的生成动作识别旧部分与新增部分，建立递推、解释一般结构，并区分给定规则与有限样本猜想。教师保留学生有效的逐步计算，不强制通式或形式归纳。

## Acceptance criteria

- [ ] 在现有初步代数与方法索引中按结构需要接入增补；一般推导/证明仍由既有流程负责，不重复火柴题流程或新增Skill。
- [ ] 点阵第k行有k点的任务区分起点、状态、增量、递推计算、闭式及一般理由；按原目标决定是否需要通式。
- [ ] 接住学生已找到的新增一行或递推路线；正确答案缺理由时研究每项数什么，不靠多试几个样本认定一般证明。
- [ ] 教师提供拼合构造时明确归因；学生后续代入或复述不能记为独立发现或策略监控。
- [ ] 核验第10个三角点阵55、8层台阶36；共边正方形变独立正方形时由3n+1改为4n，说明条件变化。
- [ ] 明确仅给1、3、6、10的有限前缀不能唯一确定下一项；不将15以外的相容续项直接判错，不以术语或字母为准入条件。
- [ ] 完成阶段1递推P0–P2三起点各一组旧/新多轮对照及PB1–PB3边界，记录学生判断、教师支持与仍未知的一般化能力。
- [ ] 复用先修、恢复、知情全解、退出和每轮一个合并表现段；执行既有静态/契约检查并保留实际回放与未测试项，不建新测试接口。
