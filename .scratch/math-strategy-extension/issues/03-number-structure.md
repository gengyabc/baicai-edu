# 03: 整除、质因数与奇偶结构

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 学生用因子配对和乘法结构解释约数的完整性、最小补因子及奇偶性质，而不是只记公式或试出一个数。任务范围、可行性与最小性得到分别核验。

## Acceptance criteria

- [ ] 从现有高年级条件入口按需进入数论增补，关联必要知识工具；余数周期继续引用已有规则，不要求完整数论摸底或新增教学实现。
- [ ] 约数配对检查遗漏与重复，36的正约数为9个、24为8个；平方因子只计一次，指数选择须有对象对应理由。
- [ ] 36补成立方最小正整数乘数为6，24为9；同时解释可行与排除更小，接受有限检验或工具可达的因子结构路线。
- [ ] 改为36补成平方时最小乘数1；明确正整数等范围，不暗中要求乘数大于1，不把唯一分解定理证明或指数记法设为门槛。
- [ ] 两奇数之和、三奇数之和分别给出一般配对或表达理由；2反驳所有质数为奇数，1不属于质数。
- [ ] 无思路先区分选择与工具障碍；确认缺口进入已有子任务，分解正确不自动证明策略选择或最小性。
- [ ] 完成阶段1数论N0–N2三起点各一组旧/新多轮对照及NB1–NB4边界，不以固定话术或有限样例替代一般理由。
- [ ] 运行既有静态/契约检查并验证先修返回、知情全解和证据边界；保留版本、实际轨迹与限制，未运行或失败不标通过。
