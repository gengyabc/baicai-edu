# 01: 几何分割、拼补与辅助构造

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 学生从当前图形、已知条件和自己的分法出发，理解分割、补全、等积与辅助对象的用途，并能解释每个面积项对应的区域。完成从现有教学入口触发、按需读取专题规则、继续学生路线到记录真实证据的闭环。

## Acceptance criteria

- [ ] 通过现有高年级核心条件入口与方法索引接入，仅在面积转化或辅助构造需要时读取规则；复用推导、证明及原session调度，不新增Skill或协议字段。
- [ ] 对L形区域接受合法分割和补集两种路线，检查覆盖、重叠、遗漏、单位与每项对应的区域；不强制改成教师预设分法。
- [ ] 同底同高三角形的等积依赖明确的垂直距离，允许垂足落在底边延长线上；不从示意图或画板位置大小推定长度、平行、面积。
- [ ] 辅助线的选择连接学生可见线索与所需关系；教师提供的构造明确归因，不记为独立发现。工具缺口进入既有先修子任务。
- [ ] 核验42平方厘米的L形例、58平方厘米近迁移、同底不同高的12与15，以及等积不意味着全等或等周长的边界。
- [ ] 完成阶段1几何G0–G2三起点各一组旧/新多轮对照及GB1–GB4边界，至少观察一次策略或理由决策及后续回应，不匹配固定措辞。
- [ ] 代表性验证先修单层返回、知情全解、退出与教师供给证据；每轮至多一个合并表现段，无学生表现不造能力记录。
- [ ] 执行既有静态/契约检查并留版本、实际轨迹、状态及限制；未执行标未测试，数学核验不等于教学效果通过。
