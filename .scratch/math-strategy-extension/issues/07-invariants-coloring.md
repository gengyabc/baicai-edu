# 07: 不变量与染色

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 学生分析全部合法操作保留的量，连接初态与目标来证明不可能；需要染色时理解其覆盖作用，并区分必要条件与可达构造。

## Acceptance criteria

- [ ] 通过操作状态或覆盖结构条件接入专题，复用现有证明与方法索引，不因所有棋盘题都默认染色或新增Skill。
- [ ] 8×8棋盘行列和偶数记黑，删两同色对角格后30黑32白；水平/竖直骨牌都各覆盖一黑白，完整保持性支持不可铺结论。
- [ ] 学生试铺失败不能直接证明不可能；教师引入染色或状态量须说明用途并归因，不将跟随计数记为独立发现。
- [ ] 6×6同类删格保持理由；2×2删上行可铺须有一张骨牌构造；一般区域两非相邻异色格证明颜色平衡不是充分条件。
- [ ] 加入斜对角或其他牌型后重新核验每个合法操作，不沿用未经验证的不变量，也不从未排除推到已可达。
- [ ] 完成阶段2不变量I0–I2三起点各一组旧/新多轮对照及IB1–IB4边界，保留学生已证明的方向，处理第一处承重缺口。
- [ ] 奇偶等确认缺口走现有递归子任务，恢复时保留染色提供者、原题与待答位置；知情全解、拒绝迁移和结束不回退。
- [ ] 案例数学、条件接线及现有静态/契约回归经核验，实际多轮输出与证据归属留档；纯教师证明不生成学生掌握。

## Comments

按已确认的三阶段扩展规格发布。归属非套路拓展阶段；已存在的奇偶教学路径足以接入，不要求新数论票先落地。
