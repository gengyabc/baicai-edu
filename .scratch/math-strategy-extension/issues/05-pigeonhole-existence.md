# 05: 抽屉与保底存在性

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 学生通过类别容量与总数比较说明重合为何必然发生，区分保底下界、实际精确人数和识别具体对象，并在需要时用构造说明保底紧性。

## Acceptance criteria

- [ ] 现有方法索引能按有限对象、类别与至少/必有目标进入专题；对象分配覆盖有理由，避免关键词直接套除法或新增Skill。
- [ ] 13人按12个月分类时，以全类最多1人的容量矛盾说明某月至少2人；一月2、其余各1说明保证2紧，不断言实际恰好2人。
- [ ] 25人可保证某月至少3，12人不能保证同月；给出有效反向容量理由及相容分配，不以几个样例代替全称证明。
- [ ] 无生日数据不能指认具体名单或指定月份；存在证明不自动成为实际对象识别，教师不虚构数据。
- [ ] 接续学生已有分类或算式，优先修复保底与精确的解释障碍；必要工具confirmed gap才进入既有子任务。
- [ ] 完成阶段2抽屉H0–H2三起点各一组旧/新多轮对照及HB1–HB3边界，学生给出原理名称不算完整论证。
- [ ] 知情全解确认后可提供核验证明，不强制先修或额外练习；教师证明与学生独立解释分清，支持/选择/计划不造独立能力。
- [ ] 执行现有静态/契约检查及代表性恢复/退出回归，留实际轨迹、状态和限制；未执行行为场景保持未测试。
