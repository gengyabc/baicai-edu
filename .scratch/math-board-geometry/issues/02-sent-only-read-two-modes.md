# 首版 AI 只读，两个 tab 互不相通

Type: grilling
Status: resolved

## Question

首版几何画板的定位是教学引擎之一，还是只是表达工具？两个模式怎样放在同一入口里？

## Answer

首版只画、只读：学生操作，AI 读取已发送快照并按学生自述回应；不追问辅助线、不给教学建议、不推导、不评论画得像不像，与当前数量画板的功能范围一致。复杂教学功能以后再说。

界面用独立 tab 分开数量与几何：各自的画布、工具栏、草稿存储键、撤销历史、选择与视口；切换 tab 不互见、不转换、不传递数据，只共用题目参考、「我想说」和「放入回答」入口。

`math_board_settings` 仍只作用于数量模式；几何没有设置入口。
