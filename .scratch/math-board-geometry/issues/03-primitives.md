# 首版图元与构造范围

Type: grilling
Status: resolved

## Question

首版允许学生画哪些对象？精确构造做到什么程度？

## Answer

- 点：自由点（学生放置、拖动）。派生点只能来自构造。
- 线段：引用两个已有点。
- 多边形（含三角形）：引用三个及以上已有点的闭合对象。
- 圆：圆心点 + 圆上点。
- 矩形、平行四边形：三点定第四点的精确构造，矩形附加直角约束（见 `05-rectangle.md`、`15-rectangle-parallelogram.md`）。
- 点显示 A/B/C 标签且可改名，引用只认稳定 ID；标签在快照中唯一。
- 每个图元可带一条说明；没有多选说明与组（见 `08-notes-copy.md`）。

砍掉射线、直线、一般四边形模板和交点构造。首版唯一的精确构造族是“两点→一点”的闭式运算：线段中点、矩形由三个自由顶点确定第四个顶点。不引入圆与线、线与线的求交。

首版没有 `relations` 数组、没有直角/等长标记、没有测量读数。学生或题目的条件只能写在说明里，AI 只读不验。
