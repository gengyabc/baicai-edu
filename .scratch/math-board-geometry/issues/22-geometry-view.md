# 几何视图与工具栏

Type: task
Status: ready-for-agent
Blocked by: 20

## 目标

在几何 tab 中提供画笔、选择、拖动、说明、撤销/重做与缩放，不接提交。

## 背景

规格 `../spec.md` §2、§3；决策 `../issues/03-primitives.md`、`10-labels-tools.md`、`14-labels.md`、`17-drag-constraints.md`。

## 验收

- [ ] 独立 SVG 画布（`cartesian-2d`，`board-unit`，y 向下），与数量画板的坐标、图案轨无任何换算关系。
- [ ] 左／下工具栏：选择、点、线段、多边形（含三角形）、圆、平行四边形、矩形、辅助线（`role: auxiliary`，虚线）；缩放与适应宽度。
- [ ] 点选与连线：允许先放点后连线，空白两次点选自动落点；点优先于线命中；吸附已有点时显示预览。
- [ ] 拖动自由点提交一次撤销；预览不进历史、不进快照。
- [ ] 矩形/平行四边形拖动：任一角对角不动、其余角联动；圆形拖动语义按规格。
- [ ] 点显示 A/B/C 标签，选中可改名；改名一条撤销。
- [ ] 每个图元与整板可写说明（「我想说」），切换选择不覆盖。
- [ ] 网格与吸附开关为本地 UI 状态，不进快照。
- [ ] 撤销/重做上限与数量模式一致（40 步），快捷键盘位与读屏标签可用。
- [ ] 手动「清空本模式」：确认后清画布与该模式撤销历史，不删附件。
- [ ] 数量 tab 的视图与行为完全不回归。
