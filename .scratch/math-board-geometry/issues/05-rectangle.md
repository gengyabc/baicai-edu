# 矩形是精确构造模板

Type: grilling
Status: resolved

## Question

数量画板里“矩形”只是数量图案；几何里要不要矩形？

## Answer

要。矩形与平行四边形同属一族（三点定第四点），矩形额外保持直角约束。拖动任一角时，其对角不动、另两角联动重算，因此怎么拖都仍是矩形。命名上仍叫矩形。

Q24 之后，本节“其余自由顶点不动、只重算派生点”的说法作废，以 `15-rectangle-parallelogram.md`、`17-drag-constraints.md` 为准。

与数量模式同名的 `rectangle` 图案在任何层面都不互相转换：几何矩形有顶点和边，数量矩形只有数值。
