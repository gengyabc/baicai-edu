# 拖动时的退化与约束保持

Type: grilling
Status: resolved

## Question

拖动自由点时，怎样避免产生退化图元，又保持矩形/平行四边形的约束？

## Answer

- 拖动被吸收：自由点不能拖到使任何包含它的构造退化的位置；拖动停在阈值处，而不是拒绝整次拖动。
- 圆上点不能与圆心重合。
- 平行四边形：拖动一个顶点时，其对角不动；另外两个顶点按“三点定第四点”的闭式运算重算，结果保持两组对边平行。
- 矩形：与平行四边形同一族，附加直角约束；拖动一个顶点时，其对角不动，另外两个顶点按直角重算。对角充当每次拖动的锚点，不写入快照。
- 快照验证拒绝退化输入（零长度线段、共线多边形、零半径圆）；预览状态不进入快照，也不进入撤销历史。
