# 教育包依赖与统一安装

## 目标

- 数学安装入口一次配齐共享学习包与数学画板。
- 语文、英语安装入口一次配齐共享学习包。
- 共享包与画板仍可独立安装，多学科共用同一个注册，不复制 patch。
- 保留现有学生数据及本工作区已有未提交改动。

## 方案

先核实当前 DSH 的 bundle 发现与激活机制。依赖声明采用 package.json 的 dependencies，仓库内私有包使用 file: 相邻目录。若 DSH 仅激活 profile 顶层依赖，则提供仓库级安装入口：从同一份依赖声明计算拓扑闭包，将所需包以顶层 link: 一次交给 dsh plugin add；不在学科 patch 中复制共享技能或画板注册，不修改 DSH 安装代码。

## 验收

- 数学闭包为 learn、math-board、math-primary-low；语文/英语为 learn、对应学科。
- 多学科、重复输入去重；独立包无反向依赖。
- 安装入口支持显式 profile 与只读预览，失败返回非零，不误报激活成功。
- 回归测试覆盖依赖闭包、未知输入、循环/缺失依赖、命令执行失败。
- 尽可能在隔离 profile 中验证真实 DSH 注册与重复安装；不借验证修改当前 web profile。
- 更新所有相关安装说明与包依赖总览；明确原生单包 link: 不等于完整安装。

## 实施与验证结果

- 已在数学、语文、英语 manifest 中声明私有目录依赖，新增统一安装入口与安装说明，更新各包 README、调用图与 AGENTS 安装指针。
- DSH 0.2.2-rc.1 仅自动选择新增顶层依赖，安装器将声明的依赖闭包提升为一次 CLI add 的顶层链接；已有手动禁用保持禁用。
- 静态检查：31 skills，0 errors，0 warnings。
- 普通回归：140/140（安装器 13、教学协议 35、画板 92）。
- 真实 DSH 隔离集成测试：1/1，验证数学新装、全学科追加、重复运行、配置唯一注册、显式禁用保留；含空格的临时 DSH_HOME 在测试后自动清理。
- 独立只读代码审查无待修复问题。当前 web profile、学生数据与用户原有未提交改动均未修改；没有宣称真实 Web 界面已验收。
