## 1. 目标与非目标

优化的是第一次进入画板时带着学生实际操作的互动教程，不是帮助文档、开发者指南或纯按钮高亮导览。

数量画板与几何画板分别提供分章节的连续小任务，覆盖下文列出的重要操作。可验证的步骤必须由学生亲手操作、成功达到本步目标后通过，不能只点“下一步”。前一步作品尽量用于后一步，不为每步无故重建画面。

非目标：不新增数学解题功能，不验证学生数学结论，不测量或评判几何关系，不改变提交协议、教师工具授权及年级段教学规则，不新增跨设备进度同步或学生能力档案。完成教程只说明完成操作练习。

## 3. 已确认的产品决策

1. 数量、几何各自独立引导，不混为一条长教程。~~首次进入各自的页面时启动引导。~~ **（ADR-0005 取代）**首次进入只播放一次轻量快速导览；分章教程由学生在「更多操作 → 查看教程」显式进入，不自动开始。
2. 允许随时退出，并保留再次进入、续学和重练的入口。
3. 以连续小任务组织章节，尽量复用本章或前章成果。
4. 全部操作使用教程练习；退出、完成后回到原有真实草稿，不向对话实际附加练习文件。
5. 支持分章节完成与单章重练，不要求一次走完全部内容。
6. 按当前浏览器、画板类型分别保存进度，不引入跨设备同步。
7. 续学恢复未完成步骤及对应练习画面；重练一章不清其他章进度。
8. 区分已完成与已跳过；跳过的步骤可补练，不能悄悄计入完成数。
9. 未达目标要提示差什么，提供“重置本步”“跳过本步”。
10. 鼠标与触屏都能完成，不强制 Shift、悬停或键盘快捷键；等效操作不必全部重复训练。
11. 文件操作是可选进阶章，不阻塞基础教程完成。
12. 教师演示仅在首次有图时引导，不为教程调用教师工具或凭空生成教师图；复制也只进入教程练习。

## 4. 章节结构与完成口径

数量与几何各有独立的章节清单，显示本章位置、完成与跳过状态。教程运行时只常驻本章步骤轨；其他章节在「全部章节…」里列出（ADR-0005）。进入教程从保存的章节继续，没有记录时从基础章开始；基础章后可继续后续章节，也可退出后续学。章节目标及下文全部非可选操作仍须覆盖，不能以“基础教程已完成”代替整套操作覆盖。

清单（无论常驻还是收在「全部章节…」里）应区分“基础章完成”“其他章节待练”“可选进阶章”，不得把未完成或跳过章节显示为整套教程全部完成。补练与重练使用足以完成目标的练习起点；不要求先重走所有前章。具体拆成多少个提示步骤可由实现决定，但不得把下列独立操作合并成一句提示来替代练习。

每个步骤至少包含：本步目标、当前要做的动作、需要的练习起点、可验证的完成条件、未通过提示、重置本步后的起点。检测本步实际变化，不能让已有对象、程序预置或前一步事件自动满足本步。

## 5. 数量画板操作覆盖与验收

连续任务示例：摆放一批同类物品 → 整理与命名 → 分组与合并 → 写出各层说明 → 修正与整理视图 → 练习放入回答。示例是操作任务，不要求学生求出数学答案。

| 章 / ID | 必须亲手练习 | 完成条件与关键防误判 |
| --- | --- | --- |
| 基础 Q01 | 添加图案 | 本步新增对象成功；点图案或拖入均可，不以按钮点击代替新增成功 |
| 基础 Q02 | 拖动 | 移动指定练习对象并松手提交；只是按下、预览或原地单击不通过 |
| 基础 Q03 | 单选、多选、取消选择 | 分步达到指定选择集合，再清空选择；触屏可用追加选择，鼠标可框选等 |
| 整理 Q04 | 命名 | 对指定对象保存有效名称，重新选中仍能读到；取消或无效输入不通过 |
| 整理 Q05 | 圈组、组命名、解散组 | 确实形成包含目标成员的组，保存组名，再解散为独立成员；多添加几个不算分组 |
| 整理 Q06 | 合并、拆开 | 用满足现有规则的对象成功合并，再拆开恢复来源；禁用按钮、失败合并不通过 |
| 整理 Q07 | 复制 | 成功增加目标副本，原对象保留；重复选择原对象不通过 |
| 整理 Q08 | 划去 | 指定对象实际变为划去状态，说明它不同于删除；撤销可恢复 |
| 整理 Q09 | 删除 | 目标对象从教程练习移除；不把清空整板当作删除所选 |
| 说明 Q10 | 整板说明 | 先取消选择，再写入并重新打开核对整板说明，不能误写成对象说明 |
| 说明 Q11 | 单个图形说明 | 写入指定图形，再切换对象核对关联未混淆 |
| 说明 Q12 | 组说明 | 写入目标组，而非某个成员或整板；重新选组可读到 |
| 说明 Q13 | 多选对象说明 | 关联到本次指定对象集合，而非整板、单个图形或另一集合 |
| 调整 Q14 | 创建颜色 | 选不同档位后新增对象采用该档位数值及颜色；已有对象保持原值，不教成“改已有对象颜色” |
| 调整 Q15 | 工具箱图案添加、收起 | 加入原本未显示的图案并用它新增，再收起；已有对象不消失，至少保留一个工具箱图案 |
| 调整 Q16 | 撤销、重做 | 对明确的一次变化先撤销、再重做，状态分别恢复；按钮点击或不可用状态不通过 |
| 调整 Q17 | 缩放、适应画面 | 实际改变缩放，再回到适应视图；提示可滚动查看，不能只点当前档位 |
| 调整 Q18 | 清空与确认 | 先有练习内容，确认清空后对象、说明、修改记录与撤销历史按现有规则清除；不影响另一真实画板或附件 |
| 放入 Q19 | 附带修改记录选项 | 在教程练习内切换选项并核对选择；说明快照与修改记录是不同附件，关闭记录仍可放入快照 |
| 放入 Q20 | 练习放入回答 | 学生实际触发模拟放入，获得明确练习反馈；真实输入框、附件与发送行为均无变化 |

必要语义随操作说明，不新增运算判断：分组不是合并；合并受同形、同值、同组或均未分组、同别名限制；拆开与来源有关；灰色合并结果不意味着错误。清空不可撤销，删除所选不等于清空。规则依据见[分组与合并](<../../math-board/docs/interface.zh.md>)。

清空后可连续进入放入章节的新练习阶段，或由教程明确提供该章练习起点；不能要求学生提交空白作品，也不能借恢复步骤悄悄恢复已清空的撤销历史。

## 6. 几何画板操作覆盖与验收

连续任务示例：放点与连线 → 添加轮廓和圆 → 使用构造工具并拖动 → 文字和说明 → 视图与修改恢复 → 练习放入回答。各图形在练习画面中留出可操作空间，不要求数学证明或按像素复刻示范。

| 章 / ID | 必须亲手练习 | 完成条件与关键防误判 |
| --- | --- | --- |
| 基础 G01 | 点工具与落点 | 成功创建自由点；只选工具不算落点完成 |
| 基础 G02 | 线段 | 成功创建引用练习端点的线段，不以第一次点击或未完成预览通过 |
| 基础 G03 | 三角形 | 完成三点绘制并生成对象，不要求判断边长角度 |
| 基础 G04 | 多边形闭合 | 实际点回起点完成闭合，存在完整对象；未闭合预览不通过 |
| 基础 G05 | 圆 | 完成圆心、圆上点的绘制并生成圆，不把单个点当作圆 |
| 构造 G06 | 平行四边形、矩形 | 分别通过对应三点构造工具成功创建；不能以普通多边形代替，也不测量边角判断 |
| 构造 G07 | 取中点 | 先选可用线段或边，实际执行后生成对应派生点；自由落一个点不能通过 |
| 构造 G08 | 拖动自由点 | 目标自由点成功移动并提交；说明派生点不能直接拖动，不把拖不动当成任务失败原因 |
| 构造 G09 | 辅助线 | 开启后成功创建辅助角色图形，再关闭；只切换开关不代替创建练习 |
| 编辑 G10 | 选择、取消选择 | 选中指定点或图形，再清空选择；不以悬停通过 |
| 编辑 G11 | 点改名 | 指定点保存有效新名，原图形引用保留；重名等失败不通过 |
| 编辑 G12 | 文字添加、修改 | 成功创建文字，再原地修改其内容；取消、空输入或新增第二份代替修改均不通过 |
| 编辑 G13 | 删除 | 成功删除指定练习对象，目标引用按现有规则处理；不清空全板代替删除 |
| 说明 G14 | 点与图形说明 | 分别写入指定点、指定图形并核对关联；不把文字元素与图形说明混为同一种操作 |
| 说明 G15 | 短标签修改 | 对画布上的短标签直接点开并修改原说明，反馈字样已更新；不必悬停 |
| 说明 G16 | 整板说明 | 取消选择后保存整板说明；不被自动选中的新图形截走说明目标 |
| 调整 G17 | 网格、吸附 | 分别切换并体验对应绘制操作；以设置状态及操作成功检查，不拿示意位置推断几何关系 |
| 调整 G18 | 撤销、重做 | 对本章明确变化分别撤销、重做，结果与操作匹配 |
| 调整 G19 | 缩放、适应画面 | 缩放真正变化，再切回适应视图；能滚动查看放大的内容 |
| 调整 G20 | 清空本模式 | 有内容时确认清空练习几何画板及撤销历史，不影响数量画板与已有附件 |
| 放入 G21 | 练习放入回答 | 实际触发模拟放入，明确只有几何快照与整板说明，没有几何修改记录；不创建真实附件或发送消息 |

构造步骤检查“使用指定工具创建成功”，不根据学生图上的长度、角度、平行、垂直、相等或共线来判定过关，不对学生几何结论作真假判断。可说明工具构造及自由点/派生点的操作差别。依据见[几何工具、文字、拖动与说明](<../../math-board/docs/geometry.zh.md>)。

## 7. 可选文件进阶章

数量与几何分别使用各自文件格式，不互相转换；此章可跳过，不阻塞基础章节完成。

| ID | 操作 | 验收 |
| --- | --- | --- |
| F01 | 保存画板文件 | 实际发起安全的练习保存；不能把点按钮算保存成功。用独立练习文件，不复用、覆盖真实作品的文件句柄 |
| F02 | 打开画板文件 | 选择适用格式的练习文件并成功载入教程练习；取消、格式错误或跨模式文件拒绝均不通过，且不破坏当前练习 |
| F03 | 系统能力与失败反馈 | 文件选择取消、权限拒绝、下载回退等均可返回或跳过；不阻塞退出教程，不宣称文件已落盘或已读取 |

## 8. 教师演示短引导

触发条件是首次已有真实教师演示图，而不是第一次看到空的演示页。教程不调用教师画图工具、不读取未提交学生草稿来生成示例。

| ID | 操作 | 验收 |
| --- | --- | --- |
| D01 | 查看图与说明 | 说明该页只读；文字介绍可由用户确认继续，不伪称检测到了“看懂” |
| D02 | 缩放与查看 | 实际改变视图，必要时滚动；不修改教师作品 |
| D03 | 放到我的几何画板 | 实际点击复制，将当前图追加到教程练习几何状态；原教师图、真实几何草稿均不变，不附文件 |
| D04 | 返回与编辑归属 | 引导回到练习几何页，说明复制后可编辑练习副本；退出教程回到真实作答，不把练习复制算作真实受助使用 |

教师图不存在、在练习中被隐藏或换图导致本步目标失效时，提示当前条件不可用，可退出或稍后继续，不虚构图、不误记复制完成。教师工具返回请求记录不等于用户已经看见或已经复制。

## 9. 隔离、退出与恢复边界

- 隔离范围不止可见图形：两种画板的内容、全部学生说明、分组/合并来源、修改记录、撤销/重做、选择、视口，以及练习触及的图案清单、创建颜色、选项和文件目标均不得写回真实作答状态。
- “清空”只作用于教程练习，不调用宿主清空工具，不删除真实草稿或真实附件。
- 所有步骤中禁止真实放入、上传和代发；放入步骤只模拟，其他步骤中的同一入口不得绕过隔离。
- 退出、完成、切页后停止当前教程以及刷新恢复，都必须确保下一次正常使用的是原真实草稿，而非练习作品。续学则显式重新进入保存的教程练习。
- 恢复不能用一份进入教程前的旧备份覆盖期间合法更新的真实状态；实现须处理宿主设置/清空请求到达、页面销毁和异步保存回调，不能吞掉外部合法变更，也不能把它们记为学生教程操作。
- 教师图复制、导入与导出也走隔离路径；不要只隔离画布而遗留真实修改记录、附件或文件句柄副作用。
- 教程进度和教程练习保留在浏览器，不上传为作答，不写学生档案，不作为教学掌握证据。

## 10. 进度、容错与输入适配

### 进度

- 至少能区分未开始、进行中、已完成、已跳过；存储章节/步骤位置及可续学的练习状态。
- 存储作用域为当前浏览器，数量与几何分别保存；教师演示短引导不冒充几何编辑章节完成。
- 退出后重新进入可续学；单章重练不删除其他章进度。只启动或点击跳过不得触发完成反馈。
- 现有 v1 的“已看过”标记不能直接迁移为新教程全部完成。具体版本迁移及入口样式留给实现，但不得混淆看过、完成和跳过。
- 浏览器存储不可用时，允许当前练习与退出，明确不能保证续学；不假装保存成功。恢复数据损坏时保留真实草稿，并提供重新开始相关练习的路径。

### 容错

- 明确说明未达标的原因及下一步动作，不把失败点击当成功。
- “重置本步”恢复该步骤练习起点，只影响教程练习；“跳过本步”保留跳过状态，可后续补练。
- 失败操作、无效名称、空说明、不可合并对象、未完成图形、保存取消、对象上限等不能误推进。说明练习要求实际写入有效内容，不能空保存通过。
- 必要准备可由教程提供，但程序预置目标对象或恢复练习画面不算学生亲手完成本步。
- 随时可退出，包括说明卡、文件选择取消返回、绘图未结束、目标控件暂时不可用时；高亮遮罩不能把人困住。

### 输入与文案

- 鼠标、触屏均有可完成路径，多选不依赖 Shift，操作不依赖 hover。
- 按设备提示等效动作，不要求把点入与拖入、框选与快捷键等每种等效输入都各练一次。
- 小屏、滚动、缩放或窗口尺寸变化后，高亮仍对应当前目标，不遮住需要操作的控件；保留可聚焦的退出/恢复路径。
- 沿用现有中英文字典机制，两种语言的步骤、目标和失败反馈保持一致，不新增仅中文可完成的步骤。

## 11. 验收场景

以下是后续实现必须执行的验收，不代表本次已经通过：

1. **首开分流**：数量、几何各自首次启动；进入一个不标记另一个完成；无教师图时不启动教师短引导。
2. **完整覆盖**：逐条回放 Q01–Q20、G01–G21；每项有对应任务、有效完成条件和失败用例，不能只断言步骤数量或事件名。
3. **连续性**：前步作品用于后续整理；从目录单独练某章时有足够起点，不依赖真实草稿。
4. **防误通过**：添加失败、重复同档颜色、取消编辑、空说明、无效构造、合并失败、文件取消都不推进。
5. **说明作用域**：数量四种说明目标分别保留；几何点/图形/整板及短标签编辑不串写。
6. **恢复与补练**：退出、关闭工作台、刷新后续学恢复步骤和画面；跳过可补练；单章重练不清其他章。
7. **隔离对照**：预先准备两种真实草稿及说明、历史、设置和视口，完成/退出/刷新教程后逐项核对；真实输入框及附件不变，练习无上传。
8. **破坏性操作**：练习删除、清空、导入、教师图复制后真实草稿和另一模式均不变；清空不可通过撤销复活。
9. **外部变化**：教程期间到达的合法宿主变更不被旧备份覆盖；异步练习保存不落入真实草稿；不重放教程动作进入真实修改记录。
10. **文件章**：分别测试支持文件 API 和下载回退的环境；取消/拒绝不阻塞，无真实文件覆盖；下载回退提示不谎称落盘已验证。
11. **演示章**：已有图才启动；练习复制不改真实几何草稿；隐藏/换图不误判；真实教师图保持只读。
12. **输入回放**：至少分别用鼠标和触屏完成主流程，多选、闭合多边形、标签编辑均无仅键盘或悬停路径依赖。
13. **界面回归**：小屏、滚动、横竖切换、说明卡展开时目标与提示可见，用户始终能退出；中英文均可完成。
14. **存储异常**：拒绝存储或恢复数据损坏仍不影响真实草稿，反馈真实，不伪造进度。
15. **协议回归**：离开教程后正常放入流程不变：数量可带独立修改记录，几何没有；放入不等于发送，草稿保留。
