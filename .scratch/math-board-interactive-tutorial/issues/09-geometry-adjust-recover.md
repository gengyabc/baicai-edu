# 09: 几何调整与恢复互动章

**What to build:** 学生在几何教程练习中体验网格和吸附、撤销与重做、缩放与适应画面、清空本模式，理解辅助界面与作品状态的区别。

**Blocked by:** 03 — 几何基础教程与安全练习闭环。

**Status:** resolved

## 验收条件

- [x] 覆盖 G17–G20；本章支持从目录独立开始、续学、重置、跳过、补练和重练，不要求其他进阶章先完成。
- [x] 分别切换网格和吸附，并实际体验对应绘制；以选项状态和绘制成功核对，不从示意位置测量或判断几何关系。
- [x] 学生对明确练习变化先撤销、再重做，状态相应恢复；无效按钮点击不推进，程序准备作品不算本步操作。
- [x] 实际缩放并滚动查看内容，回到适应画面；当前档位重复点击不能冒充有效变化。
- [x] 在非空练习中确认清空几何模式，清空内容及该模式撤销历史，不能撤销回清空前；不影响数量画板或已有附件，不调用宿主数量清空工具。
- [x] 视口、网格、吸附、历史及清空只影响教程练习；退出、完成、刷新、迟到保存都不写回真实状态。
- [x] 清空后如继续练习，应明确提供新阶段起点，不悄悄恢复被清空的撤销历史；失败原因可理解，退出始终可用。
- [ ] 中英提示、鼠标/触屏均可完成；自动测试覆盖选项、状态恢复、视图变化、清空及跨模式隔离，记录交互回放并执行相关检查。

## 边界

按规格 G17–G20、第 9–11 节验收。网格与吸附不是数学正确性证据，不新增几何修改记录附件或数量清空提示。

## Answer

- 几何调整与恢复章 `geometry-adjust` 的步骤为 `adjust-grid / adjust-snap / adjust-undo / adjust-redo / adjust-zoom / adjust-scroll / adjust-fit / adjust-clear`。网格要先从关到开，再在网格开着时提交一个新点；吸附要先从开到关，再在吸附关着时提交一个新点。只拨开关、顺序反了，或点还没提交，都不通过。点的坐标不检查，也不从落点判断几何关系。撤销把那一个新点撤回到放置前的画板，重做把同一个点放回来。撤销或重做不可用、前后画板对不上，都不通过。`skip` 或 `start` 放上的点不会被当成这一步的操作。缩放数字必须变化；当前档位、或只把适应画面关掉而数字不变，都不通过。滚动要在缩放不是 1 或未适应时真正改变位置。适应画面只接受从关回到开。确认清空要求练习几何画板非空，清空后点和图形都没有，目标里的撤销画板也被丢掉；之后的撤销事件不能把旧画板装回去。网格和吸附不是几何对错的证据。几何模型、基础章、构造章和编辑章的步骤列表都没有改。
- `start(previousFrame)` 在上一画面已有至少一个点时复用该画板，否则放一个点。这次创建不送进 `observe`。新开始的历史是空的。网格关、吸附开、缩放 1、适应画面开、滚动 `{ left: 0, top: 0 }`。`fresh()` 返回 `{ frame, saved }`。`skip` 不调用 `observe`，不替学生打开网格、关闭吸附、撤销、重做、改缩放、滚动、回到适应或清空。跳进撤销时留下一条可撤销的历史；跳进清空时画板仍然非空。不一致的已存目标抛出 `Invalid adjust goal`，不自行修补。
- 几何页的缩放下限是 1，刚进入本章时「缩小画布」是禁用的，不会报告。第一次能改变数字的是「放大画布」，从 1 到 1.25，同时离开适应画面。缩放为 1 且适应画面开着时，测试替身里的画布就是 1280×640 的框，滚动位置变不了。因此跳进滚动这一步时把缩放设为 1.25、适应画面设为关。这个准备不送进 `observe`，被跳过的缩放步骤不会因此变成完成。适应画面按钮是来回切换：已经适应时再点会把它关掉，目标只接受从关回到开。撤销和重做比较点、图形和整板说明，不把后来的画纸尺寸算进这一步。回放里的点都落在原画纸内。
- 清空仍走几何页自己的 `clearMode`：发布 `G.empty()`，历史设为 `{ past: [], future: [] }`。不调用宿主数量清空，也不新增几何修改记录。清空后的空画板和空历史就是新阶段，不会把清空前的历史装回去。
- 已勾选的隔离项由本章单元测试和几何页处理器回放覆盖：退出后预置的真实几何草稿和数量草稿都不变，上传、附件和发送次数为 0。练习记录写在 `practice:v2:geometry`，不写几何草稿键。刷新后续上未完成的调整步骤。单章重练不清基础章已进入的步骤。既有的宿主迟到保存测试仍通过，本章没有另写一条迟到保存用例。
- 最后一项未勾：中英和 `mouse`／`touch` 指针类型都有处理器回放，聚焦检查与全量测试已执行，但没有真实浏览器、真实鼠标、触屏设备或布局验收。滚动回放是在替身节点上设置 `scrollLeft`／`scrollTop` 再调用 `onScroll`。处理器回放不是浏览器通过。
