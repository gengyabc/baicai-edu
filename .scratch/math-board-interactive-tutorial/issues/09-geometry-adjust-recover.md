# 09: 几何调整与恢复互动章

**What to build:** 学生在几何教程练习中体验网格和吸附、撤销与重做、缩放与适应画面、清空本模式，理解辅助界面与作品状态的区别。

**Blocked by:** 03 — 几何基础教程与安全练习闭环。

**Status:** ready-for-agent

## 验收条件

- [ ] 覆盖 G17–G20；本章支持从目录独立开始、续学、重置、跳过、补练和重练，不要求其他进阶章先完成。
- [ ] 分别切换网格和吸附，并实际体验对应绘制；以选项状态和绘制成功核对，不从示意位置测量或判断几何关系。
- [ ] 学生对明确练习变化先撤销、再重做，状态相应恢复；无效按钮点击不推进，程序准备作品不算本步操作。
- [ ] 实际缩放并滚动查看内容，回到适应画面；当前档位重复点击不能冒充有效变化。
- [ ] 在非空练习中确认清空几何模式，清空内容及该模式撤销历史，不能撤销回清空前；不影响数量画板或已有附件，不调用宿主数量清空工具。
- [ ] 视口、网格、吸附、历史及清空只影响教程练习；退出、完成、刷新、迟到保存都不写回真实状态。
- [ ] 清空后如继续练习，应明确提供新阶段起点，不悄悄恢复被清空的撤销历史；失败原因可理解，退出始终可用。
- [ ] 中英提示、鼠标/触屏均可完成；自动测试覆盖选项、状态恢复、视图变化、清空及跨模式隔离，记录交互回放并执行相关检查。

## 边界

按规格 G17–G20、第 9–11 节验收。网格与吸附不是数学正确性证据，不新增几何修改记录附件或数量清空提示。
