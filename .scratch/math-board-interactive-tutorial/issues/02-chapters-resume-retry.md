# 02: 章节导航、续学与补练

**What to build:** 学生能从章节目录继续数量教程，退出后恢复到未完成步骤和练习画面，能重置本步、跳过、补练及单章重练。提供可由几何与教师引导复用的章节体验，而非仅保存一个步骤编号。

**Blocked by:** 01 — 数量基础教程与安全练习闭环。

**Status:** ready-for-agent

## 验收条件

- [ ] 利用数量基础章节演示完整路径：开始练习 → 中途退出 → 关闭或刷新 → 续学恢复相同步骤和对应画面 → 完成本章。
- [ ] 目录区分未开始、进行中、已完成与已跳过；显示章节及步骤位置，基础章完成不等于整套完成，可选文件章不阻塞基础章。
- [ ] 重置本步恢复足以重新尝试的练习起点；跳过保留跳过状态，之后可补练；重练一章不清除其他章进度。用可验证场景证明，不要求尚未交付的生产章节充当依赖。
- [ ] 连续学习优先复用练习成果；从目录进入单章有足够的独立起点，不强迫先重走前章，也不使用真实作品凑前置条件。
- [ ] 当前浏览器分别保存各画板进度与练习状态；开始、退出、跳过不算完成，恢复画面或程序预置不能自动满足当前步骤。
- [ ] 存储拒绝、内容损坏或版本不兼容时保持真实草稿安全，明确续学限制并允许重新开始/退出；不假称进度保存成功。
- [ ] 说明卡、未完成绘图或目标暂不可用时仍可退出；重置/跳过不污染真实草稿或触发真实放入。后续页面接入时遵守同样的生命周期契约。
- [ ] 中英文、鼠标和触屏可完成导航与补练；小屏/滚动/尺寸变化后操作目标、提示与退出入口可用。
- [ ] 自动回归覆盖状态区分、恢复画面、单章重练、存储异常与真实草稿隔离，并记录实际交互回放结果；本票不把新版首开迁移切换提前计为已交付。

## 边界

规格第 4、9、10 节为行为边界。进度只表明操作练习完成，不写学生档案或能力判断；不引入跨设备同步。现有“已看过”到新版首次入口的产品切换由 12 负责。
