# 05: 数量说明互动章

**What to build:** 学生分别给整张数量画板、单个图形、组和多选对象写学生说明，重新选择后核对文字归属，理解“我想说”的目标取决于当前选择。

**Blocked by:** 04 — 数量整理互动章。

**Status:** ready-for-agent

## 验收条件

- [ ] 覆盖 Q10–Q13，四种作用域分别实际写入有效说明，不能只打开说明卡或空保存通过。
- [ ] 整板说明步骤明确取消选择后再保存，重新打开可读到整板说明；自动选中新图形不能把内容截成对象说明。
- [ ] 单图形说明只关联指定图形；组说明关联目标组而非某成员；多选说明关联指定对象集合而非另一集合或整板。
- [ ] 切换对象、组和多选集合后能核对各自文字未覆盖或串写；取消编辑、空输入、保存失败或写错目标不推进。
- [ ] 连续学习可复用整理章成果；目录独立开始/重练会提供或引导建立必要组及对象，不要求真实草稿含组。
- [ ] 说明卡中仍能退出、重置或跳过；恢复后保留本步画面及已保存文字，不以恢复/预置说明冒充当前操作。
- [ ] 所有说明与进度仅属于教程练习，不进入真实正文、附件、修改记录、学生档案或教学证据。
- [ ] 中英目标/反馈与鼠标/触屏路径齐全；自动测试覆盖四种归属、切换、防空保存误通过及隔离，记录交互回放并执行相关检查。

## 边界

按规格 Q10–Q13、第 9–11 节验收。学生说明是自述，不是已验证结论；本章不解释或诊断学生数学想法。
