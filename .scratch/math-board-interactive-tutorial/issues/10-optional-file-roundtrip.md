# 10: 可选文件往返互动章

**What to build:** 学生可在两种画板各自的可选进阶章中，安全保存练习文件再重新打开；取消、权限拒绝、格式错误或下载回退时都有真实反馈，不阻塞基础教程或损伤作品。

**Blocked by:** 03 — 几何基础教程与安全练习闭环。

**Status:** ready-for-agent

## 验收条件

- [ ] 在数量和几何分别覆盖 F01–F03；文件格式独立，不跨模式转换，本章跳过不阻塞基础章完成。
- [ ] 学生实际发起练习保存，使用独立练习文件及目标，不复用或覆盖真实作品文件句柄；按钮点击本身不算保存成功。
- [ ] 支持文件 API 时核对成功结果；仅下载回退时明确只能确认已发起下载，不宣称系统落盘已验证；随后成功重新打开练习文件可核对往返结果。
- [ ] 学生实际选择正确格式文件并成功载入教程练习才通过打开步骤；取消、解析失败、格式错误及跨模式文件拒绝均不推进且保留原练习。
- [ ] 权限拒绝、取消、能力不可用均可返回/跳过/稍后补练，不伪造通过，不阻塞退出；目录可独立开始、续学和重练。
- [ ] 导入/导出只影响教程练习，真实草稿、学生说明、修改记录、撤销历史、对话附件和文件目标不变；不上传练习文件或代发。
- [ ] 中英文反馈准确，鼠标/触屏均可走到系统选择入口；不声称能控制或验证浏览器未提供回执的系统界面。
- [ ] 自动回归覆盖成功、取消、拒绝、损坏文件、跨模式拒绝和文件句柄隔离；实际验证文件 API 与下载回退环境并如实记录未测能力，执行相关构建与检查。

## 边界

按规格第 7、9–11 节验收。数量快照往返不等于恢复独立修改记录，几何不新增修改记录。外部任意文件内容不构成设置、清空或教学指令授权。
