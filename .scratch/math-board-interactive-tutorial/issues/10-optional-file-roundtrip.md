# 10: 可选文件往返互动章

**What to build:** 学生可在两种画板各自的可选进阶章中，安全保存练习文件再重新打开；取消、权限拒绝、格式错误或下载回退时都有真实反馈，不阻塞基础教程或损伤作品。

**Blocked by:** 03 — 几何基础教程与安全练习闭环。

**Status:** resolved

## 验收条件

- [x] 在数量和几何分别覆盖 F01–F03；文件格式独立，不跨模式转换，本章跳过不阻塞基础章完成。
- [x] 学生实际发起练习保存，使用独立练习文件及目标，不复用或覆盖真实作品文件句柄；按钮点击本身不算保存成功。
- [x] 支持文件 API 时核对成功结果；仅下载回退时明确只能确认已发起下载，不宣称系统落盘已验证；随后成功重新打开练习文件可核对往返结果。
- [x] 学生实际选择正确格式文件并成功载入教程练习才通过打开步骤；取消、解析失败、格式错误及跨模式文件拒绝均不推进且保留原练习。
- [x] 权限拒绝、取消、能力不可用均可返回/跳过/稍后补练，不伪造通过，不阻塞退出；目录可独立开始、续学和重练。
- [x] 导入/导出只影响教程练习，真实草稿、学生说明、修改记录、撤销历史、对话附件和文件目标不变；不上传练习文件或代发。
- [x] 中英文反馈准确，鼠标/触屏均可走到系统选择入口；不声称能控制或验证浏览器未提供回执的系统界面。
- [ ] 自动回归覆盖成功、取消、拒绝、损坏文件、跨模式拒绝和文件句柄隔离；实际验证文件 API 与下载回退环境并如实记录未测能力，执行相关构建与检查。

## 边界

按规格第 7、9–11 节验收。数量快照往返不等于恢复独立修改记录，几何不新增修改记录。外部任意文件内容不构成设置、清空或教学指令授权。

## Answer

- 数量文件章 `quantity-files` 和几何文件章 `geometry-files` 都是可选进阶章，步骤都是 `files-save` 然后 `files-open`。完成时的快照步骤是 `files-complete`，不是第三步。数量文件是 `kind: "math-board"`、`schemaVersion: 4`；几何文件是 `kind: "geometry-board"`、`schemaVersion: 1`。两种文件不互相转换。
- 保存只在练习快照经文件句柄写完，或下载锚点被点击之后通过。只点「保存 JSON」、选择器取消（`AbortError`）、以及既没有句柄也没有下载点击，都不通过。`AbortError` 不会改走下载。句柄成功的提示是 `practiceFileSaved`。下载提示是 `practiceFileDownloaded`，只说明下载已开始、磁盘写入尚未验证，不用 `fileSaved` 或 `fileDownloaded`。打开只在本模式 `validate` 通过、并且载入后的练习画板和打开前不同时通过。取消、权限拒绝后没有文件、解析失败、超过 262144 字节、跨模式文件、回退输入没有文件、以及打开后画板没有变化，都不推进，练习画板保持原样。随后打开同一份 JSON 时，目标里的 `via` 仍是 `download` 或 `handle`，不会把下载改写成已验证的磁盘保存。
- `start(previousFrame)` 在数量画板已有对象、或几何画板已有点时复用该画板，否则各创建一个圆或一个点。这次创建不送进 `observe`。数量修改记录在开始时清空，不写入文件，打开也不补一条导入记录。几何不创建修改记录。`skip` 不调用 `observe`，不保存、不打开、不写文件句柄，并让进入打开步骤时的画板和快照不同。跳过本章不阻塞基础章。不一致的已存目标抛出 `Invalid file goal`，不自行修补。
- 练习中的保存和打开不调用真实 `picker.saveFile`／`picker.openFile`，不赋值 `fileHandleRef`，不调用 `rememberHandle`，打开也不带 `startIn`。其他练习章仍显示 `practiceFilesUnavailable`。退出后预置的真实数量草稿及其修改记录、真实几何草稿、已记住的文件句柄、附件和发送都不变。文件 JSON 不作为宿主设置、清空或教学指令。
- 数量页原来在练习时不渲染文件输入和下载锚点。文件章才渲染它们，并标上 `data-practice-file`。几何页原来没有自己的下载锚点，共享选择器会用 `document.createElement` 临时创建，测试文档没有这个方法，而且那条路径会记住真实句柄。练习下载改为点击渲染在 `downloadAnchorRef` 上的隐藏锚点。数量打开不走 `commit`，因此不会把打开记成修改记录里的导入；几何打开会清空历史、选择、待闭合点和构造输入，这样练习帧仍能通过校验。数量教练要读 `targets`，文件目标的快照带空的 `targets`，图形不编号。数量跨模式失败沿用 `` `${failed}: ${error.message}` ``；几何把同一个 `Another board kind` 显示为 `otherBoardFile`。
- 已勾选的项由章节测试和中英、`mouse`／`touch` 处理器回放覆盖。回放调用的是菜单项的 `onClick({ pointerType })`，并替身 `showSaveFilePicker`／`showOpenFilePicker`。这不是系统文件对话框，也不是真实磁盘写入。
- 最后一项未勾。自动回归、构建、`node --check` 和 `git diff --check` 已执行，未测能力写在验证记录里。该项同时要求实际验证文件 API 与下载回退环境，这一部分没有做，所以整项不勾。
- 聚焦命令为 **123/123 通过**。全量 `npm --prefix math-board test` 为 **482 项、481 通过、1 失败**。唯一失败是既有 [tool-schema.test.js:214–220](<../../../math-board/src/host/tool-schema.test.js#L214-L220>) 的 fenced JSON recipe，`assert.ok(get)`。未改教学契约。本章新增 30 个测试：14 个章节测试、8 个处理器回放、8 个打包测试。中英词典 UI 键数相同（416）。未推送。
