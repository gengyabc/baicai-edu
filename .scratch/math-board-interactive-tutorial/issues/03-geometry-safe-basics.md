# 03: 几何基础教程与安全练习闭环

**What to build:** 学生在独立的几何教程练习中完成基本绘制、选择及模拟放入，使用与数量一致的章节、续学和容错体验；退出后继续真实几何草稿，两种画板互不污染。

**Blocked by:** 01 — 数量基础教程与安全练习闭环；02 — 章节导航、续学与补练。

**Status:** ready-for-agent

## 验收条件

- [ ] 覆盖 G01、G02、G03、G04、G05、G10、G21：点、线段、三角形、多边形闭合、圆、选择/取消选择和模拟放入。
- [ ] 按连续任务使用前序点和图形；点工具不等于落点，线段第一次点击不等于完成，未闭合多边形与单个圆心不能通过。
- [ ] 几何页面实际接入章节导航、重置、跳过、补练和续学，刷新可恢复未完成步骤及练习画面；数量进度不受影响。
- [ ] 练习对象、点引用、学生说明、撤销历史、选择、视口和本地选项与真实状态隔离；完成、退出、关闭、切页或刷新不把练习写回真实草稿。
- [ ] 几何模拟放入明确只有几何快照与整板说明、没有几何修改记录；本步及其他步骤均不实际上传、附文件、修改输入框或发送。
- [ ] 宿主合法变更与迟到保存不能被旧恢复备份覆盖或错误写到真实状态；不影响数量草稿或既有附件。
- [ ] 鼠标/触屏均能完成全部绘制及闭合，多选/取消不依赖快捷键或悬停；中英提示与失败反馈齐全，高亮不遮挡所需画布。
- [ ] 提供成功/失败推进、跨模式隔离、刷新恢复与防真实上传的自动回归，并记录两种输入的交互回放；重建受影响产物并运行相关检查。

## 边界

遵循规格第 6、9–11 节。完成检查只认指定操作成功，不量长度角度，不判断平行、垂直、相等、共线或数学结论，不按像素复刻或“画得像”评分。
