# 08: 几何编辑与说明互动章

**What to build:** 学生在几何教程练习中修改点名、写字和改字、删除对象，再分别填写点、图形与整板说明，并直接点击短标签修改原说明。

**Blocked by:** 03 — 几何基础教程与安全练习闭环。

**Status:** ready-for-agent

## 验收条件

- [ ] 覆盖 G11–G16，支持连续任务及从目录独立开始/续学/重练，按需要提供足够练习起点。
- [ ] 对指定点保存有效新名，原图形引用保留；重名等失败不推进。
- [ ] 亲手添加非空文字，再原地修改同一个文字元素；取消、空保存或新增第二份替代修改均不通过。
- [ ] 删除指定对象并按现有规则处理引用；不能清空整板代替删除所选，不改领域删除规则。
- [ ] 分别向指定点与图形保存有效说明，核对关联；文字元素与图形说明是不同操作，不互相替代。
- [ ] 实际点击画布短标签打开并修改其原说明，画面更新；未选择对象时保存整板说明，不能被新图形自动选择截走。
- [ ] 取消、空输入、失败保存、写错对象或仅打开卡片不推进；说明卡可退出、重置、跳过，恢复画面不自动过关。
- [ ] 点名、文字、说明、删除及历史只影响教程练习，不进真实输入框、附件、修改记录或学生档案；退出/刷新不污染真实状态。
- [ ] 中英文、鼠标和触屏路径齐全，短标签不依赖悬停；自动测试覆盖引用保留、原地改字、说明归属、误通过及隔离，记录交互回放并执行相关检查。

## 边界

按规格 G11–G16、第 9–11 节验收。说明和文字均是学生自述材料，不据此判定几何结论或作答对错。不依赖构造章或调整章。
