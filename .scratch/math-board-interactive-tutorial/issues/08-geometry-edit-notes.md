# 08: 几何编辑与说明互动章

**What to build:** 学生在几何教程练习中修改点名、写字和改字、删除对象，再分别填写点、图形与整板说明，并直接点击短标签修改原说明。

**Blocked by:** 03 — 几何基础教程与安全练习闭环。

**Status:** resolved

## 验收条件

- [x] 覆盖 G11–G16，支持连续任务及从目录独立开始/续学/重练，按需要提供足够练习起点。
- [x] 对指定点保存有效新名，原图形引用保留；重名等失败不推进。
- [x] 亲手添加非空文字，再原地修改同一个文字元素；取消、空保存或新增第二份替代修改均不通过。
- [x] 删除指定对象并按现有规则处理引用；不能清空整板代替删除所选，不改领域删除规则。
- [x] 分别向指定点与图形保存有效说明，核对关联；文字元素与图形说明是不同操作，不互相替代。
- [x] 实际点击画布短标签打开并修改其原说明，画面更新；未选择对象时保存整板说明，不能被新图形自动选择截走。
- [x] 取消、空输入、失败保存、写错对象或仅打开卡片不推进；说明卡可退出、重置、跳过，恢复画面不自动过关。
- [x] 点名、文字、说明、删除及历史只影响教程练习，不进真实输入框、附件、修改记录或学生档案；退出/刷新不污染真实状态。
- [ ] 中英文、鼠标和触屏路径齐全，短标签不依赖悬停；自动测试覆盖引用保留、原地改字、说明归属、误通过及隔离，记录交互回放并执行相关检查。

## 边界

按规格 G11–G16、第 9–11 节验收。说明和文字均是学生自述材料，不据此判定几何结论或作答对错。不依赖构造章或调整章。

## Answer

- 几何编辑与说明章 `geometry-edit` 的步骤为 `edit-rename / edit-text-add / edit-text-change / edit-delete / edit-point-note / edit-element-note / edit-caption / edit-deselect / edit-board-note`。改名只认指定点的非空新名称，而且原先引用该点的图形仍然引用同一个点。空名称、取消、名称没变、模型拒绝的重名，以及只含空白的名称，都不通过。文字先要新增一条非空文字，再改同一条；取消、空保存或另起第二条都不通过。删除只认标出的那条线段，开始时就在的点、说明图形和另一个对象还要留下。删别的对象、清空整板或把对象删光都不通过。点说明、图形说明和整板说明各写各的。文字元素不能代替图形说明。图形说明超过 20 字不通过，短标签也就不会出现。短标签要点开后再改同一条说明，只打开卡片不算。整板说明这一步如果目标是点或图形，页面不调用 `action()`，新出现并被选中的对象也不能把说明截走。说明和文字都是学生自己的话，不据此判断几何结论或作答对错。几何模型、基础章和构造章的步骤列表都没有改。
- `start(previousFrame)` 返回练习画面。已有自由点、引用它的图形，以及删除后必须留下的另一个对象时复用，否则补齐。这些创建不送进 `observe`。`fresh()` 返回 `{ frame, saved }`。`skip` 准备下一步的点、文字或 1–20 字短标签，不调用 `observe`，也不替学生完成本步要求的改名、改字、删除或写入。不一致的已存目标抛出 `Invalid edit goal`，不自行修补。
- 删除一条线段时，模型会一并去掉没有其他图形再用的端点。简报里的后备图只有一个点、一条用到它的线段和另一个点；若删除那条唯一线段，被标出的点会一起消失，后面的图形说明和短标签就没有几何图形可用，文字元素也不能代替。因此说明线段和被标出的点留下，另有一个不是该线段端点的自由点留下，删除的是另一条端点别处都不用的线段。模型没有改。
- 已勾选的隔离项由本章单元测试和几何页处理器回放覆盖：退出后预置的真实几何草稿不变，数量草稿不变，上传、附件和发送次数为 0。练习记录写在 `practice:v2:geometry`，不写几何草稿键。单章重练不清基础章已进入的步骤。
- 最后一项未勾：中英和 `mouse`／`touch` 指针类型都有处理器回放，短标签走的是命中目标而不是悬停，聚焦检查与全量测试已执行，但没有真实浏览器、真实鼠标、触屏设备或布局验收。处理器回放不是浏览器通过。
