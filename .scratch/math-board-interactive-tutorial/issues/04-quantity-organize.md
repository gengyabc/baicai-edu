# 04: 数量整理互动章

**What to build:** 学生对同一批练习物品完成命名、分组、合并及日常整理，亲手体验这些操作的区别与结果；本章既可接续基础成果，也能从目录独立重练。

**Blocked by:** 02 — 章节导航、续学与补练。

**Status:** ready-for-agent

## 验收条件

- [ ] 覆盖 Q04–Q09：对象命名、圈组/组命名/解散、合并/拆开、复制、划去、删除；每个独立动作均有实际练习和成功条件。
- [ ] 保存有效对象名称后重新选择可读到；取消/无效输入不通过。成功形成包含目标成员的组、修改组名并解散，多次添加对象不能算分组。
- [ ] 用满足同形、同值、同组或均未分组、同别名规则的练习对象合并，再按合并来源拆开；失败/禁用点击不推进。不改变现有分组或合并规则。
- [ ] 复制产生目标副本且原对象保留；划去实际改变目标状态而非删除；删除移除指定对象而非清空整个画板。
- [ ] 随操作说明分组不等于合并、灰色结果不表示错误、拆开与来源有关，不替学生判断运算或数学答案。
- [ ] 目录能开始/续学/重练本章，适当复用上一步作品，独立进入时有足够练习起点；失败可提示、重置、跳过并补练。
- [ ] 所有动作、名称、组及来源只在教程练习生效；退出/刷新/异步保存不污染真实草稿、修改记录、撤销历史或附件。
- [ ] 中英提示、鼠标和触屏流程齐全；自动测试覆盖每项成功及至少一个失败/误判路径，记录完整章节回放并执行相关构建和回归检查。

## 边界

按规格第 5 节 Q04–Q09 及第 9–11 节验收。本票向后续说明章提供可创建、命名、解散练习组的完整操作，不只添加分组事件名称。
