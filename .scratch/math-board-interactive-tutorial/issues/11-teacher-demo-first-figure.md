# 11: 教师演示首次有图引导

**What to build:** 首次已有教师演示图时，学生得到短引导，了解只读查看、缩放和复制，亲手把当前图追加到教程练习几何画板并查看副本；真实教师作品和学生草稿不变。

**Blocked by:** 03 — 几何基础教程与安全练习闭环。

**Status:** ready-for-agent

## 验收条件

- [ ] 覆盖 D01–D04；有真实演示图才启动，无图不自动展开空教程，不调用教师画图工具或凭空生成演示图。
- [ ] 说明教师页只读；阅读介绍可由学生确认继续，不宣称检测到“看懂”或已经复制，也不以工具返回 recorded 代替实际操作。
- [ ] 学生实际改变视图并按需要滚动，教师作品不被编辑；界面有可用的退出入口。
- [ ] 实际点“放到我的几何画板”后，把当前图追加到隔离的练习几何状态，再引导进入练习几何页查看可编辑副本；不是替换真实草稿或自动附文件。
- [ ] 练习复制不改真实几何/数量草稿、真实历史或附件，不记作学生真实受助使用，不上传或写学生档案；结束/退出/刷新回到真实作答。
- [ ] 隐藏或换图导致目标失效时明确说明，可退出或稍后继续，不误报复制完成、不虚构旧图；可用图恢复后有可继续的练习路径。
- [ ] 短引导进度与几何编辑章区分，可退出后续学/重练，跳过不算完成；不依赖尚未交付的几何编辑章完成。
- [ ] 中英提示与鼠标/触屏齐全；自动回归覆盖无图、有图、实际复制、换图/隐藏和隔离，记录交互回放并执行相关检查。

## 边界

按规格第 8–11 节验收。教师页不新增学生页的“我想说”“放入回答”或编辑工具；教师图与练习副本都不被当作数学掌握证据。
