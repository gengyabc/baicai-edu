# 11: 教师演示首次有图引导

**What to build:** 首次已有教师演示图时，学生得到短引导，了解只读查看、缩放和复制，亲手把当前图追加到教程练习几何画板并查看副本；真实教师作品和学生草稿不变。

**Blocked by:** 03 — 几何基础教程与安全练习闭环。

**Status:** resolved

## 验收条件

- [x] 覆盖 D01–D04；有真实演示图才启动，无图不自动展开空教程，不调用教师画图工具或凭空生成演示图。
- [x] 说明教师页只读；阅读介绍可由学生确认继续，不宣称检测到“看懂”或已经复制，也不以工具返回 recorded 代替实际操作。
- [x] 学生实际改变视图并按需要滚动，教师作品不被编辑；界面有可用的退出入口。
- [x] 实际点“放到我的几何画板”后，把当前图追加到隔离的练习几何状态，再引导进入练习几何页查看可编辑副本；不是替换真实草稿或自动附文件。
- [x] 练习复制不改真实几何/数量草稿、真实历史或附件，不记作学生真实受助使用，不上传或写学生档案；结束/退出/刷新回到真实作答。
- [x] 隐藏或换图导致目标失效时明确说明，可退出或稍后继续，不误报复制完成、不虚构旧图；可用图恢复后有可继续的练习路径。
- [x] 短引导进度与几何编辑章区分，可退出后续学/重练，跳过不算完成；不依赖尚未交付的几何编辑章完成。
- [ ] 中英提示与鼠标/触屏齐全；自动回归覆盖无图、有图、实际复制、换图/隐藏和隔离，记录交互回放并执行相关检查。

## Answer

- 短引导章 `teacher-demo-basics` 的步骤是 `demo-read`、`demo-view`、`demo-copy`、`demo-return`。完成时的快照步骤是 `demo-complete`。只在教师页已有通过校验、并且画板上至少有一个元素的图时启动。无图、隐藏图或空画板不启动，也不记成跳过或完成。不调用教师画图工具，不读取未提交的学生草稿来编造一幅图。`recorded` 和页面渲染都不算继续。
- 介绍文案说明这一页只读。中英目标句都不含“看懂”“understood”“已经复制”“already copied”。学生点「继续」才进入下一步。缩放数字要先变化，再在不是 1 倍或未适应时发生真实滚动；点当前缩放档位、缩放数字没变、滚动位置没变，都不通过。教师图对象不被修改。退出按钮一直在。
- 点现有的「放到我的几何画板」后，`placeFigure` 把当前图追加到引导自己的练习帧。事件是 `{ type: 'copy', before, after }`。`full` 或 `empty` 不通过，也不把 `copied` 记成 true。不调用 `onCopy`、`copyToGeometry` 或 `appendFigure`，不附文件。几何页在对话框已打开且当前是几何页时显示这个练习帧；学生点「查看可编辑副本」才送出 `{ type: 'view-copy' }`。编辑写回 `practice:v2:teacher-demo`，不写真实几何草稿。退出后仍是真实几何草稿。
- 复制前后，预置的真实几何草稿、真实数量草稿、几何练习记录、`geometry-demo-seen`、附件和发送都不变。进度只写 `baicai-edu-math-board:practice:v2:teacher-demo`。`geometry-demo-seen` 仍可由外壳在打开新图时用来切页，但本章不把它当成完成、跳过或进行中。
- 隐藏图时，现有教师页不再画出「放到我的几何画板」，因为这个按钮只在 `figure` 存在时渲染。引导保持打开，状态是 `teacherDemoFigureUnavailable`，可以退出，稍后点「继续这段引导」。换图后再点复制不通过旧目标。重练对准当前这幅图，从 `demo-read` 开始。不编造旧图。
- 进度与 `geometry-edit` 分开。进入本章不会把几何编辑章标成完成，也不会改写已打开的几何练习记录。另一章还开着时，返回步骤不通过；退出那一章之后，几何页才能显示引导帧。`skip` 不调用 `observe`。跳进返回步骤时可以放入当前图供查看，但不把复制记成完成，也不切页。不一致的存档抛出 `Invalid demo goal`，不自行修补。
- 已勾选的项由章节测试和中英、`mouse`／`touch` 处理器回放覆盖。回放在新文件 [geometry-demo-view.test.js](<../../../math-board/src/teacher-demo/geometry-demo-view.test.js>)，调用的是按钮的 `onClick({ pointerType })`。这不是真实浏览器，也不是真实鼠标或触屏。
- 最后一项未勾。自动回归、构建、`node --check` 和 `git diff --check` 已执行，未测能力写在验证记录里。该项同时要求真实鼠标和触屏设备上的完整路径，这一部分没有做，所以整项不勾。
