# 06: 数量调整与恢复互动章

**What to build:** 学生在数量教程练习中调整新对象的创建颜色、工具箱和视图，撤销/重做、清空，再练习选择是否附带修改记录，理解各操作的真实范围。

**Blocked by:** 02 — 章节导航、续学与补练。

**Status:** ready-for-agent

## 验收条件

- [ ] 覆盖 Q14–Q19，能从目录独立开始、续学、重练，失败可提示、重置、跳过和补练。
- [ ] 切换不同档位后亲手新增对象，核对新对象数值及颜色正确、旧对象不变；反复点击同一档位不能替代有效练习，不新增界面数值编辑功能。
- [ ] 向工具箱加入此前未显示的图案，实际使用后收起；已有对象不消失，至少保留一个工具箱图案。
- [ ] 对明确变化先撤销再重做，分别验证恢复结果；实际改变缩放后回到适应视图，不把不可用按钮或当前档位点击算完成。
- [ ] 有内容时确认清空，只清教程练习中的对象、学生说明、修改记录和撤销历史，且不能撤销回清空前；不影响另一真实画板及附件，不调用宿主清空工具。
- [ ] 清空后明确进入新阶段或提供放入章练习起点，不要求放入空白作品，也不悄悄复活被清空的撤销历史。
- [ ] 实际切换练习中的附带修改记录选项，说明快照与记录是独立附件，关闭记录也可模拟放入；不改真实提交偏好，不产生真实附件。
- [ ] 图案清单、创建颜色、视口、偏好及记录均不写回真实状态；退出/刷新和迟到保存保持隔离。
- [ ] 中英文、鼠标/触屏可完成；自动回归覆盖颜色作用域、图案收起、恢复、清空与选项隔离，记录章节回放并执行相关检查。

## 边界

按规格 Q14–Q19、第 9–11 节验收。不依赖尚未交付的整理或说明章；准备必要练习内容不得算作学生已完成对应任务。
