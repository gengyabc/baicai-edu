# 01: 数量基础教程与安全练习闭环

**What to build:** 学生从教程入口进入独立的数量教程练习，连续完成添加、移动、选择和模拟放入回答；退出后继续原来的真实作答。交付可独立演示的最短完整闭环，而非只提供隔离基础设施。完整自动首开与发布切换由 12 交付。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

## 验收条件

- [ ] 覆盖规格 Q01、Q02、Q03、Q20：成功新增、移动后松手、单选/多选/取消选择、实际触发模拟放入；连续使用前序练习成果。
- [ ] 以本步成功变化及目标状态判断通过；添加失败、原地单击、拖动预览、错误选择集合均不推进；程序预置和之前的事件不冒充学生本步操作。
- [ ] 练习不写回真实对象、学生说明、修改记录、撤销历史、选择、视口、设置或偏好；练习持久化与真实作答分离，后续章节能复用此边界。
- [ ] 所有教程步骤中均不得真实上传、放入附件或发送；放入步骤明确反馈为模拟，其他步骤不能绕过拦截；不改变对话输入框和已有附件。
- [ ] 学生随时能退出；完成、关闭、切页和刷新后正常使用真实草稿，不残留练习状态或迟到保存；不以进入前旧备份覆盖期间合法宿主设置/清空变化。
- [ ] 未达目标给出具体提示，失败不误报完成；本票至少提供安全退出，章节重置、跳过与续学由 02 完成。
- [ ] 鼠标与触屏均能完成，多选不依赖 Shift 或悬停；中英文目标、操作与反馈一致。
- [ ] 为成功、失败、防真实上传、宿主变更和异步保存隔离提供自动回归；实际回放鼠标/触屏闭环并记录结果。受影响运行时变更按现有构建规范重建并运行相关检查，不宣称未做的浏览器验证。

## 边界

只检查操作，不检查数学答案；不读取或上传学生未提交草稿作为诊断证据，不调用宿主清空工具来清理练习。遵循已确认规格第 4、5、9–11 节，不改教学清空授权或提交协议。
