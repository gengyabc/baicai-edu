# 07: 几何构造互动章

**What to build:** 学生通过指定工具亲手创建平行四边形、矩形和中点，再拖动自由点、创建辅助图形，理解构造工具及点的操作差别，不把图形外观当作数学结论。

**Blocked by:** 03 — 几何基础教程与安全练习闭环。

**Status:** ready-for-agent

## 验收条件

- [ ] 覆盖 G06–G09：平行四边形与矩形各自实际完成三点构造，普通多边形或未结束预览不能替代。
- [ ] 学生先选中可用线段或边，实际执行取中点并生成对应派生点；自由落点、工具点击失败或不满足前置条件均不推进。
- [ ] 指定自由点实际移动并松手提交；说明派生点不能直接拖动，不要求以不可拖动对象作为拖动任务目标。
- [ ] 开启辅助线后亲手成功创建辅助角色图形，再关闭；仅切换开关不算完成整个练习。
- [ ] 仅验证指定工具与操作成功，不测量长度角度、不判断平行/垂直/相等/共线，不对学生结论真假或图像相似度评分。
- [ ] 连续复用基本绘制成果，同时支持目录独立开始、续学、重置、跳过、补练和重练；预置条件不冒充学生本步成果。
- [ ] 练习构造、派生点、辅助线状态及撤销历史不写入真实草稿；退出/刷新保持两种真实画板与附件不变。
- [ ] 中英提示及鼠标/触屏均可完成；自动回归覆盖构造成功、非法前置、错误工具和隔离，记录交互回放并执行相关构建和检查。

## 边界

遵循规格 G06–G09、第 9–11 节。只解释工具保证和可操作差别，不新增几何判题能力，不改变原有构造模型。
