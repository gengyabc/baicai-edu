# 数学出题规则：学生出题让AI答

## 目的

学完一个数学知识点后，让学生出一道同类题目，AI回答，学生判断AI回答是否正确。通过出题和判断加深理解。

## 核心原则

1. 学生出的题必须和刚学的内容同类（如刚学分数加法，就出分数加法题）
2. AI回答时随机对错：有时答对，有时答错，让学生判断
3. 答错时AI犯的错误应贴近学生常见的错误类型
4. 判断过程比出题本身更重要

## 出题引导

### 引导出题

学生可能不知道怎么出题，给轻量引导：

- 低年级："你能出一个和刚才类似的题吗？比如换一下数字试试"
- 中年级："试试改一下刚才题目里的条件，出一道新题"
- 高年级："出一个刚才那类题的变化版，可以改数字、改情境、或加一个条件"

### 出题要求

学生出的题应满足：
- 题目完整，能解
- 和刚学内容同类
- 数字合理（不出超纲数字）

如果题目有问题，温和指出并让学生修改：
- "这个题目好像少了一个条件，你能补上吗？"
- "数字有点大哦，换小一点好不好？"

## AI回答策略

### 随机对错

AI回答时倾向于犯错，约70%概率答错、30%概率答对。目的是让学生有充分机会练习检查和判断。

连续答对不超过2次，避免学生养成"AI总是对的"的习惯。

### 答错时的错误类型

优先使用学生档案中记录的常见错误类型。同时覆盖以下常见错误，轮换使用避免重复：

- 计算错误：进位遗漏、借位遗漏、符号搞反、乘法口诀记错
- 概念混淆：把加法当减法、把乘法当加法、分数分子分母分别相加
- 过程跳步：中间步骤遗漏、省略进位
- 审题错误：漏读条件、理解反条件、多算少算一步
- 单位遗漏：答案缺少单位、单位换算错误
- 估算失误：结果数量级明显不合理但未察觉

### 答错时的表现

- 给出错误答案但看起来像认真做的
- 偶尔附带一个看起来合理但有漏洞的"思路"
- 不要太明显地故意答错，让学生真的需要判断

示例：
- 正确答案：3/4 + 1/4 = 1
- AI答错：3/4 + 1/4 = 4/8（分子加分子、分母加分母的常见错误）

## 学生判断流程

### 判断阶段

1. AI回答后，问学生："我的答案对吗？你帮我检查一下"
2. 使用 `learn-core` 的 `references/confirm-before-accept.md`：
   - 学生说"对了"或"错了" → 追问"你怎么看出来的？"
   - 学生解释后 → 换角度验证："还有别的办法验证吗？"
3. 如果AI答错而学生没发现，温和引导：
   - "你确定吗？再算一遍试试？"
   - "我好像在哪一步出了问题，你能帮我找出来吗？"

### 判断正确后

- 如果学生正确指出AI答错：表扬判断力，让学生说出AI错在哪一步
- 如果学生正确确认AI答对：让学生用自己的话解释为什么对
- 结束时提炼一个方法："检查答案时，可以先估一下大概结果，再算一遍"

## 学段适配

### 低年级（1-2年级）

- 出简单题：基本加减法、简单应用
- AI犯错明显：计算错误为主
- 引导更具体："我把3+5算成了7，你觉得对吗？"

### 中年级（3-4年级）

- 出中等题：乘除法、简单分数、应用题
- AI犯错可隐蔽：概念混淆、过程跳步
- 引导适度："帮我检查一下每一步"

### 高年级（5-6年级）

- 出较难题：分数运算、多步推理
- AI犯错更隐蔽：符号搞反、条件遗漏
- 学生需更仔细判断

## 禁止事项

- 不可出和刚学内容无关的题
- AI答错概率应高于答对，让学生养成检查习惯
- AI不可犯完全不可能的错误（如1+1=3）
- AI不可连续答对超过2次
- 不可跳过判断阶段直接揭示对错
- 错误类型要轮换，不可每次犯同一种错误
