# 学生出题与 AI 回答设计

## 出题引导

给轻量提示，让学生自己编一道刚学内容的同类题：

- 低年级：换数字。
- 中年级：改一个条件。
- 高年级：改数字、情境，或加一个条件。

等学生说完，检查题目完整能解、内容同类、数字合理且不超纲。缺条件或数字过大时，温和指出并让学生修改，不替学生出题。

## 先算对，再决定怎么错

先在内部正确解题，再用 `bash` 验算一次（`python3` / `node -e`；不可用时分步手算并复核），之后决定呈现的回答。

- 已确认的技能（数学 memory 的 `learning_memory.confirmed_skills`）上 AI 不犯错；白名单是硬边界。
- 在存在合适非白名单错误时，跨多轮约 70% 答错、30% 答对，连续答对不超过 2 次。当前题若只能在已确认技能上制造错误，则正确回答；比例和连续次数服从白名单边界。
- 答错时优先使用学生 `error_history` / `skill_errors` 的常见错误；没有记录时从下表选择。错误类型轮换，不连续用同一种。
- 错误应贴近当前水平，像认真做出来的；给出答案，偶尔附一个合理但有漏洞的思路。采用可追溯到具体步骤的典型错误，让学生需要计算或检查才能判断。
- 错误答案必须与正确答案可区分，并能指出错在哪一步。

| 错误类型 | 可选表现 |
|---|---|
| 计算错误 | 进位/借位遗漏、符号搞反、口诀记错 |
| 概念混淆 | 加法当减法、乘法当加法、分子分母分别相加 |
| 过程跳步 | 中间步骤遗漏、省略进位 |
| 审题错误 | 漏条件、理解反条件、多算少算一步 |
| 单位遗漏 | 缺单位、单位换算错误 |
| 估算失误 | 结果数量级明显不合理却未察觉 |

例如：3/4 + 1/4 正确为 1，AI 可答 4/8，并用“分子加分子、分母加分母”解释。

## 学段适配

- 1-3 年级：基本加减法、简单应用，错误以较明显的计算错误为主；用具体数字引导判断。
- 4-6 年级：乘除法、分数、应用题、多步推理，错误可用较隐蔽的概念混淆、跳步、符号错误或漏条件；引导学生逐步检查。

设计完成条件：题目有效、正确解已经复核、回答符合白名单与错误轮换规则；若答错，能定位一个具体错误步骤。随后回到 `math-student-problem` 的学生判断与揭示收尾，揭示时机与学生判断反馈由该流程统一执行。
