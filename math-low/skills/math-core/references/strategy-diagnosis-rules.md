# 策略诊断规则

`math-diagnose` 获取证据并回传结论；本文限定观察与推断。诊断是弄清学生怎样理解当前问题，不是逐级测完一张能力表。

## 先限定观察范围

先辨当前题的数量角色、未知量、数域与学生实际动作；选题规则见 `references/problem-design.md`，分数与小数见 `references/fraction-relations.md`。同一学生可在不同题型、运算或数字范围使用不同策略；一次用具体表示不等于整体退步。

| 观察信号 | 可核验的策略证据 |
|---|---|
| 直接建模 | 图形、物品或手指对应情境中的数量与动作，再数所求的集合；需说清数的是哪一部分 |
| 计数策略 | 从某个已知数起，记录增加或减少的步数；确认起点、停止条件，以及答案是末数还是步数 |
| 已知事实 | 能直接提取某个结果；快答、口诀或写出答案本身不说明怎样理解数量关系 |
| 派生事实 | 说明从哪条已知事实，借拆分、合并、倍数或补偿得到新结果；与直接记忆分别描述 |
| 关系重述 | 能把所求量与已知量联系，用补足、逆运算或部分整体等关系解释自己的解法 |
| 等量组 | 同时追踪组数、每组量和总量；分清求几组还是求每组多少，答案含义与单位一致 |
| 位值 | 十或百能作为单位计数，也能拆回小单位；重新分组后知道总量不变 |
| 对提示的响应 | 区分学生原有思路、教师给出的部分，以及学生提示后自行完成的步骤 |

工具外观不决定阶段：手指可代表物品，也可记录计数步数；画图同样可记录分组、派生关系或中间过程。只追问当前无法分辨的一处，未涉及项留作未知。

## 分物策略的判据

沿用共享 schema 的四个分数字段取值，只描述当前等分任务的协调方式，不作为等值、比较或运算的先修门槛。

| 取值 | 关键证据 |
|---|---|
| `equal_sharing_no_coordination` | 只满足各份相等或全部用完之一；尚不能协调二者 |
| `equal_sharing_nonanticipatory` | 先对半或试分，再调整，最终能让每人一样多且分完；尚未预先关联人数与切法 |
| `equal_sharing_additive` | 预先把一件或一组物品按人数等分，再累加每人所得；能解释多块合计的份量 |
| `equal_sharing_multiplicative` | 直接协调总量与人数，把每人份量看作商，并能展开说明为什么，不只是套用 a÷b=a/b |

若2人或4人分物答对仍无法判断协调方式，可选一个非纯对半的近邻题补证；不是每次必测。图画多少、分数是否最简、是否会写符号或会命名都不能单独定阶段。

## 分数与小数的额外观察

- **单位与等值**：辨明整体、单位分数、几个这样的单位；是否能解释再细分后块数改变而份量不变。单块大小与总份量分别核对。
- **部分组**：同一剩余量占一个物品多少、又占一组多少，可能不同。分数除法答错先检查这两个单位，不直接归因于忘记倒数。
- **小数单位化**：能否双向联系1与10个0.1、0.1与10个0.01；整数位值与分数关系各自取证。未涉及的小数理解留作未知，不硬塞进一个分物阶段。
- 只会一种除法含义，不自动推定另一种；用实物分配正确却暂不会命名，优先记录表达缺口而非概念错误。

## 卡点与错因

提示无响应先按 `learn-core` 的 `references/guidance-non-response-handling.md` 探查。若已有具体矛盾，指向该步骤或数量问学生怎样想；只在学生确已认同自己算错时问错在哪里，避免预先判错。

| 类型 | 有实际证据时记录 |
|---|---|
| `calculation` | 数量关系正确，但计数、事实提取或运算步骤发生错误 |
| `concept` | 单位、等量、数量角色或运算关系混淆；解释无法满足题意 |
| `process` | 漏掉条件、未完成所需步骤，或所答不是未知量；简短表达本身不是错误 |
| `estimation` | 已明确的范围或数量级与结果冲突，学生未能协调 |

先保留学生的解释，再核对实际步骤。结合历史区分偶发与重复，`diagnosis.label` 细化到具体错误，`diagnosis.evidence` 只写关键动作或理由。教师方法不同、未发现教师示例里的错误、沉默或尚未回答都不足以记录学生错误；须有其实际错误判断或推理。

## 保守结论

- `strategy_summary` 写当前题型/未知量与实际动作，给一个可立即尝试的 `next_target`。阶段不明时保留未知或原值，从已有可独立行动的题、同结构低负荷题补证，而非强制回到摆全量。
- `current_levels` 只更新有策略证据的 `arithmetic_strategy_stage` / `fraction_strategy_stage`；共享枚举不变。阶段是压缩摘要，题型与数域差异留在策略描述中，不推定全局逐级过关。
- `confidence`：`low` 仅有自述或含混表现；`medium` 一次清楚的策略展示但稳定性待验证；`high` 多个独立任务中的关键证据一致。记住一个事实与灵活关系运用分别判断。
- 完成条件：每项结论都有对应证据或明确未知，提示后的表现未冒充独立表现，且只有一个下一步；取证足够就停止追加测验。

阶段、标签与内部字段留在内部。学生可见的是一处已观察到的想法和一个具体问题或下一步。
