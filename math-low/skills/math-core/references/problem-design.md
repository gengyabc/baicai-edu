# 按数量关系选题

## 选当前一题

1. 从显式目标或已有证据确定要观察的一处关系；年级与阶段只提供起点，学生已经能做的题不按默认年级降级。
2. 在内部辨明各数量的含义、已知量、未知量与单位，再选择情境和数字。教学分类用于教师选题，给学生的是自然的问题。
3. 保持情境可理解，数字允许学生从已有知识起步；出题时保留方法选择，等学生尝试后才决定是否支架。

完成条件：题目关系完整、未知量明确、有学生可进入的路径，且未在题干或配图中预先安排算法。纯算式目标可直接出算式，需要解释数量意义时再引入情境。

## 加减法

| 结构 | 需区分的未知量 | 选题关注点 |
|---|---|---|
| 加入 | 原有、增加、结果 | “原有5，又来一些，现有8”与“原有一些，又来5，现有8”不是同一任务 |
| 拿走 | 原有、拿走、剩下 | 问拿走多少与问剩下多少，学生需要追踪的量不同 |
| 部分与整体 | 整体或一个部分 | 静态组成关系可用合并、分开或补足理解 |
| 比较 | 较大量、较小量或差 | 分清谁和谁比，差是两者相差的量，不是某一堆的总量 |

- 理解依据是情境中的关系，不是“多就加、少就减”等词语匹配。
- 学生可以用加法求差、试数找原量、匹配两堆等；检验是否满足关系，而非是否采用教师预期运算。
- 一道结果未知题的成功不代表同数字的起始量未知题已会。变式时说清本轮是稳定同一关系，还是有意改变未知量。

## 乘除法与余数

| 已知 | 未知 | 需要观察 |
|---|---|---|
| 组数、每组量 | 总量 | 能否同时保留组数和每组量 |
| 总量、每组量 | 组数（包含除） | 按每组量组成多少组，答案数的是组 |
| 总量、组数 | 每组量（等分除） | 组数固定、各组相等，答案是每组多少 |

- 先看学生是否能表示等量组；逐个分、反复加减、跳数、已知乘法事实都可成为解法。理解具体分组不以背口诀或会写乘除符号为前提。
- 数学上交换因数可得相同积，但情境中“几组”和“每组几个”的角色仍需分清；对等价算式追问含义，不按书写顺序判错。
- 余数如何处理取决于对象与问题：可保留、只计完整组、需要额外一组、问剩余，或允许分割成分数。出题先明确可否分割；验证结果时回看实际要求。
- 等量组能理解后，可扩展阵列、面积、倍数或测量情境；按当前证据选一种，不把所有乘法情境都预画成阵列。

## 位值与多位数

- 从可理解的成组数量进入“一个十既是一组，也是十个一”。观察能否在整组与单个之间来回解释，不以读出数位名称代替理解。
- 学生自己的组合、分步增减、补偿或标准算法都先按数量关系检验。用组十材料时，确认其含义；给材料不等于示范算法。
- 对重新分组，关注总量是否保持，例如42可表示4个十和2个一，也可表示3个十和12个一。学生有相关步骤时再追问，避免预先替他选拆法。
- 数字变难后回用实物是合理的意义建构，不自动记为退步。标准算法可以讨论，但每步要能与学生理解的数量或运算联系。

## 只改变一个主要挑战

按本轮目的改变数字关系、未知位置、情境或表示之一，其余尽量保持；不是所有题都只需增大数字。

- 稳定：保持关系，换一组近邻数字，允许原办法继续有效。
- 扩展：选有利于察觉关系的数字，如同一个加数的近邻、接近整十或两数很接近；用作机会，不宣布学生必须用什么策略。
- 连接：沿学生已提出的关系换一个问题，或用开放等式检查关系是否仍成立。明确目标可突破年级默认，但保持可进入的小步。

完成条件：学生有机会展示目标关系；若题目过难，依据具体卡点缩小数量或澄清情境，而不是顺手把关键关系和解法一起说出。
