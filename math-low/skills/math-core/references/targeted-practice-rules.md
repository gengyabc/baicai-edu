# 按证据选择练习

`math-practice` 执行与回传；本文统一目的、题量与调整。

## 只选当前目的

四类沿用层名，不是等级或必经顺序。一次一题；题量为上限，不补配额。

| 目的与证据 | 设计 | 上限 |
|---|---|---|
| 第1层 诊断：起点/错误模式待查 | 查重复错误保持结构与未知量、换近邻数字；查数量角色可只改未知位置，按新题型解释证据 | 1–2题 |
| 第2层 对比：需看清一处差别 | 学生办法与明确标注示例；可比有效办法或错误步骤，只问一处关系 | 1题 |
| 第3层 变式：独立关系未稳或要求多练 | 保持关系。其中一题主改生活场景，数字与未知位置近邻，检验能否迁到新场景；只换数字、沿用同一故事不算迁移 | 2–3题 |
| 第4层 连接：已有知识能支持当前学习/纠错 | 联系确已知道的事实、单位、关系，用相关题/开放等式解释联系 | 1–2题 |

连接不要求先计算稳定；对比不限纠错，有独立办法且愿比较再引另一表示。理解示例与独立运用分别取证。

## 设计当前题

- 读 `references/problem-design.md` 定数量角色、未知量和一个主要挑战；分数/小数另读 `references/fraction-relations.md`，按单位与数字关系选数，不只看数大。
- 阶段不指定算法，也不把某个策略阶段设成下一内容的关卡。
- 偏好改呈现：视觉提供图具不规定画法；计算偏好可在生活故事里更早给出算式，诊断数量角色、情境、余数时故事仍保留动作和所求。题干按 CGI 写成一段日常生活故事，场景更换与迁移取证见 `references/problem-design.md`。学生做不出当前题时，兴趣桥见 `references/math-personalization.md`。
- 年级调整语言/表达负担，表现决定负荷；乘除具体情境与关系不以符号名称为前提。
- 错误对照标为待检查示例，同轮澄清正确结论；学生未判断不算错误。

完成条件：一个目的、明确问题。题干是故事和问句，未预先展开算法或摆法。

## 逐题调整

1. 出题时，本场未完成的题最多一句接上，然后是故事和问句，问句后面不再加句子。新的 `session_id` 直接给新故事。思考题普通文本，流程选择按共享协议。
2. 回答后复用策略细节，按共享确认协议补缺口，可沿同一表示验证，不强制换法。
3. 连错时找具体关系或计算卡点，按 `references/math-teaching-core.md` 的「最小介入」处理当前题，不机械退层。下一题可以换近邻数字或重选目的；不在当前题里改数字、换场景或指定工具。没有可继续的办法时，才用兴趣桥重述同一题。嫌麻烦/短答非错误。
4. 证据够即停；到上限仍未知则记录未知/局部卡点、返回主线，不追加或宣告掌握。

完成条件：诊断辨明推理，对比说明差别，变式有换场景后的迁移证据，连接展示联系；有缺口也可如实结束。只在原场景做对，变式目的仍未完成。

收束用一句已展示关系/待解步骤，下一目标取一个近邻；不要求背方法句，不计时排名，不以更快/更抽象为唯一成功标准。
