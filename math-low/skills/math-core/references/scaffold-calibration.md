# 数学支架校准

## 按证据介入

目标是让学生继续自己的推理，不是让学生完成教师预设的步骤。以下是分支，不是逐级必走的提问清单；每次只取当前需要的一项，然后等待。

| 当前证据 | 当前动作 | 留给学生的工作 |
|---|---|---|
| 只说“太麻烦、太慢” | 承接感受，开放邀请：“你想怎样让它省事一点？” | 决定是否调整、调整什么 |
| 明确求助，但卡点不清 | 问已做到哪里或哪一步卡住；已有说明就直接使用 | 展示现有想法，而非猜教师要哪种算法 |
| 情境或数量角色混淆 | 请学生用自己的话说情境，或指出图中某个数量 | 把数量与动作对应起来 |
| 已有部分方法，某处卡住 | 指向那一处表示或关系，问一个具体问题 | 补足自己的下一步 |
| 理解情境，却找不到起点 | 提供一种可选工具，或保留结构、缩小数字；二者选一 | 自己组织表示和计算 |
| 学生主动尝试新办法 | 请他说明新出现的一步，再据其推理验证 | 解释并决定是否继续使用 |
| 学生明确要求示范，或针对卡点的支持后仍需示范 | 把一个局部思路明确作为“一个可选办法”展示，再请学生解释或续做 | 理解这个局部，并决定如何接下去 |

一次提示后能继续就撤去支架。需要再次介入时以新表现为依据；连续卡住交诊断，持续无回应按共享协议处理。学生拒绝帮助时保留自主尝试的空间。

## 透露多少

强度按**替学生作了多少数学决策**判断，而非字数或句数。

- 优先问学生已有的图、数或动作；用他自己的拆分与记号作追问起点。
- 新拆分、跨十中间数、先后运算顺序都属于数学决策。只有学生已提出，或进入明确示范分支时，才把它们给出来。把教师选定的拆分写成问句仍是强提示。
- 工具用来减轻记录和操作负担，使用方式留给学生设计。视觉偏好不等于必须画全量；阶段估计也不等于指定算法。
- 局部示范只展开当前卡点，留待学生解释、尝试后再继续；即使学生请求示范，也不一次发出整条路线。
- 学生沿示范做出下一步，记录为有支持表现；独立选择或迁移另取证。

发送支架回复前的完成条件（仅用于继续教学）：有一处来自学生的依据或明确求助，有一个本轮待答问题，学生仍拥有一个实质的数学选择。示范分支还需明确哪些内容由教师提供。

## 对照场景

用于修改技能后的行为审阅；示例是强度边界，不是固定话术。

| 输入与已有证据 | 合适的下一回合 | 越界信号 |
|---|---|---|
| 23−8，学生只说摆圆太麻烦 | 承接感受，问他想怎样省事，然后等待 | 立刻给出 23=20+3，规定先拿走3；或继续要求摆满23个 |
| 同题，学生明确问“给我一点提示”，没有拆数证据 | 一个可选工具或一题更小的同结构问题，保留方法选择 | 用“先减几才能到20？”暗中指定跨十路线 |
| 学生自己说“先拿走3，剩20” | 问“你已经拿走的3，和要拿走的8有什么关系？” | 直接代算剩余要拿走的数量 |
| 15−6，画板已划去6、留下9；学生说从头数剩下的圆 | 承接其直接建模，验证只补未说明的关系 | 再问为何摆15个，或用“一定要全摆吗”推动换算法 |
| 学生说“我会心算，只是不想说” | 降低表达负担，让其展示自己的一小步 | 因表达短而退回逐个摆数 |
| 学生自己提出倒数，或用一个图形表示20 | 沿其办法继续；含义不清只澄清表示 | 重定向到教师选定的拆数路线 |
| 学生说“我还是想一个个画” | 接受其选择，让其继续 | 反复追问怎样更快，制造换策略的压力 |
| 分物题，学生只分出整份，剩余未处理并求助 | 指向剩余物，问怎样处理才能仍然一样多 | 直接规定每块切成几份、每人拿几份 |
| 学生要求看示范 | 明确给一个可选的局部思路，再等待解释或续做 | 把拆数、运算顺序和结果一次讲完 |
