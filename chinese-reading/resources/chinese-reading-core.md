# 语文阅读规则

先证据后结论，区分字面事实与推断。赏析默认检查本义与语境义/表达效果；作用题绑定本文对象、情境、结构与主题，作者意图必须能回溯原文。

## 常见问题与纠偏

诊断定义与标签只用 `references/chinese-error-labels.md`；本表提供纠偏动作。

| 问题 | 纠偏 |
|---|---|
| 单层赏析 | 从本义追到语境中对描写对象的表达效果 |
| 空泛模板 | 把“生动形象”“承上启下”落实为本文的具体描写、承接/开启内容及主题作用 |
| 概括偏差 | 核对关键事件/结果，补遗漏、去枝节，按文本类型整合 |
| 作者意图误判 | 回文找作者态度与表达依据，不用学生自己的生活感想替代 |
| 细节功能忽视 | 回查指代对象、标题层次、标点与关联词逻辑 |
| 只会背答案 | 选下表一种方法实际解读，不以“多读多写”代替工具 |
| 同错反复 | 以 `error_history` 回看有证据的重复诊断；未能归类先补证据 |

## 薛法根文本解读法

一次只选一种，用学生听得懂的话提问，不先报方法名。

| 方法 | 用途 | 提问焦点 |
|---|---|---|
| 提领法 | 抓不住重点 | 找牵动全文的词句，说明为何选它 |
| 还原法 | 只知写什么，不知为何这样写 | 比较文学形象与日常真实的反差 |
| 原型法 | 概括或结构困难 | 目标 → 阻碍 → 努力 → 结局 |
| 见人法 | 情感、人物或意境困难 | 透过人事景物看作者的风格、处境与情感认知 |
| 降维法 | 不明白写法之妙 | 对比常态写法，解释作者选择的效果 |
| 要素法 | 结构或单元学习目标 | 找统编教材语文要素在文中的落点 |

见人法中确认生活经验缺口后，按 `chinese-core` 的“内部动作”执行经验桥接，再接回见人法或双层赏析；不独立记录桥接回合。

## 文本层次与能力检查

由表层字面、里层情感到深层风格/艺术，按当前目标选择，不强制每篇走全：

- 信息：提取与概括，按文本类型调整策略。
- 细读：双层赏析、修辞效果、指代与关联词。
- 结构：开头/结尾/过渡作用、线索顺序、标题多重用途。
- 文学要素：人物、场面、环境的作用，由细节连接意图、情感、风格与主题。

## 诊断流程

1. 齐备题目、原文与学生答案，按题型确定需检查的意思、结构或意图。
2. 将答案与原文关键词句逐点对照；作者意图同样由证据推断。
3. 定位具体失分点后按标签表选一个主标签；证据不足先补问。
4. 给直指失分点的小步任务，以学生自行回文并修正为完成条件。回合与记录由 `chinese-reading-session` 负责。
