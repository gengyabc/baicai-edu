# 语文学习推荐

`learn-recommend` 经学科契约读取本文件。这里只决定候选、难度、理由和排序；选择与交接归共享流程。

## 候选：目标—证据缺口—任务

用最新阅读答案、写作片段及快照核对 `priority_targets`、`developing_topics`、`error_history`、`session_history` 与 memory。区分独立表现、支架后表现、自述与待验证建议；旧标签不覆盖实际修正，无记录时给低负荷探索。通常给 2–3 个有区别的小目标，首选一个；证据不足则少给，不凑读写配额。不预先发题或代答。

| 当前表现 / 缺口 | 可开始的小任务 |
|---|---|
| 概括漏关键结果 | 找目标、阻碍和结局，合成一句话 |
| 人物判断无依据 | 找两处动作，解释如何支持判断 |
| 赏析只说「生动」 | 对比普通写法，说清在本文中多表达了什么 |
| 作文没有定格 | 选自己的一个瞬间，用两个准确动作展开 |
| 有定格但空泛 | 补一处可观察的声音、表情或旁人反应，保留原意 |
| 有细节但结尾空喊 | 让结尾回到一个真实细节 |
| 已理解原文且提炼了写法 | 换一个生活主题，只用该写法写一小段 |

首选学生已有支点、能补主要理解或表达缺口的一步；不先堆修辞或模板。`active_domain` 和旧下一步不锁定推荐顺序。只用现有材料或选定后可提供的短材料；原文缺失就推荐同类新短文，不假装能继续讲原文。明确换内容时优先换材料或领域，可保留有用的小目标。

阅读按 `references/chinese-reading-core.md` 一次选一种方法；经验缺口只据实际表现。写作与迁移门槛按 `references/chinese-writing-core.md`，不强行填六圈，未理解或无可用写法不强推迁移。按 `references/chinese-grade-defaults.md` 调文本长度与问题层数，`material_difficulty` 一次只改一个负荷因素；兴趣与偏好按 `references/chinese-personalization.md` 选材料，不当作能力证据。

## 理由与完成

理由用学生能懂的中文，连接真实表现与具体下一步。如：「你上次已经判断人物很勇敢，这次找出支持它的动作，就能把想法说得更有根据。」没有记录就说这是可尝试的方向，不补写往绩。每个候选有可追溯的依据与一个可开始的小任务；推荐不确认技能、不新增诊断。
