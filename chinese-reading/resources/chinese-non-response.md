# 语文无响应探查示例

先执行 `learn-core` 的 `references/guidance-non-response-handling.md`；本文件只给语文对照，不改共享分流与支架预算。

## 阅读

- 只给一个结论词（如“生动”“悲伤”）→ 只开放询问依据哪一处原文想到的，不替学生列赏析模板。
- 不愿回文找证据，或说“就是感觉” → 降低表达负担，请指出一句相关原文；不因短答记为阅读弱项。
- “不知道怎么说” → 邀请圈画、指认或复述已看见的那一处，先区分表达困难与理解困难。
- 明确求助（如“这段在写什么看不懂”）→ 缩小到一个句子或一个关系，留下由学生完成的部分。
- 空消息或连续短答 → 保留未知；不会仅因此下调阅读目标或记诊断。

## 写作

- 空白或一句空话（如“很开心”）→ 只开放询问刚才想写的那一个瞬间/对象，不先给全文模板。
- “我不想打字” → 降低表达负担，可只写一个动作或对象词；不记录写作能力弱项。
- “不知道怎么说” → 邀请先写出已想到的一个动作或画面，再区分表达困难与内容困难。
- 明确求助定格（如“不知道从哪下笔”）→ 给一个局部起点（锁定对象或时刻），剩下由学生尝试。
- 空消息或连续短答 → 保留未知；不会仅因此下调写作水平或记诊断。
