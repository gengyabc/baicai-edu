# 经验缺口桥接

## 确认范围

仅作为 `chinese-reading-session` 的内部子流程，复用其已验证的会话与快照。若被单独加载，交回阅读教学确定目标与会话；没有 `session.json` 或 `student_id` 为空时先引导 `/start`。

接收当前文本或片段、核心情感/意境/人物处境、学生理解状态，以及至少一处可回文验证的证据。先确认目标是建立感受再理解表达；以下情况交回阅读教学换方法：

- 事实说明文、知识性文本或纯信息提取。
- 唯一目标是答题技巧或术语训练。
- 学生已有充分相关经验，能自然进入文本情感。
- 战争、死亡、重大苦难等高风险创伤主题。

## 读取规则

| 条件 | 加载并读取 |
|---|---|
| 需要见人法或文本层次细节 | `chinese-core` 的 `references/chinese-reading-core.md` |
| 选择个性化替代经验前 | `learn-core` 的 `references/prestart-settings-interpretation.md` |
| 开始桥接提问前 | `learn-core` 的 `references/personas.md`：Guided Coach，追感受时叠加 Socratic Tutor，一次一问 |
| 学生不回应或只答一个词 | `learn-core` 的 `references/guidance-non-response-handling.md`：改说法、举例、拆步骤，最多 3 次；仍进不去则停止 |
| 出现自伤、被伤害、被欺负、家里危险或不想活的信号 | `learn-core` 的 `references/llm-safety-boundaries.md`：立即停止桥接和教学，执行危机流程，不把细节写入档案 |

加载 skill 后，按返回的 base directory 定位其 references。

## 桥接

1. 判断经验缺口：只能复述内容、套术语或给空泛情感词时，用一个低风险问题核对是否缺少相关经验；确认是经验障碍才桥接，词义或结构障碍交回阅读教学。
2. 锁定一个需要被感受到的情感处境，并标出将回读的原文证据；两者明确后才选择替代经验。
3. 选择替代经验，必须同时满足：
   - **可进入**：日常经验，不依赖强烈或特殊经历。
   - **低风险**：不涉及隐私、痛苦或家庭冲突。
   - **情感对应**：共享情感结构，而非仅表面相似。
   - **可回溯**：能指出它为什么帮助理解当前文本。

   优先用 `personal.interests`、喜欢的活动/物件/宠物、熟悉角落、被陪伴或舍不得事物的日常感觉。Prestart 个人经历只作轻量桥梁，用完立即回文。任一条件不满足就换经验或停止桥接。`personal.most_sad_event` 仅在学生主动提起时用一句轻桥，立即回文；不主动取材、追问或复述家庭信息与难过经历。
4. 用简短提问请学生说自己的感觉，等待回应；他愿意表达并能说出感受后再建立对应，抗拒或不适按停止条件处理。
5. 指出该感受与作者/人物处境共享的情感结构，同时保留两种经历的差异；学生认为贴切后立即回文，不贴切则换经验或停止。
6. 立即回到原文，请学生指出支撑该感受的句子、画面、对比或细节。个人经验不替代文本证据。
7. 学生能自行表达作者/人物感受，并指出至少一处原文证据后，才算桥接完成；需要时再补术语、表达作用或写法分析。技巧服务于理解。

出现牵强（学生进不去或觉得“不像”）、偏离文本且回不去、抗拒分享/不适/沉默、高风险创伤主题，或情感结构只有表面相似时，立即承认桥接未成功，换方法或直接讲解；危机信号优先执行上表安全流程。

## 返回阅读教学

只返回内存结果，不生成 `session_segment`、独立诊断或会话记录，不写学生数据：

- `status`：`bridged` / `stopped` / `safety_stop`。只有学生自行表达感受且找到至少一处原文证据才用 `bridged`。
- `bridge_summary`：一句话说明替代经验与共享的情感结构，仅保留必要教学信息，不复述隐私。
- `student_feeling`：学生感受原话，保留他的用词；未说出留空。
- `text_evidence`：学生指认的原文句子或细节；未找到留空，不以类比替代。
- `stop_reason` / `next_action`：失败时给具体信号与换方法/直接讲解建议；危机只回传需安全处理，不传创伤细节。

调用方接回见人法或双层赏析，将有效证据并入唯一阅读段，再判断诊断与技能追踪；失败不算掌握，安全停止优先。
