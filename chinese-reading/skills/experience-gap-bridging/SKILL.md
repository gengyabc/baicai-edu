# Skill: 经验缺口桥接

## Purpose

当学生缺少与文本情感对应的人生经历时，不从术语和技巧切入，而是先寻找学生可进入的替代性生活经验，帮助学生建立情感对应，再回到文本理解作者或人物的感受、意境与表达选择。

## When To Use

- 文学文本的核心难点在于情感、意境或人物处境理解
- 学生能说出字面内容，但明显"进不去感觉"
- 学生缺少与文本对应的直接经验
- 当前目标是先建立感受，再进入表达理解或技巧分析

通常在 `chinese-reading-session` 的 learn 模式或 diagnose 模式下触发：当见人法卡住、学生只会套情感词时，由阅读教学 skill 调用本 skill，桥接完成后交回阅读教学继续。

## Session Gate

本 skill 仅作为 `chinese-reading-session` 的内部子流程，复用其已验证的会话与快照，不从语文路由独立进入。若被单独加载，交回阅读教学先确定目标与会话；没有 `session.json` 或 `student_id` 为空时先引导 `/start`。

## When Not To Use

- 事实说明文、知识性文本、纯信息提取任务
- 当前任务的唯一目标是答题技巧或术语训练
- 学生已经具备充分相关经验，并能自然进入文本情感
- 主题涉及高风险创伤场景，如战争、重大苦难、死亡等，需要更谨慎的方法

## Required Inputs Or References

- 当前文本或片段
- 文本中的核心情感、意境或人物处境
- 学生当前的理解状态
- 至少一处可回到原文验证的文本证据

需要阅读规则细节时，加载 `chinese-core` 并读取其 `references/chinese-reading-core.md` 的见人法与文本层次部分；加载结果会给出 base directory，按 `<base_directory>/references/chinese-reading-core.md` 读取。

需要个性化输入时，加载 `learn-core` 并读 `references/prestart-settings-interpretation.md`：优先用 `personal.interests`、日常物件、熟悉的角落；`personal.most_sad_event` 只在学生主动提起时轻度使用，不主动问。

## Process

1. 先判断是否存在经验缺口。
   - 如果学生只能复述内容、套用术语、给出空泛情感词，通常说明还没有真正进入文本感受。
2. 提炼当前文本最核心、最需要被感受到的情感处境。
   - 只抓一个小目标，不要同时讲多个情感层次。
3. 选择替代经验。

### 替代经验选择标准

替代经验必须满足以下全部条件：

1. **学生可进入**：日常经验，不需要强烈或特殊经历
2. **低风险**：不涉及隐私、痛苦、家庭冲突
3. **情感对应**：与文本核心情感有相似的情感结构，而非仅表面相似
4. **可回溯**：选择后能明确指出"为什么这个经验能帮助理解"

优先从 `personal.interests` 和日常经验里选，如：
- 学生喜欢的活动、物件、宠物
- 熟悉的角落
- 被陪伴的感觉
- 舍不得的事物

不要从 `personal.most_sad_event` 里主动取材；学生自己提起时，只用一句轻桥，马上回到文本。

**不符合上述任一条件时，应停止桥接或换一个替代经验。**

4. 用简短提问把学生带入替代经验。
   - 先让学生说出自己的感觉，不要立刻替他说结论。
5. 把学生刚说出的感觉桥接回作者或人物处境。
   - 明确指出两者之间共享的情感结构，而不是说它们完全相同。
6. 立刻回到文本证据。
   - 问学生：文中哪些句子、画面、对比或细节，能看出这种感觉？
7. 最后才在需要时补充术语、表达作用或写法分析。
   - 技巧服务于已建立的理解，不替代理解本身。

## Output Requirements

- 学生能够用自己的话说出作者或人物的感受
- 学生能指出至少一处原文证据支撑这种理解
- 输出应体现"先带入，再回文，再总结"的闭环

## Stop Conditions

遇到以下情况应立即停止继续桥接，改用更谨慎或更直接的方法：

### 失败信号

1. **替代经验牵强**：学生无法进入或明显感到"不像"
2. **对话偏离文本**：变成无边界聊天，无法回到原文证据
3. **学生抗拒分享**：对个人经验表现出明显不适或沉默
4. **主题超出范围**：涉及战争、死亡、重大苦难等高风险创伤场景
5. **情感结构不对应**：发现替代经验与文本情感只有表面相似，没有真正对应

出现任一失败信号时，应承认桥接不成功，改用其他方法或直接讲解。

如果学生提到自伤、被伤害、被欺负、家里危险或不想活，停止桥接和教学，按 `learn-core/references/llm-safety-boundaries.md` 的危机流程处理，不把细节写进学生档案。

## Non-Goals

- 把所有文学教学都变成情感带入
- 用个人经历替代文本阅读
- 强迫学生分享隐私或痛苦经验
- 跳过文本证据，直接输出情感结论
- 把本技能扩展成高风险创伤主题的通用方法

## 语气与支架

- 用 `learn-core` 的 Guided Coach 语气；需要追感受时叠加 Socratic Tutor，一次只问一个。
- 学生不回应或只给一个词时，按 `learn-core` 的 `references/guidance-non-response-handling.md` 改说法、举例、拆步骤，最多 3 次；仍进不去就停止桥接。
- 不把学生的家庭信息、难过经历主动复述；Prestart 里的个人经历只在搭桥时轻量使用，用完立刻回到文本。

## 返回调用方

桥接本身不单独成为一轮教学；结束时把下面三件事交回 `chinese-reading-session`：

1. 用一句话说明用了哪个替代经验、桥到了哪种情感结构。
2. 学生自己说出的感受原话（尽量保留他的用词）。
3. 学生指认的原文证据（句子或细节）。

调用方据此继续阅读教学（回到见人法或双层赏析），并把这些内容并入它自己的 `session_segment`，不要重复记录。

### 桥接结果契约

只向阅读调用方返回内存结果，不生成 `session_segment`、独立诊断或独立会话记录，不写学生数据：

- `status`：`bridged` / `stopped` / `safety_stop`。
- `bridge_summary`：替代经验与情感结构的简述；仅保留必要教学信息，不复述隐私。
- `student_feeling`：学生已说出的感受原话；未说出留空。
- `text_evidence`：学生指认的原文证据；未找到留空，不以类比替代。
- `stop_reason` / `next_action`：失败时给具体失败信号与换方法/直接讲解建议；危机仅回传需安全处理，不传创伤细节。

只有学生能自行表达感受并指出至少一处原文证据才算 `bridged`。调用方在自己的唯一阅读段中合并有效证据，判断诊断与技能追踪；失败不算掌握，需停止教学的安全信号优先处理。
