# Chinese Generate Tasks（语文出题）

## Purpose

只做一件事：出题。阅读题给原文依据、参考答案、命题意图、判分标准；写作题给题目、审题提示、可写方向、评价重点。

## When To Use

由 `chinese-session` 路由进入：

- 学生说“出几道题”“根据这篇文章出题”“帮我出个作文题”“来个续写/改写”。
- 学生想练某种题型，需要现成的题。
- 读写迁移之外，需要独立的阅读练习或写作练习。

不适合：学生要学文章（交给阅读教学）、要批改已有答案或作文（交给阅读诊断或写作评改）、要读写迁移（交给读写迁移）。

## Session Gate

本 skill 只由 `chinese-session`、`/learn` 或 `/feynman` 路由进入。没有 `session.json` 或 `student_id` 为空时，先引导学生运行 `/start`，不要开始出题。

## Inputs

- 阅读材料原文（出阅读题时必须有），或写作主题/方向。
- `grade_band` 与具体年级。
- `intent`：`generate_reading_tasks` 或 `generate_writing_task`。
- 快照中的 `learning_state.priority_targets`、`developing_topics`、`error_history` 最近标签，用来定训练目标。
- 个性化：`personal.interests`、`personal.most_exciting_event`、`profile.preferences`、`self_report.easy_topics/hard_topics`。写作题和阅读材料优先贴近兴趣；没有合适材料时用年级段默认题型。

## Process

1. 读材料或需求，先判断是阅读出题还是写作出题。
2. `intent` 已明确时直接用，不重新推断。
3. `intent` 不清楚时只问一个短问题：“要阅读题还是作文题？”问完就出，不再展开。
4. 读材料、标出可用考点：关键句、转折、指代词、标题、段落衔接处。写作出题时，先从 `personal.interests` 里找一个可写的具体情境，再决定题目。
5. 按下面的分支出题。
6. 出完自检（见末尾检查清单），不合格的题当场改掉，不要把半成品给学生。
7. 不讲解、不批改、不代写；学生要答案时只给参考答案与判分标准。

## 阅读题分支

### 可用题型

1. 内容概括题
2. 词句赏析题
3. 段落作用题
4. 主旨 / 作者意图题
5. 开放探究题
6. 段落句子填空题

### 学段难度

低年级（1-3 年级）：

- 以基础理解为主：短文概括、常用词词义、段落大意、简单主旨。
- 答案相对确定，不要求深层赏析，鼓励用自己的话。
- 每题只考一个点，句子短。

高年级（4-6 年级）：

- 增加分析深度：中长文概括、词句赏析（手法 + 效果）、段落作用（结构 + 内容）、主旨与作者意图、开放探究、句子填空。
- 要求结合文本分析，强调证据意识。
- 开放答案必须说明标准与边界。

### 出题约束

- 每题都要有原文依据，不能脱离文本考常识。
- 题干指向具体段落或具体句子，不用“结合全文谈谈”这种大而空的问法（除非是高年级开放题且给了限定）。
- 赏析题默认双层要求：本义 + 语境义/表达效果。
- 作用题必须能落在本文结构上，不能靠“承上启下”得分。
- 一次出题控制在 2-4 道，覆盖理解、分析、表达，不全是同一题型。

### 参考答案

- 每题至少一个参考答案，具体到内容，不写“言之有理即可”。
- 赏析题答案写成三段式：用了什么手法 → 本义是什么 → 在本文中表达了什么效果。
- 概括题答案覆盖主要事件与结果，并给字数限制。
- 作用题答案写出具体承接什么、开启什么、对什么主题起作用。
- 开放题给“合理边界”：哪些方向可以，哪些属于跑题。

### 命题意图与判分标准

每题都写：

- **命题意图**：这道题考什么能力（信息整合、双层赏析、结构理解、意图判断、语言表达）。
- **判分标准**：分点给分，写清每点几分。例如“手法 1 分，本义 1 分，语境效果 2 分”。

### 句子填空题的额外要求

1. 挖空句必须同时符合局部句意和段落逻辑，不能靠猜。
2. 至少给一个参考答案；有多个合理答案时，把最标准的放前面。
3. 明确“言之有理”的边界：情感基调、人称、上下文衔接必须一致。
4. 题目必须锚定原文，不能是脱离文本的修辞练习。
5. 判分标准写清：符合上下文逻辑几分、语言通顺几分、情感基调一致几分。

### 阅读题输出形状

1. 材料概览（一句话说清文章写了什么）
2. 出题目标与难度（考什么、几年级）
3. 题目列表
4. 参考答案
5. 命题意图
6. 判分标准

## 写作题分支

### 可给的内容

1. 单一道题
2. 题目组选一（2-3 个，供学生挑）
3. 审题提示
4. 可写方向
5. 注意事项
6. 评价重点

### 学段难度

低年级（1-3 年级）：

- 主题 + 开头句 + 一个技巧提示。
- 题目短、指向具体，如“写一件让你开心的事”。

高年级（4-6 年级）：

- 主题 + 技巧提示 + 两三个可写方向；高年级可只给主题与要求。
- 允许半开放，如“一个让我印象深刻的瞬间”；也可以用有张力的题目，如“那一次，我错了”。

### 题型与要点

- **记事类**：事件要具体；给多个可写方向；审题提示指出陷阱（如“‘难忘’要体现在细节上，不是只说‘我难忘’”）。
- **写人类**：人要有特点，不泛泛写人；鼓励用定格瞬间展开。
- **情景/想象类**：情景足够具体；想象要有逻辑，不是胡编。
- **基于行文技巧的写作题**（读写迁移用）：主题与阅读材料不同；明确提示用哪个技巧；评价重点包含技巧运用是否自然。

### 写作题输出形状

1. 题目
2. 适用年级
3. 训练目标
4. 审题提示
5. 可写方向
6. 评分重点

### 与训练目标对齐

- 有 `priority_targets` 时，题目要能练到其中一项；不要出与档案目标无关的题。
- 没有明确目标时，用 `developing_topics` 里最靠前的一项。
- 两者都空时，用年级段默认题型，并在 `strategy_summary` 里说明是默认。

## 检查清单（出完必过）

1. 每道题都有原文依据吗？（写作题则是：每道题都能落到具体画面吗？）
2. 难度匹配年级吗？
3. 参考答案具体吗？
4. 判分标准清晰、可操作吗？
5. 填空题有命题意图和边界说明吗？
6. 开放答案说明了合理边界吗？
7. 题型是否覆盖了理解、分析、表达，而不是一堆同型题？

## Session Segment

出题也是一段会话，本轮在内存里产出一个 `session_segment`；本 skill 不直接写学生数据，入口会把它写入 `session_log.json`：

```json
{
  "focus": "《XX》双层赏析与段落作用练习",
  "subject": "chinese",
  "mode": "learn",
  "submode": "generate_tasks",
  "source": "reading",
  "strategy_summary": "按高年级难度出了 3 道题，覆盖概括、赏析、作用，并给出分点判分标准。",
  "strengths": [],
  "difficulties": [],
  "next_step_candidate": "让学生先做赏析题，再按判分标准自评",
  "recommended_targets": ["双层赏析"],
  "feynman_handoff_recommended": false,
  "confirmed_skills": [],
  "skill_errors_observed": []
}
```

字段要求：

- `subject` 固定 `chinese`；`mode` 固定 `learn`；`submode` 固定 `generate_tasks`。
- `source`：阅读题写 `reading`，写作题写 `writing`。
- 出题本身不产生学生表现，`strengths`、`difficulties`、`confirmed_skills`、`skill_errors_observed` 通常为空；不要为了填满而编造学生表现。
- 学生做完题后要诊断，交回入口重新路由到阅读诊断或写作评改，不在本 skill 内接着批改。

## End-State Rule

- 出完题用一句话说明“这组题练什么、怎么算过关”，然后把选择权交给学生（现在做 / 换一组 / 先看一道示例）。
- 不用硬停止收尾。
- 需要保存时交回入口，按 `learn-data` 的 finalize 规则执行；本 skill 不自行写档案。
