# 语文阅读核心规则

## 核心原则

1. 先证据，后结论
2. 默认双层赏析：本义 + 语境义 / 表达效果
3. 作用题必须绑定本文对象、情境、主题
4. 区分文本事实与推断
5. 主题与作者意图必须可回溯

## 阅读思路链

1. 文本解读到提出问题
2. 赏字分两层
3. 析作者，得结论

## 错误标签

统一标签表：同一 base directory 下的 `references/chinese-error-labels.md`。

阅读标签：`reading:概括偏差`、`reading:证据不足`、`reading:单层赏析`、`reading:意图误判`、`reading:空泛模板`、`reading:结构失察`、`reading:审题偏差`、`reading:细节功能忽视`。

## 常见问题

### 单层赏析

只停留在字面本义，忽略语境义和对描写对象的表达效果。

示例：问“这句话有什么表达效果？”
- 错误答案：这句话写得很生动。
- 正确方向：这句话用XX手法，本义是XX，在本文中表达了作者对XX的XX情感。

### 空泛模板

套用"生动形象"、"承上启下"等公式，不关联具体文本。

示例：问"这段话有什么作用？"
- 错误答案：这段话承上启下，推动情节发展。
- 正确方向：这段话承接上文XX，开启下文XX，对本文XX主题有XX作用。

### 概括偏差

信息提取不全或语言冗长，无法精准击中要点。

示例：问"概括文章主要内容"
- 错误答案：文章写了一个小朋友去公园，看到了很多花，还遇到了一只小狗...（太细）
- 正确方向：文章写了小朋友在公园的经历，表达了XX感受。

### 作者意图误判

深层理解题脱离作者精神品质，单纯联系生活谈感受。

示例：问"作者通过这篇文章想表达什么？"
- 错误答案：我觉得我们应该爱护环境。
- 正确方向：作者通过XX故事，表达了对XX的思考，这种思考在文中表现为XX。

### 细节功能忽视

忽略指代词含义、标题多重用途、标点与关联词逻辑。

示例：问"这个'它'指什么？"
- 错误答案：它指前面提到的东西。
- 正确方向：联系前文XX句，"它"指的是XX。

### 死记硬背

只"多读多写"不掌握阅读工具，语文水平停滞。

做法：教给学生六种文本解读方法。

### 诊断缺失

不知具体病灶，在同一坑里反复跌倒。

解决：每次诊断都要用统一标签记录，形成学生的错题图谱。

## 薛法根文本解读法

六种深读方法：

1. **提领法**: 抓住"文眼"，寻找牵一发而动全身的关键词、关键句
2. **还原法**: 将文学形象与生活真实比较，发现矛盾和反差
3. **原型法**: 穿过故事内容，把握作者构思公式（目标→阻碍→努力→结局）
4. **见人法**: 透过人、事、景、物，看见背后的"人"及其语言风格、情感认知
   - 当学生缺少与作者情感对应的人生经历时，调用 skill 工具加载 `experience-gap-bridging` 建立情感桥梁
5. **降维法**: 从学生视角对比作者写法与常态写法，发现作者高明之处
6. **要素法**: 结合统编教材语文要素，在文本中寻找"要素落点"作为教学锚点

## 核心能力

### 1. 信息处理

- 精准提取关键信息
- 概括时不增添多余细节
- 根据文本类型切换策略

### 2. 细读赏析

- 使用双层赏析
- 识别并解释修辞手法
- 留意指代词和关联词

### 3. 结构与逻辑

- 判断开头、结尾、过渡的作用
- 梳理线索、顺序和推进
- 从多个角度解释标题

### 4. 文学要素分析

- 分析人物、场面、环境及其作用
- 通过细节推断写作意图
- 连接情感、风格和主题

## 诊断用法

1. 先确定错误标签
2. 找到文本证据
3. 判断问题属于意思、结构还是意图
4. 给出一个小步下一步

## 文本层次

三层文本内涵:

- **表层**: 字面意思
- **里层**: 隐含情感
- **深层**: 表达风格与艺术

## 诊断流程

三步走:

1. 精准锁定作者意图
2. 信息提取
3. 文本细读
