# 语文阅读核心规则

## 核心原则

1. 先证据，后结论
2. 默认双层赏析：本义 + 语境义 / 表达效果
3. 作用题必须绑定本文对象、情境、主题
4. 区分文本事实与推断
5. 主题与作者意图必须可回溯

## 阅读思路链

1. 文本解读到提出问题
2. 赏字分两层
3. 析作者，得结论

## 错误标签

统一标签表：同一 base directory 下的 `references/chinese-error-labels.md`。

标签定义、选择与落库以该表为唯一依据；以下“常见问题”只提供纠偏方式。

## 常见问题

### 单层赏析

只停留在字面本义，忽略语境义和对描写对象的表达效果。

示例：问“这句话有什么表达效果？”
- 错误答案：这句话写得很生动。
- 正确方向：这句话用XX手法，本义是XX，在本文中表达了作者对XX的XX情感。

### 空泛模板

套用"生动形象"、"承上启下"等公式，不关联具体文本。

示例：问"这段话有什么作用？"
- 错误答案：这段话承上启下，推动情节发展。
- 正确方向：这段话承接上文XX，开启下文XX，对本文XX主题有XX作用。

### 概括偏差

信息提取不全或语言冗长，无法精准击中要点。

示例：问"概括文章主要内容"
- 错误答案：文章写了一个小朋友去公园，看到了很多花，还遇到了一只小狗...（太细）
- 正确方向：文章写了小朋友在公园的经历，表达了XX感受。

### 作者意图误判

深层理解题脱离作者精神品质，单纯联系生活谈感受。

示例：问"作者通过这篇文章想表达什么？"
- 错误答案：我觉得我们应该爱护环境。
- 正确方向：作者通过XX故事，表达了对XX的思考，这种思考在文中表现为XX。

### 细节功能忽视

忽略指代词含义、标题多重用途、标点与关联词逻辑。

示例：问"这个'它'指什么？"
- 错误答案：它指前面提到的东西。
- 正确方向：联系前文XX句，"它"指的是XX。

### 死记硬背

只"多读多写"不掌握阅读工具，语文水平停滞。

做法：教给学生六种文本解读方法。

### 诊断缺失

不知具体病灶，在同一坑里反复跌倒。

解决：每次诊断都要用统一标签记录，形成学生的错题图谱。

## 薛法根文本解读法

一次只选一个方法，用学生能听懂的话提问，不先报方法名。

| 方法 | 内涵 | 学生可进入的问题 |
|---|---|---|
| 提领法 | 抓住文眼、牵动全文的关键词句 | 全文只能留一个词或一句话，你留哪句？为什么？ |
| 还原法 | 文学形象与生活真实比较，发现矛盾和反差 | 生活里通常这样吗？作者写的哪里不一样？ |
| 原型法 | 把握故事构思：目标→阻碍→努力→结局 | 他想要什么？卡在哪？怎么试的？最后怎样？ |
| 见人法 | 透过人事景物看背后的人、语言风格与情感认知 | 写这些时，作者是个什么样的人？心里在想什么？ |
| 降维法 | 对比作者与常态写法，发现高明之处 | 换我来写会怎么写？作者这样写高明在哪？ |
| 要素法 | 在文本中寻找统编教材语文要素落点 | 哪个地方正好在练这个单元的语文要素？ |

选择：抓不住重点用提领法；只知写什么、不知为何这样写，用还原法或降维法；概括或结构失分，用原型法或要素法；情感、人物、意境难点用见人法。缺少对应经验时，由阅读调用 `experience-gap-bridging` 内部子流程，接回结果继续见人法或双层赏析，不独立记录桥接回合。

## 核心能力

### 1. 信息处理

- 精准提取关键信息
- 概括时不增添多余细节
- 根据文本类型切换策略

### 2. 细读赏析

- 使用双层赏析
- 识别并解释修辞手法
- 留意指代词和关联词

### 3. 结构与逻辑

- 判断开头、结尾、过渡的作用
- 梳理线索、顺序和推进
- 从多个角度解释标题

### 4. 文学要素分析

- 分析人物、场面、环境及其作用
- 通过细节推断写作意图
- 连接情感、风格和主题

## 诊断用法

1. 先确定错误标签
2. 找到文本证据
3. 判断问题属于意思、结构还是意图
4. 给出一个小步下一步

## 文本层次

三层文本内涵:

- **表层**: 字面意思
- **里层**: 隐含情感
- **深层**: 表达风格与艺术

## 诊断流程

三步走:

1. 精准锁定作者意图
2. 信息提取
3. 文本细读
