# 经验缺口桥接

仅供 `chinese-reading-session` 内部执行，复用已验证会话与快照；不独立开启教学。

## 输入与适用范围

接收文本片段、目标情感/意境/人物处境、学生理解状态及至少一处可回文验证的证据。学生能复述字面，却因缺少对应生活经验难以进入情感时才桥接。

事实/知识文本、纯信息提取、术语或答题技巧训练、已有充分相关经验，以及战争、死亡、重大苦难等高风险创伤主题，均交回阅读换方法。

## 条件读取

| 条件 | 规则 |
|---|---|
| 需见人法或文本层次 | `chinese-core` 的 `references/chinese-reading-core.md` |
| 选替代经验 | `learn-core` 的 `references/prestart-settings-interpretation.md` |
| 开始提问 | `learn-core` 的 `references/pedagogy-core.md` 的 Voice And Feedback：Guided Coach，追感受时叠加 Socratic Tutor，一次一问 |
| 不回应或仅一个词 | `learn-core` 的 `references/guidance-non-response-handling.md`：改说法、举例、拆步骤，最多 3 次；仍进不去则停止 |
| 自伤、被伤害、欺凌、家里危险或不想活的信号 | `learn-core` 的 `references/llm-safety-boundaries.md`：立即停止桥接与教学，执行危机流程，不记录创伤细节 |

## 流程

1. 用一个低风险问题核对经验缺口；词义或结构障碍交回阅读，不用类比掩盖。
2. 锁定一个情感处境及将回读的原文证据，再选替代经验。经验须同时满足：日常可进入、无隐私/痛苦/家庭冲突、情感结构对应、能解释与文本的联系。优先从 `personal.interests`、日常活动/物件/宠物、熟悉角落、陪伴或舍不得事物中选择。
   - Prestart 经历仅作轻桥，用完回文；难过经历与隐私边界按已读 prestart。
3. 简短询问感受并等待。学生愿意表达且说出感受后，连接双方共享的情感结构，保留经历差异；学生认可贴切后立即回文。
4. 请学生指认支持感受的句子、画面、对比或细节。个人经验不能替代文本证据。
5. 学生自行表达作者/人物感受，并找到至少一处原文证据，才算完成；之后按需补术语、表达作用或写法分析。

牵强、不像、仅表面相似、偏离文本回不去、抗拒/不适/沉默或高风险主题时，停止并承认未成功，换方法或直接讲解；危机优先执行安全流程。

## 返回阅读

只返回内存结果，不生成 `session_segment`、独立诊断或记录，不写学生数据：

| 字段 | 约束 |
|---|---|
| `status` | `bridged` / `stopped` / `safety_stop`；达到上述完成条件才用 `bridged` |
| `bridge_summary` | 一句话说明替代经验与共享情感结构，不复述隐私 |
| `student_feeling` | 学生感受原话；未说出留空 |
| `text_evidence` | 学生指认的原文句子/细节；未找到留空，不能用类比代替 |
| `stop_reason` / `next_action` | 失败信号与换方法/讲解建议；危机只回传需安全处理，不传创伤细节 |

调用方接回见人法或双层赏析，将有效证据并入唯一阅读段后判断诊断与技能追踪；失败不算掌握，安全停止优先。
