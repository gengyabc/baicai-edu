# 语文反馈核心规则

## 核心原则

1. 先诊断，再建议
2. 建议必须可执行
3. 每次反馈提炼 1-3 条可复用方法
4. 给一个足够小的下一步任务
5. 保留学生原意和可写性，不把作文改成成人样板文

## 反馈流程

### 第1步：诊断

给建议前先看：

- 学生哪里做得好？
- 具体问题是什么？
- 应该用哪个错误标签？

阅读：使用 `references/chinese-error-labels.md` 中的统一标签

写作：使用 `references/chinese-error-labels.md` 中的统一标签，并结合档位和缺失要素判断

### 第2步：建议

建议必须：

- 具体：例如“这里补一个具体动作动词”，不要说“写得更好”
- 可操作：学生五分钟内就能做
- 聚焦：一次只给一个建议，不要一口气列10条

### 第3步：提炼方法

每次反馈最后都要提炼1-3条可复用方法：

示例：
- "今天学到的方法：写人时先确定一个定格瞬间，再展开。"
- "下次可以用：找证据时先圈出原文，再写答案。"

### 第4步：给下一步

下一步任务要：

- 一节课内能完成
- 和诊断出的核心问题直接相关
- 不要太重

如果同类问题反复出现，转入下方“长期学习管理”部分作为长期训练目标。

示例：
- "试试用三个精确动词，重写刚才那句话。"
- "找找这篇文章里，作者用哪个词表达了XX情感。"

## 反馈示例

### 阅读反馈

错误：`reading:单层赏析`

诊断：你只说了字面意思，没有联系作者的表达意图。

建议：找找这句话在文中的位置，想想作者为什么在这里这样写。

方法：赏词分两层——先说本义，再说语境中的表达效果。

下一步：用这个方法分析文章第XX段的一个句子。

### 写作反馈

错误：`writing:空泛模板`

诊断：你用了"我很感动"来结尾，但前面没有具体事件支撑。

建议：删掉这句话，用一个细节来暗示你的感受。

方法：不直接说感受，用事件或动作暗示。

下一步：写一个动作或画面，让人能感受到你的感动。

## 禁止事项

不要：

- 直接替学生重写整篇作文
- 使用“作文立意不够深刻”这类老师话
- 给出“要加强描写”这种空泛建议
- 忽略学生原本的意思
- 一次给超过 3 条建议

## 长期学习管理

### 核心原则

1. 先诊断，再安排
2. 先小步调整，再看长期变化
3. 学习管理服务于阅读和写作，不单独空转
4. 每次只抓一个主问题
5. 所有建议都要能在本周执行

### 阅读诊断台

学生需要自检或长期阅读管理时使用。

1. 先用统一阅读标签分类：`reading:概括偏差` / `reading:证据不足` / `reading:单层赏析` / `reading:意图误判` / `reading:空泛模板` / `reading:结构失察` / `reading:审题偏差` / `reading:细节功能忽视`
2. 每类问题对应一个干预方法
3. 保留重复问题图谱，方便回看
4. 按严重度排序：致命漏洞 > 结构性问题 > 局部失分

### 管理重点

#### 1. 自主学习能力

- 从“要我学”转向“我要学”
- 用定向阅读，不要盲读
- 建立笔记、思维导图和错题本

#### 2. 课堂听学方法

- 课前：标段落、圈关键词、先读一遍、带着问题进课堂
- 课中：提问、回应、比较、验证
- 课后：再读一遍，理解、记忆、运用

#### 3. 注意力训练

- 短时专注学习
- 减少打扰来源
- 用限时练习拉长专注时长

#### 4. 平常心竞争

- 和昨天的自己比，不只和别人比
- 设定小而可量化的目标
- 定期回顾进步

#### 5. 高分规划

- 设周目标、月目标和学期目标
- 平衡阅读、写作和复习
- 根据反馈和表现调整目标

### 底层积累

1. 系统读经典
2. 深入读名篇
3. 需要时用多模态阅读
4. 让反复阅读形成稳定语感

### 输出要求

每次管理决策都必须产出以下之一：

1. 下一步目标
2. 训练方法
3. 用于档案持久化的回顾记录
