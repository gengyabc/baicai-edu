# 语文反馈规则

作文整篇评改的维度、档位、修改处数与低年级简化以 `references/chinese-assessment-rubric.md` 为准；安全信号按 `learn-core` 的 `references/llm-safety-boundaries.md` 停教学，优先于反馈。

## 反馈流程

1. **诊断**：从答案/草稿找有依据的优点与一个主问题，说明对应原句；无明确问题只反馈已观察到的优点与方法。标签用 `references/chinese-error-labels.md`，写作结合缺失要素，评档另读量规。证据不足先补问。
2. **建议**：保留原意、口语与可写性，把问题转成原句上的具体动作。日常引导一次一项、五分钟内可动手；整篇按量规至多 3 处，先做一处。正文学生写，AI 只局部示范；学生能指出改哪里、怎么改才完成此步。
3. **方法**：从刚才问题提炼 1-3 条短方法，收束可只一句。学生能用自己的话说明如何再用，才算理解。
4. **下一步**：一个针对主问题、一节课内可做的任务，明确对象、动作与检查标准后交回调用方。未完成只作候选，不记为学生表现。

## 长期学习管理

仅同类问题反复出现，或学生要求自检/长期安排时执行：

1. 复用科目快照 `error_history`，只取最近 `source: "diagnosis"` 条目，按领域和带前缀 `label` 聚类。同标签至少 2 次独立诊断算重复模式；`notes` 的“重复模式”仅作线索，有疑问核对证据，不另建图谱。
2. 按“致命漏洞 > 结构性问题 > 局部失分”选本周一个主标签；写作选择顺序以标签表为准。阅读给回文训练，写作给保留学生内容的局部修改。目标须有依据、动作本周能执行，并说明下次如何按同标签检查。
3. 下次回看是否改善，改善后再换目标。每次交付至少一项：下一步目标、训练方法、供入口持久化的回顾记录。学生可见内容聚焦读写动作；标签及档案由调用方按数据协议处理。
