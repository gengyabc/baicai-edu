# 语文反馈核心规则

## 使用分支

- 单次反馈、方法提炼：执行下方四步。
- 同类问题反复出现或学生要求自检、长期安排：再读“长期学习管理”。
- 作文整篇评改：维度、档位、修改处数与低年级简化以 `references/chinese-assessment-rubric.md` 为准；本文件提供反馈语言与下一步规则。
- 安全信号：按 `learn-core` 的 `references/llm-safety-boundaries.md` 执行，安全流程优先于反馈。

## 反馈流程

### 1. 诊断：先证据，再建议

从学生答案或草稿找出有依据的优点与主问题，说明对应原句；没有明确问题时只反馈已观察到的优点和方法。标签定义与选择读取同一 base directory 下的 `references/chinese-error-labels.md`；写作结合缺失要素判断，需评档时再读量规。能用证据说清主问题后才给建议，尚无依据则先补问。

### 2. 建议：一次一个主问题

保留学生原意、口语和可写性，用学生能懂的话指出可改的原句和动作，例如“这里补一个具体动作动词”。日常引导一次推进一个建议，学生五分钟内能动手；整篇评改按量规列最值得改的至多 3 处，先做其中一处。

正文由学生写，AI 只做局部示范。完成条件是学生能指出改哪里、怎么改；“理解不深”“加强描写”等笼统评价需转成原句上的具体动作。

### 3. 方法：学生能复述

用短句提炼 1-3 条可复用方法，例如“先圈出原文证据，再写答案”。方法必须对应刚才的具体问题；课堂收束可只用一句。学生能用自己的话说明如何再用，才算本次方法提炼被理解。

### 4. 下一步：小到能做

给一个直接针对主问题、一节课内能完成的任务；长期安排也要在本周可执行。示例：

- “试试用三个精确动词，重写刚才那句话。”
- “找找这篇文章里，作者用哪个词表达了 XX 情感。”

任务明确到对象、动作与检查标准后交回调用方；尚未完成的任务只作为候选，不记为学生表现。同类问题重复时按下方管理流程安排。

## 长期学习管理

### 1. 找重复模式

复用调用方快照中科目 `profile.json` 的 `error_history`；只取 `source: "diagnosis"` 的最近条目，按领域与带前缀的 `label` 聚类。同一标签有 2 次及以上独立诊断证据算重复模式，标注“重复模式”的归并条目也作为线索；有疑问先核对已有证据，不额外建立图谱。

### 2. 选本周一个目标

先诊断，再安排；按“致命漏洞 > 结构性问题 > 局部失分”选择一个最值得改的主标签。阅读与写作的标签含义、写作选择顺序均以统一标签表为准，不另列第二套标签。

- 阅读：给一个回文训练动作，如“每天找一段话，圈出证据再写一句赏析”。
- 写作：给一个局部练习，如改一句、加一个动作、补一个回扣；练习保留学生自己的内容。

完成条件：目标有诊断依据，训练动作本周可执行，并说明下次如何用同一标签检查。

### 3. 回看并交付

下一次会话回看同一标签是否减少，改善后再换目标。每次管理决策至少交付一项：下一步目标、训练方法、供入口持久化的回顾记录。学生可见内容聚焦具体读写动作；内部标签和档案记录交调用方按数据协议处理。
