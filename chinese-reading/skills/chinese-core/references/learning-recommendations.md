# 语文学习推荐

供 `learn-recommend` 经学科契约读取。这里只决定语文候选的内容、难度、理由与排序；选择和交接沿用共享流程。

## 候选：目标—证据缺口—任务

把已有阅读答案、写作片段、最近表现和快照中的下一步，转成「要学什么 → 还缺什么证据 → 做哪一个小任务」。通常给 2–3 个有依据且有差异的目标，首选 1 个；不足时少给，不以阅读/写作各占一个凑数。推荐只说明可开始的动作，不预先发教学问题或代写答案。

- 以最新实际表现核对 `priority_targets`、`developing_topics`、`error_history`、`session_history` 与 memory；区分独立表现、支架后表现、自述和待验证建议。旧标签不能覆盖已发生的修正，也不凭低水平字段列出一串弱项。
- 一次锁定一个读写主问题。阅读优先回文证据与意思的连接；写作优先对象、瞬间与可观察细节，再考虑语言和升格。候选标题包含具体动作，如「用两处动作说明人物为什么改变」，而不是「练阅读理解」「作文提高」。
- 只使用已有材料引用或选定后可直接提供的短材料。现有材料缺失时可推荐同类新短文，不声称能继续分析缺失原文；学生想换内容时避免把原文再做一遍当首选。

| 主问题 / 目标 | 证据缺口 | 可开始的小任务 |
|---|---|---|
| 概括遗漏关键结果 | 事件主线未完整连接 | 从一个短故事找目标、阻碍和结局，合成一句话 |
| 人物判断只有结论 | 原文动作与判断之间缺解释 | 找两处动作，说明它们如何支持一个人物判断 |
| 赏析只有「生动形象」 | 本义到语境效果的连接不足 | 对比一处词句与普通写法，说清本文里多表达了什么 |
| 作文泛泛叙述、无定格 | 缺少对象与一个具体瞬间 | 从自己的事件选一个瞬间，用两个准确动作展开 |
| 有定格但仍空泛 | 缺可观察的声音、表情或旁人反应 | 只改一小段中的一个关键细节，保留原意 |
| 已有细节，结尾空喊感受 | 前文细节与结尾意义未连接 | 让结尾回到前面一个真实细节，不加空泛口号 |
| 已读懂且有可操作写法 | 尚缺换主题运用的证据 | 换一个生活主题，只用一个已提炼的写法写小片段 |

阅读方法按 `references/chinese-reading-core.md` 选择，一次一种；写作与读写迁移门槛按 `references/chinese-writing-core.md`。未读懂或未提炼可操作技巧时，不把读写迁移排成必经下一步。经验缺口只有真实表现支持时才影响选材，不凭空贴标签。

## 难度、排序与中文理由

首选能补当前关键证据缺口、且学生已有支点的一步。读写领域可按证据重排，不把普通恢复的 `active_domain` 或历史下一步当固定优先级。多处问题同时出现时，先解决阻碍意思表达/理解的主问题，不先堆修辞和模板。明确换内容时，在不同材料或领域中保留有用的小目标。

年级按 `references/chinese-grade-defaults.md` 调整文本长度和问题层数；写作六圈按写作规则选择，不要求每圈填满。`material_difficulty` 一次只改一个负荷因素。`personal.interests` 与科目偏好按 `references/chinese-personalization.md` 选材料/角度，不用兴趣代替能力证据。无记录时给低负荷起点，理由明确是可尝试的方向。

理由用学生能懂的中文，把记录中的具体表现连到小任务：

- 上次把人物称为「勇敢」，未给依据：首选「从两处动作说清人物为什么勇敢」；理由：「你上次已经有了自己的判断，这次找出支持它的动作，就能把想法说得更有根据。」备选可为短故事主线概括；不能改说「你已经掌握人物分析」。
- 草稿只有「我很紧张」：首选「把上台前的一瞬间写具体」；理由：「你写清了当时的感受，这次用手或声音的小变化，让读者也能感到紧张。」不把「多用好词好句」列作等价目标。
- 已能解释原文连续动词的效果：可首选「换一个生活场景，用连续动作写一个瞬间」；理由：「你上次说清了那些动作怎样让画面动起来，可以试着用在自己的小片段里。」

完成标准：每个候选有主问题、可回溯的证据缺口和一个小任务；仅首选一个，推荐本身不确认技能或新增诊断。
