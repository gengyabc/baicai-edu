# 语文错误标签表

语文阅读和写作统一使用这份标签表。

**重要**：阅读和写作会共享部分标签名，但定义不同。存档时必须写清领域。

## 迁移规则

- 新写入的 `error_history` 必须使用带前缀的标签：`reading:` 或 `writing:`。
- 旧标签 `writing:意图误判` 归一化为 `writing:偏题`；读取旧记录时做映射。
- 每条诊断只保留一个主标签；次要标签写入 `notes`。

## 存储方式

诊断标签不写进 `skill_errors`。正确链路：

1. 学科 skill 在 `session_segment.diagnosis` 写 `{ "domain", "label", "evidence" }`。
2. `learn-data` finalize 把它写成一条 `error_history` 诊断条目：
   `{ "source": "diagnosis", "domain", "label", "evidence", "next_step", "error_id": "diag_..." }`。
3. `error_history` 保留最新 20 条；同一标签重复出现时保留最新证据，并在 `notes` 写“重复模式”。

这样标签才能被下一次诊断读回，而不是只停留在本轮回复里。

## 阅读标签

诊断阅读题时使用以下标签：

| 标签 | 定义 | 示例 |
|-------|------------|-----------------|
| `reading:概括偏差` | 信息不全或语言冗长，无法精准浓缩要点 | 概括文章时遗漏关键事件或描述过于细致 |
| `reading:证据不足` | 答案缺乏文本依据或依据不明确 | 答案观点无原文支撑 |
| `reading:单层赏析` | 只回答字面本义，忽略语境义和表达效果 | 只解释字面意思，未分析表达效果 |
| `reading:意图误判` | 未能准确判定作者写作意图，深层理解偏离 | 作者意图是批判但学生理解为赞美 |
| `reading:空泛模板` | 套用通用公式而不结合具体文本内容 | 用“承上启下”等公式无具体内容 |
| `reading:结构失察` | 忽视文章线索、顺序或段落作用 | 未发现文章的递进结构 |
| `reading:审题偏差` | 未准确理解题目要求 | 答非所问 |
| `reading:细节功能忽视` | 忽略指代词含义、标题多重用途、标点与关联词逻辑 | 未理解“它”指代的具体对象 |

## 写作标签

诊断作文问题时使用以下标签：

| 标签 | 定义 | 示例 |
|-------|------------|-----------------|
| `writing:偏题` | 偏离题目要求或主题 | 题目要求写人，实际写成叙事 |
| `writing:概括偏差` | 全篇只有概述，没有具体事件或画面 | 只写“今天很开心”，没有一件事 |
| `writing:空泛模板` | 有内容，但用套话、公式或口号收尾 | 用“我要向她学习”结尾，无具体内容 |
| `writing:细节缺失` | 有事件，但动词、感官或动作不具体 | 用“他走了”而非具体动作 |
| `writing:单层赏析` | 只写表面外貌/事件，没有性格或深层意蕴 | 写人只写外貌，未展现性格特点 |
| `writing:升格不足` | 结构完整，但缺少角度变化或回扣 | 结尾无呼应，缺乏深层意蕴 |

### 写作标签怎么选（按顺序判断）

1. 先看是否切题：不切题 → `writing:偏题`，其他标签先不选。
2. 有没有一个具体事件/画面？没有 → `writing:概括偏差`。
3. 有事件，但全是套话/口号？→ `writing:空泛模板`。
4. 有事件，但动作、感官不具体？→ `writing:细节缺失`。
5. 写人只写外貌、没有性格？→ `writing:单层赏析`。
6. 内容具体，但结尾没有回扣/角度？→ `writing:升格不足`。

一个学生可能同时有多个问题；只选最值得先改的一个主标签。

---

## 使用说明

1. 存入 `error_history` 时必须保留领域前缀（`reading:` 或 `writing:`）。
2. 只使用本文件中的标签，不要自造新标签。
3. 标签对应主问题，每条诊断只用一个主标签。
4. 多面问题在 `notes` 里记录次要标签。
5. 学生可见回复不展示标签名；用学生能懂的话说问题。
