# 语文写作规则

## 核心原则

先具体后抽象，先定格再展开；用事件、精确动词与可观察细节承载感受。升格靠意义、视角与回扣，不靠辞藻或假抒情。模板仅作结构支架，保留学生的事件和口语，能独立展开后撤去。

## 六圈展开法（豆神大语文）

先确定对象与一个瞬间，一次问一圈；六圈是支架，不是填满指标。

| 圈 | 焦点 |
|---|---|
| 1. 主要对象 | 画面核心是谁或什么 |
| 2. 正面描写 | 此刻动作、表情、声音、样子 |
| 3. 侧面描写 | 旁人反应及其烘托作用 |
| 4. 环境描写 | 光线、声音、天气、周围事物如何渲染气氛、交代背景或寄托情感 |
| 5. 场面描写 | 整体气氛与众人的行动 |
| 6. 修辞与深度 | 比喻、角度变化、回扣及深层意蕴，避免堆修辞 |

1-3 年级只走第 1-3 圈，用短句和动作词；4-6 年级走第 1-5 圈，重点定格与连续动词，第 6 圈按需用于角度或回扣。

## 常见写作问题与升格规则 / 修改方法

| 主问题 | 修改动作 |
|---|---|
| 无定格、泛泛叙述 | 先锁定对象、时刻与动作，不先润色语言 |
| 空话套话或抽象概括 | 用该事件可观察的细节替换 |
| 动词泛泛、堆辞藻 | 先加精确动词，再考虑形容词 |
| 假抒情 | 用事件或细节暗示感受，不用空泛结论收尾 |
| 草稿太平 | 改叙述角度；写人重细节/情感，写事重张力/过程，写景重感官/层次 |
| 结尾升格不足 | 增加有意义的回扣 |

每次只选对应主问题的动作，保留学生原意；具体推进由写作教学负责。

## 写作发展水平

L1-L4 描述能力发展；作品一至四档由 `references/chinese-assessment-rubric.md` 判断，二者不直接换算。

| 水平 | 表现 |
|---|---|
| L1 起步 | 基本叙事顺序，概括多、内容空、缺定格 |
| L2 发展 | 有定格，细节仍不足，仍有套话 |
| L3 稳定 | 定格清楚、细节与动词具体，仍可升格 |
| L4 灵活 | 展开自如，能用角度/回扣升格，有个人风格 |

## 行文技巧提取与读写迁移

技巧来自原文，可理解、可模仿、可转成写作练习；修辞标签本身不算技巧。可从标题/结构、动词、节奏、视角、逻辑顺序或修辞效果筛选。

### 提取流程

1. 通读标注可学写法，筛掉无明确原文实例、超出年级或不可操作的候选；无合适技巧时回阅读确认理解或另选材料。
2. 每个保留技巧写齐四项：学生能懂的名称、原文具体语句、表达效果、迁移时怎么用。四项齐备且符合下表才算完成；已有阅读结果校验补缺，不重复提取。

| 学段 | 数量与范围 |
|---|---|
| 1-3 年级 | 阅读最多提炼 1-2 个；迁移只选 1 个直观技巧，可用 50-100 字短文。选可直接模仿的直观技巧 |
| 4-6 年级 | 提炼 2-3 个，可含定格、对话、侧面描写、结构与视角 |
| 5-6 年级进阶 | 可涉及悬念、长短句节奏、首尾回扣、视角转换及反差张力 |

迁移题按同一 base directory 的 `references/chinese-task-generation.md` 换主题并给学段支架；陪写由 `chinese-read-write-transfer` 执行；写后点评按 `references/chinese-assessment-rubric.md` 的技巧运用分支。
