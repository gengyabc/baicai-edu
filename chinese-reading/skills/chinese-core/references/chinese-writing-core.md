# 语文写作核心规则

## 核心原则

1. 先具体，后抽象
2. 先定格，再展开
3. 优先细节密度，不堆辞藻
4. 删除空话、套话、大话、假抒情
5. 优先精确动词和可观察细节
6. 升格依靠意义、视角、回扣，不靠形容词堆叠

## 写作思路链

1. 先确定描写对象
2. 先锁定一个画面
3. 再用六圈展开
4. 最后加回扣和思考

## 六圈展开法（豆神大语文）

先定格一个画面，一次只问一圈；六圈是支架，不是逐条填空表。

1. **主要对象**：画面核心是谁或什么？
2. **正面描写**：此刻的动作、表情、声音、样子是什么？
3. **侧面描写**：旁人怎样反应？反应烘托了什么？
4. **环境描写**：光线、声音、天气、周围事物怎样？用于渲染气氛、交代背景、寄托情感。
5. **场面描写**：这一瞬间整体气氛怎样？大家在做什么？
6. **修辞与深度**：哪里可打比方？画面让你想到什么？结合本义与深层意蕴，而非堆修辞。

学段：1-3 年级只走第 1-3 圈，用短句和动作词；4-6 年级走第 1-5 圈，重点定格与连续动词，第 6 圈用于角度变化或回扣。

## 写作支持系统

### 1. 模板与诀窍

- 模板是支架，不是框架
- 用来支撑结构，不要代替内容
- 模板语言要少而具体

### 2. 文体方法

- 写人靠细节和情感
- 写事靠张力和过程
- 写景靠感官和层次

### 3. 读写迁移

- 快速提炼原文标题和结构
- 模仿结构、措辞和节奏
- 迁移原文的逻辑顺序

提炼技巧时按下方“行文技巧提取与读写迁移”的证据、描述与学段标准执行；生成迁移题时读取同一 base directory 下的 `references/chinese-task-generation.md`，由它规定换主题与学段支架；陪写与提醒由 `chinese-read-write-transfer` 执行；写后点评读取 `references/chinese-assessment-rubric.md` 的技巧运用分支。

## 升格规则

1. 用可观察的细节替换抽象词
2. 先加精确动词，再加形容词
3. 草稿太平就换角度
4. 结尾需要升格时加回扣

## 常见写作问题

### 空话套话

示例：
- 错误：这件事让我感动不已，我觉得我们应该向她学习。
- 修正：她弯腰捡起那张废纸，轻轻放进垃圾桶，没有看任何人一眼。

### 堆辞藻

示例：
- 错误：阳光明媚，天空湛蓝，花儿鲜艳，景色宜人...
- 修正：阳光洒在石板路上，那朵野菊正好开在我脚边。

### 无定格

没有抓住一个具体瞬间展开，而是泛泛叙述。

解决：问学生"你最想写的那个画面是什么？"

### 假抒情

用"我感到..."结尾，却没有具体事件支撑情感。

解决：要求学生用事件或细节暗示情感，不直接说。

## 修改方法

### 添加精确动词

示例：
- 原句：他走进教室。
- 修改：他踮着脚尖溜进教室，眼睛四处扫了一眼。

### 用细节替代抽象

示例：
- 原句：妈妈很辛苦。
- 修改：妈妈每天下班回家，第一件事是帮我热饭菜。

### 改角度

示例：
- 原句：我很害怕。
- 修改（侧面）：我紧紧抓住书包带，不敢抬头看那个黑洞洞的巷口。

### 加回扣

示例：
- 原句：这件事让我难忘。
- 修改：直到现在，我还会想起那天傍晚的风，那是我第一次一个人走回家。

## 写作档位判断

### L1：起步

- 有基本叙事顺序
- 但内容空泛，缺少定格
- 语言多为概括性陈述

### L2：发展

- 能抓住一个定格瞬间
- 但细节不够具体
- 语言有进步但仍有套话

### L3：稳定

- 定格清晰，细节丰富
- 语言具体，有精确动词
- 但升格空间仍存在

### L4：灵活

- 定格与展开自如
- 能用角度变化和回扣升格
- 语言有风格，不套路

## 行文技巧提取与读写迁移

### 核心原则

1. 技巧必须来自阅读材料原文，不可凭空引入
2. 每个技巧必须引用原文具体语句作为证据
3. 技巧必须可操作：学生看了能知道自己怎么用
4. 技巧不是修辞手法的标签，而是“作者这样写达到了什么效果，你可以怎么模仿”

### 提取流程

#### 第1步：通读标注

阅读全文时标注值得学习的写法：
- 有表现力的动词、形容词用法
- 特殊句式或节奏（短句连用、长短交替）
- 角度选择（正面/侧面、远景/近景）
- 结构安排（开头方式、过渡、回扣结尾）
- 修辞手法及其实际效果（不是贴标签）

#### 第2步：筛选技巧

按以下标准筛选：
- 学生当前年级能理解和模仿
- 在文中有明确实例
- 可以转化为写作练习

#### 第3步：描述技巧

每个技巧包含：
- **名称**：简洁、学生能懂（如“用动作写心情”而非“间接心理描写”）
- **原文证据**：引用具体语句
- **效果说明**：这样写好在哪里
- **迁移提示**：学生写作时可以怎么用

### 学段适配

#### 低年级（1-3年级）

- 阅读提炼最多 1-2 个技巧；进入低年级迁移练习时只选 1 个最直观的技巧，避免负担
- 短文（50-100字）即可作为素材
- 技巧必须非常直观，如：
  - 用动作写出心情（不是“我很开心”，而是“我蹦蹦跳跳地走进教室”）
  - 写出看到的颜色和形状（“那朵花红红的，像小灯笼”）
  - 用声音词让句子有画面（“哗啦啦，雨下起来了”）

示例：
- 技巧：用动作写心情
- 原文：小明低下头，慢慢把试卷折起来，塞进书包最里面。
- 效果：不说“难过”，但读者能感受到
- 迁移：写一个你开心或难过的时刻，不用“开心”“难过”这两个词，用一个动作来表现

#### 高年级（4-6年级）

- 提取 2-3 个技巧
- 可以涉及结构和角度变化
- 技巧示例：
  - 先写环境再写人物（环境烘托）
  - 用一个具体瞬间展开（定格法）
  - 用对话推进情节
  - 侧面描写烘托主要对象

示例：
- 技巧：定格展开
- 原文：她弯腰捡起那张纸，轻轻抚平褶皱，小心地放进抽屉。
- 效果：抓住一个动作瞬间，用连续动词展开，画面感强
- 迁移：写一个你观察到的动作瞬间，至少用两个连续动词

##### 进阶：5-6 年级

- 可以涉及深层结构和表达深度
- 技巧示例：
  - 开头设置悬念或矛盾
  - 长短句交替制造节奏
  - 结尾回扣开头（首尾呼应）
  - 视角转换增加深度
  - 用反差制造张力

示例：
- 技巧：开头设置悬念
- 原文：那天之后，我再也没有走过那条小巷。
- 效果：读者立刻想知道“那天发生了什么”
- 迁移：用一个让人好奇的句子作为文章开头，不要直接说出结果
