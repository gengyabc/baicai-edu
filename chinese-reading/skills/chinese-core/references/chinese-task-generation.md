# 语文出题规则

## 训练目标对齐

选 `priority_targets` 一项；为空则取 `developing_topics` 首项；都空则用年级默认题型，并在 `strategy_summary` 说明。题目须真正练到目标。

## 阅读题出题

一次 2-4 道，搭配理解、分析、表达。每题锚定原文段落/句子；开放题可结合全文但须限定范围，不考脱离文本的常识。

| 学段 | 题型与要求 |
|---|---|
| 1-3 年级 | 短文概括、常用词义、段意、简单主旨；每题一个点、短句提问、答案相对确定，鼓励自己的话，不要求深层赏析 |
| 4-6 年级 | 中长文概括、词句赏析、段落作用、主旨/意图、开放探究、句子填空；强调文本分析，开放答案明确标准 |

### 题目与答案标准

每题附具体参考答案、命题意图和分点判分标准（每点分值，合计等于总分）；答案落实到本文，不留 XX 占位符，不仅写“言之有理即可”。

| 题型 | 额外约束 |
|---|---|
| 内容概括 | 给字数要求；整合关键事件和结果，不只抄原文 |
| 词句赏析 | 手法 → 本义 → 语境义/表达效果，避免空泛公式 |
| 段落作用 | 具体承接、开启内容及主题作用，不能只答“承上启下” |
| 主旨/意图 | 结论可回溯原文 |
| 开放探究 | 说明可接受方向与跑题边界 |
| 句子填空 | 挖空符合局部句意与段落逻辑，有文本线索；至少一个答案，多解时最标准在前；合理边界覆盖人称、衔接、情感基调，判分覆盖逻辑、通顺和基调；不能变成猜句或脱离文本的修辞练习 |

## 写作题出题

单题或 2-3 题供选，齐备审题提示、可写方向、注意事项和评价重点。半开放题也落到具体画面：记事限定事件与审题陷阱；写人抓特点与定格；情景/想象具体且逻辑自洽。

| 学段 | 支架 |
|---|---|
| 1-3 年级 | 短而具体的主题 + 开头句 + 一个技巧提示，短篇幅，先保护愿意写 |
| 4-6 年级 | 主题 + 技巧提示 + 两三个可写方向 |
| 5-6 年级自由式 | 可只给主题与要求、自由选材，撤去可写方向 |

## 基于行文技巧的写作题出题

阅读→写作迁移额外要求：

- 技巧取自 `references/chinese-writing-core.md` 的提取结果；题目主题与阅读材料不同，避免照搬。
- 任务有使用该技巧的空间，明确技巧目标，评价其运用效果而非仅看是否出现。
- 按上方学段提供支架；即使 5-6 年级自由选材，也保留本次技巧与评价目标。

## 检查清单

逐题检查，未通过先修改再交付：

1. 阅读有原文依据，写作有具体可写画面，且确实练到目标。
2. 难度、题型和支架符合学段；阅读题组不是同型堆积。
3. 阅读答案具体到本文，命题意图和分点判分齐备、分值相符；填空与开放题的合理边界完整。
4. 写作题审题提示、可写方向（自由式可省）与评价重点齐备；迁移题换主题、留技巧空间、明示技巧目标。
