# 语文出题规则

## 核心原则

1. 阅读题立足原文证据和结构，写作题落到可写的具体情境
2. 难度必须匹配年级段
3. 题型搭配要覆盖理解、分析、表达，不只出套路题
4. 句子填空题必须提供命题意图和参考判分标准
5. 允许"言之有理"的开放答案时，必须说明合理边界

## 按学段的题型

### 低年级（1-3年级）

侧重基础理解：

1. 内容概括（短文）
2. 词义理解（常用词）
3. 段落大意
4. 简单主旨

题型特点：
- 答案相对确定
- 不要求深层赏析
- 鼓励用自己的话表达

### 高年级（4-6年级）

增加分析深度：

1. 内容概括（中长文）
2. 词句赏析（手法+效果）
3. 段落作用（结构+内容）
4. 主旨与作者意图
5. 开放探究
6. 句子填空

题型特点：
- 要求结合文本分析
- 可以有开放答案，但要说明标准
- 强调证据意识

## 阅读题出题

### 通用题目与答案标准

- 一次 2-4 道，搭配理解、分析、表达，不全是同型题。低年级每题一个点、短句提问。
- 每题锚定具体段落或句子，有原文依据，不考脱离文本的常识；高年级开放题可结合全文，但须限定范围。
- 每题至少一个具体参考答案、命题意图（考什么能力）和分点判分标准（每点几分）；不能仅写“言之有理即可”。下方示例中的 XX 必须替换为本文内容。
- 赏析答案写清手法 → 本义 → 语境义/表达效果；作用题写具体承接、开启与主题作用。
- 主旨/意图题要求结论回溯到文本；开放探究题明确可接受的方向与跑题边界。

### 内容概括题

要点：
- 不能只抄原文，要能整合信息
- 提供字数要求（如"不超过50字"）
- 参考答案要覆盖主要事件和结果

示例：
- 题目：用一句话概括文章主要内容。
- 要求：不超过30字。
- 参考答案：文章写了XX，表达了XX。
- 命题意图：考查信息整合能力。

### 词句赏析题

要点：
- 默认双层赏析要求
- 必须关联具体文本
- 不接受空泛公式

示例：
- 题目：分析第XX段“XXXX”这句话的表达效果。
- 参考答案：这句话用了XX手法，本义是XX，在文中表达了XX。
- 命题意图：考查双层赏析能力。
- 判分标准：提到手法1分，本义1分，语境效果2分。

### 段落作用题

要点：
- 必须绑定本文结构
- 要求说出具体承接/开启内容
- 不接受"承上启下"空话

示例：
- 题目：第XX段在全文中有什么作用？
- 参考答案：这段承接上文XX，开启下文XX，对XX主题有XX作用。
- 命题意图：考查结构理解能力。
- 判分标准：说出具体内容2分，说出作用2分。

### 句子填空题

要点：
- 挖空句同时符合局部句意与段落逻辑，有文本线索，不能靠猜或变成脱离文本的修辞练习
- 至少一个参考答案，多解时最标准的在前
- 合理边界写清人称、上下文衔接、情感基调必须一致
- 分点判分包含上下文逻辑、语言通顺、情感基调；同时提供命题意图

示例：
- 题目：在文章第XX段横线处填入一句话，使上下文连贯。
- 参考答案：XX（最标准），也可：XX或XX（言之有理）。
- 命题意图：考查段落逻辑和语言表达。
- 判分标准：符合上下文逻辑2分，语言通顺1分，情感基调一致1分。

## 写作题出题

可给单题或 2-3 题供选择，配审题提示、可写方向、注意事项与评价重点。

学段支架：1-3 年级给短而具体的主题 + 开头句 + 一个技巧提示，篇幅短，先保护愿意写；4-6 年级给主题 + 技巧提示 + 两三个可写方向，5-6 年级可只给主题与要求、自由选材。半开放题也要落到可写的具体画面。

### 记事类

要点：
- 事件要具体，不要太宽泛
- 提供多个可写方向
- 审题提示要指出可能的陷阱

示例：
- 题目：一件难忘的小事
- 审题提示："难忘"要体现在细节上，不是只说"我难忘"。
- 可写方向：一次误会、一个小收获、一次被帮助...

### 写人类

要点：
- 人要有特点，不是泛泛写人
- 鼓励用定格瞬间展开

示例：
- 题目：他/她的一个特点
- 审题提示：抓住一个具体瞬间，写清这个特点。
- 可写方向：妈妈的认真、朋友的幽默、老师的耐心...

### 情景/想象类

要点：
- 情景要足够具体
- 想象要有逻辑，不是胡编

示例：
- 题目：假如我有一天时间可以倒流
- 审题提示：想想你会选择哪个时刻，为什么。
- 可写方向：回到考试前、回到小时候、回到某个决定时刻...

## 基于行文技巧的写作题出题

当写作任务来自阅读→写作迁移时（参考同一 base directory 下的 `references/chinese-writing-core.md`），额外遵循以下规则：

### 要点

- 题目必须让学生有机会使用从阅读中学到的技巧
- 题目主题应与阅读材料不同，避免照搬
- 明确提示学生使用哪个技巧
- 评价重点包含技巧运用效果

### 学段适配

#### 低年级（1-3年级）：引导式

- 给出主题 + 开头句 + 提示使用技巧
- 示例：
  - 阅读技巧：用动作写心情
  - 题目：写一件让你开心的事
  - 开头：放学铃响了，我……
  - 提示：试试不用"开心"这个词，用一个动作让别人知道你很开心

#### 高年级（4-6年级）：半引导式

- 学段支架按上方“写作题出题”；迁移任务始终保留所用技巧与评价目标，5-6 年级可撤去可写方向
- 示例：
  - 阅读技巧：定格展开
  - 题目：一个让我印象深刻的瞬间
  - 提示：抓住一个动作瞬间，用连续动词展开
  - 可写方向：比赛中的关键时刻、和朋友的第一次见面、看到惊喜的那一刻

##### 进阶：5-6 年级自由式

- 给出主题与本次技巧目标，学生自由选材、决定如何运用技巧
- 示例：
  - 阅读技巧：开头设置悬念 + 首尾呼应
  - 题目：那一次，我错了
  - 提示：试试用一个让人好奇的句子开头，结尾回扣开头
  - 评价重点：技巧运用是否自然，不是生硬套用

### 检查

- 题目是否给了使用技巧的空间？
- 主题是否与阅读材料不同？
- 技巧提示是否清晰？
- 难度是否匹配年级？

## 训练目标对齐

有 `priority_targets` 时选其中一项；没有时取 `developing_topics` 最靠前的一项；两者都空则用年级段默认题型，在 `strategy_summary` 说明。题目必须确实能练到所选目标。

## 检查清单

出完逐题检查，不通过则修改后再交付：

1. 阅读题有原文依据、写作题能落到具体画面吗？
2. 难度与支架匹配年级吗？
3. 阅读参考答案是否具体到本文内容，写作题是否齐备审题提示、可写方向（自由式可省）与评价重点？
4. 每道阅读题都有命题意图与可操作的分点判分标准，且分点之和等于题目总分吗？
5. 填空题明确逻辑、人称、情感基调边界了吗？
6. 开放答案说明了可接受方向与跑题边界吗？
7. 阅读题组覆盖理解、分析、表达而非同型堆积吗？
