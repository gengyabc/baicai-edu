# 语文出题规则

## 核心原则

1. 题目必须立足原文证据和结构
2. 难度必须匹配年级段
3. 题型搭配要覆盖理解、分析、表达，不只出套路题
4. 句子填空题必须提供命题意图和参考判分标准
5. 允许"言之有理"的开放答案时，必须说明合理边界

## 按学段的题型

### 低年级（1-3年级）

侧重基础理解：

1. 内容概括（短文）
2. 词义理解（常用词）
3. 段落大意
4. 简单主旨

题型特点：
- 答案相对确定
- 不要求深层赏析
- 鼓励用自己的话表达

### 高年级（4-6年级）

增加分析深度：

1. 内容概括（中长文）
2. 词句赏析（手法+效果）
3. 段落作用（结构+内容）
4. 主旨与作者意图
5. 开放探究
6. 句子填空

题型特点：
- 要求结合文本分析
- 可以有开放答案，但要说明标准
- 强调证据意识

## 阅读题出题

### 内容概括题

要点：
- 不能只抄原文，要能整合信息
- 提供字数要求（如"不超过50字"）
- 参考答案要覆盖主要事件和结果

示例：
- 题目：用一句话概括文章主要内容。
- 要求：不超过30字。
- 参考答案：文章写了XX，表达了XX。
- 命题意图：考查信息整合能力。

### 词句赏析题

要点：
- 默认双层赏析要求
- 必须关联具体文本
- 不接受空泛公式

示例：
- 题目：分析第XX段“XXXX”这句话的表达效果。
- 参考答案：这句话用了XX手法，本义是XX，在文中表达了XX。
- 命题意图：考查双层赏析能力。
- 判分标准：提到手法1分，本义1分，语境效果2分。

### 段落作用题

要点：
- 必须绑定本文结构
- 要求说出具体承接/开启内容
- 不接受"承上启下"空话

示例：
- 题目：第XX段在全文中有什么作用？
- 参考答案：这段承接上文XX，开启下文XX，对XX主题有XX作用。
- 命题意图：考查结构理解能力。
- 判分标准：说出具体内容2分，说出作用2分。

### 句子填空题

要点：
- 填空句子必须符合段落逻辑
- 提供至少一个参考答案
- 说明"言之有理"的边界

示例：
- 题目：在文章第XX段横线处填入一句话，使上下文连贯。
- 参考答案：XX（最标准），也可：XX或XX（言之有理）。
- 命题意图：考查段落逻辑和语言表达。
- 判分标准：符合上下文逻辑2分，语言通顺1分，情感基调一致1分。

## 写作题出题

### 记事类

要点：
- 事件要具体，不要太宽泛
- 提供多个可写方向
- 审题提示要指出可能的陷阱

示例：
- 题目：一件难忘的小事
- 审题提示："难忘"要体现在细节上，不是只说"我难忘"。
- 可写方向：一次误会、一个小收获、一次被帮助...

### 写人类

要点：
- 人要有特点，不是泛泛写人
- 鼓励用定格瞬间展开

示例：
- 题目：他/她的一个特点
- 审题提示：抓住一个具体瞬间，写清这个特点。
- 可写方向：妈妈的认真、朋友的幽默、老师的耐心...

### 情景/想象类

要点：
- 情景要足够具体
- 想象要有逻辑，不是胡编

示例：
- 题目：假如我有一天时间可以倒流
- 审题提示：想想你会选择哪个时刻，为什么。
- 可写方向：回到考试前、回到小时候、回到某个决定时刻...

## 基于行文技巧的写作题出题

当写作任务来自阅读→写作迁移时（参考 `references/chinese-writing-core.md`），额外遵循以下规则：

### 要点

- 题目必须让学生有机会使用从阅读中学到的技巧
- 题目主题应与阅读材料不同，避免照搬
- 明确提示学生使用哪个技巧
- 评价重点包含技巧运用效果

### 学段适配

#### 低年级（1-2年级）：引导式

- 给出主题 + 开头句 + 提示使用技巧
- 示例：
  - 阅读技巧：用动作写心情
  - 题目：写一件让你开心的事
  - 开头：放学铃响了，我……
  - 提示：试试不用"开心"这个词，用一个动作让别人知道你很开心

#### 中年级（3-4年级）：半引导式

- 给出主题 + 技巧提示 + 可写方向
- 示例：
  - 阅读技巧：定格展开
  - 题目：一个让我印象深刻的瞬间
  - 提示：抓住一个动作瞬间，用连续动词展开
  - 可写方向：比赛中的关键时刻、和朋友的第一次见面、看到惊喜的那一刻

#### 高年级（5-6年级）：自由式

- 给出主题，学生自由选材和运用技巧
- 示例：
  - 阅读技巧：开头设置悬念 + 首尾呼应
  - 题目：那一次，我错了
  - 提示：试试用一个让人好奇的句子开头，结尾回扣开头
  - 评价重点：技巧运用是否自然，不是生硬套用

### 检查

- 题目是否给了使用技巧的空间？
- 主题是否与阅读材料不同？
- 技巧提示是否清晰？
- 难度是否匹配年级？

## 检查清单

出题前检查：

1. 每道题都有原文依据吗？
2. 难度匹配年级吗？
3. 参考答案具体吗？
4. 判分标准清晰吗？
5. 填空题有命题意图说明吗？
6. 开放答案说明了边界吗？
