# 语文批改量规

## 批改流程

齐备题目要求与学生作品，标明普通作文或读写迁移（另需所学技巧）。缺题目先索取，不先判断切题；只有片段时只评可见维度，整体结构与档位暂定。

按下表依次检查全部适用维度；每项有原文依据或具体缺失说明，再给改法。档位有依据、下一步可执行才算完成。评价作品，不评价学生本人。

| 步骤 | 检查与交付 |
|---|---|
| 1. 切题 | 是否回应要求、中心清楚、有无跑题；说明切题程度与具体问题 |
| 2. 技巧运用（仅迁移） | 是否使用所学技巧、是否恰当、是否达到效果；区分未使用、生硬套用、自然有效 |
| 3. 内容 | 定格、具体细节、空话套话；指出缺失 |
| 4. 结构 | 开头/中间/结尾、定格位置、回扣；给调整点 |
| 5. 语言 | 动词精确度、形容词堆积、语气；给局部改法 |
| 6. 深度 | 角度变化、有意义回扣、假抒情；给升格方向 |

普通作文技巧运用为 N/A，不计入档位，不因未用迁移技巧降档。迁移未使用技巧不能评一/二档（最多三档），三/四档仍结合其他维度判断。

### 低年级迁移简化（1-3 年级）

内部保留适用检查；只向学生反馈是否尝试技巧及一处具体可改，保留技巧判断与下一步，不展开六步长评、不强求结构完整。此分支优先于通用输出。

## 档位判断

以档位与分项分析为主，不强制精确分数。

| 档位 | 切题 | 技巧运用（仅迁移） | 内容 | 结构 | 语言 | 深度 |
|---|---|---|---|---|---|---|
| 一档 优秀 | 完全符合 | 恰当自然有效 | 定格清楚、细节丰富 | 展开自然、回扣有力 | 动词精确、无套话 | 角度变化或深层意蕴 |
| 二档 良好 | 基本符合、中心清楚 | 使用但略生硬 | 有定格、细节不足 | 有展开、回扣不足 | 基本具体、偶有套话 | 有但不突出 |
| 三档 合格 | 基本切题、中心模糊 | 未用或明显不当 | 有叙事、缺定格 | 顺序清楚、无展开 | 偏概括 | 无明显深度 |
| 四档 待改进 | 偏题或中心不清 | 未使用 | 空泛 | 混乱或不完整 | 大量套话/假抒情 | 无 |

## 输出格式

1. **档位判断**：一/二/三/四档；片段注明暂定。
2. **分项分析**：切题、技巧运用（仅迁移必填）、内容、结构、语言、深度，每项有依据。
3. **最值得改的至多 3 处**：按实际问题数，每处“原文 + 问题 + 改法”，不凑满；低年级迁移只选一处。
4. **下一步练习目标**：能直接执行的局部任务，不代写整篇。
