# 语文批改量规

## 核心原则

1. 先看切题，再看技巧运用，再看内容，再看结构，再看语言，再看表达深度
2. 不只给判断，还要给改法
3. 优先指出最值得先改的 3 处
4. 评分以档位判断和分项分析为主，不强制输出精确分数
5. 批改结果要能直接转成下一轮练习目标
6. **技巧运用只用于读写迁移写作**；普通作文按 N/A，不计入档位，也不因“没用迁移技巧”降档

## 批改流程

### 第1步：看切题

看这些问题：
- 作文有没有回应题目？
- 中心是否清楚？
- 有没有跑题的内容？

输出：切题程度 + 具体问题点

### 第2步：看技巧运用

当本次写作来自阅读→写作迁移时，看这些问题：
- 学生是否使用了从阅读中学到的技巧？
- 技巧使用是否恰当（不是生硬套用）？
- 技巧效果是否达到（如"用动作写心情"是否真的让读者感受到了心情）？

输出：技巧运用程度 + 具体效果分析

非读写迁移写作时跳过此步。

### 第3步：看内容

看这些问题：
- 有没有具体的定格瞬间？
- 细节是具体还是抽象？
- 有没有空话、套话？

输出：内容等级 + 具体缺失点

### 第4步：看结构

看这些问题：
- 有没有清楚的开头、中间、结尾？
- 定格是否放得合适？
- 结尾有没有回扣？

输出：结构评价 + 建议调整点

### 第5步：看语言

看这些问题：
- 动词是精准还是泛泛？
- 形容词是不是太多？
- 语气是否合适？

输出：语言问题 + 具体修改建议

### 第6步：看深度

看这些问题：
- 有没有角度变化？
- 有没有有意义的回扣？
- 有没有假抒情？

输出：深度评价 + 升格方向

## 档位判断

### 一档（优秀）

- 切题：完全符合题目要求
- 技巧运用（仅读写迁移）：迁移技巧使用恰当，效果自然
- 内容：定格清晰，细节丰富具体
- 结构：展开自然，回扣有力
- 语言：动词精确，无套话
- 深度：有角度变化或深层意蕴

### 二档（良好）

- 切题：基本符合，主题清晰
- 技巧运用（仅读写迁移）：有使用迁移技巧，但效果不够自然或略有生硬
- 内容：有定格，但细节不够具体
- 结构：有展开，但回扣不足
- 语言：基本具体，偶有套话
- 深度：有一定深度，但不突出

### 三档（合格）

- 切题：基本切题，主题模糊
- 技巧运用（仅读写迁移）：未使用迁移技巧，或使用明显不当
- 内容：有叙事但缺定格
- 结构：顺序清晰但无展开
- 语言：有内容但偏概括
- 深度：无明显深度

### 四档（待改进）

- 切题：偏离题意或主题不清
- 技巧运用（仅读写迁移）：未使用迁移技巧
- 内容：空泛，无具体内容
- 结构：混乱或不完整
- 语言：大量套话或假抒情
- 深度：无

## 输出格式

批改后输出：

1. **档位判断**：一档/二档/三档/四档

2. **分项分析**：
   - 切题：...
   - 技巧运用：（读写迁移写作时必填）...
   - 内容：...
   - 结构：...
   - 语言：...
   - 深度：...

3. **最值得改的 3 处**：
   - 第一处：原文 + 问题 + 改法
   - 第二处：原文 + 问题 + 改法
   - 第三处：原文 + 问题 + 改法

4. **下一步练习目标**：具体可执行的任务

## 示例

### 示例1：三档作文

原文片段：今天我去了公园，看到了很多花，我觉得很开心。

档位判断：三档（合格）

分项分析：
- 切题：如果题目是"一次外出"，基本切题
- 技巧运用：非读写迁移写作，跳过
- 内容：无定格，全是概括性叙述
- 结构：顺序清晰但无展开
- 语言：全是概括，无具体细节
- 深度：无

最值得改的 3 处：
1. "看到了很多花" → 问题：太笼统 → 改法：写一朵具体的花，用什么颜色、形状
2. "我觉得很开心" → 问题：假抒情 → 改法：用一个动作或画面暗示快乐
3. 整段缺少定格 → 问题：没有具体瞬间 → 改法：选择一个画面展开，比如看到花时的动作

下一步练习目标：用定格六圈法，写一个具体的公园画面（不少于3句）。

### 示例2：二档作文

原文片段：妈妈每天都很辛苦，我看着她忙碌的背影，心里很感动。

档位判断：二档（良好）

分项分析：
- 切题：符合写人题目
- 技巧运用：非读写迁移写作，跳过
- 内容：有定格（背影），但细节不够
- 结构：有定格但展开不足
- 语言：有画面但仍有套话（"心里很感动"）
- 深度：缺少角度变化

最值得改的 3 处：
1. "忙碌的背影" → 问题：仍是概括 → 改法：写具体动作，如弯腰、擦汗、脚步
2. "心里很感动" → 问题：假抒情 → 改法：用一个细节暗示，如想帮她却不知道怎么帮
3. 缺少回扣 → 问题：结尾无呼应 → 改法：加一句回扣开头或定格的句子

下一步练习目标：改写"忙碌的背影"这一句，用三个具体动词展开。

### 示例3：二档作文（读写迁移）

阅读材料技巧：用动作写心情
原文片段：我拿到试卷，偷偷塞进书包，一口气跑出校门。

档位判断：二档（良好）

分项分析：
- 切题：符合"一件难忘的事"题目
- 技巧运用：使用了"用动作写心情"技巧，"偷偷塞进""一口气跑出"传达了紧张和释然，但"偷偷"略显直白
- 内容：有定格瞬间，动作连续
- 结构：有定格但缺少前后展开
- 语言：动词具体，但整段偏短
- 深度：缺少角度变化

最值得改的 3 处：
1. "偷偷塞进书包" → 问题：动作有但稍直白 → 改法：换成更具体的动作，如"飞快地把试卷折了两折，塞到数学书后面"
2. 缺少前后画面 → 问题：只有定格没有展开 → 改法：在定格前加一句教室里的紧张（如"老师的手从我身边划过"）
3. "一口气跑出校门" → 问题：结尾太快 → 改法：加一个停顿或回扣，如"跑出校门那一刻，风灌进来，我才敢慢慢松开书包带"

下一步练习目标：在定格前后各加一句，让画面有来有去。
