# 数学画板

DSH Web 输入框上方的表达型数学工作台入口；点击后打开宽屏工作台。它只承载学生的思路，不做运算、不自动解题、不用图片识别，也不替学生提交答案。

## 定位

画板表达「有什么图案、每个代表多少、怎么摆放和分组」；加减乘除由学生自己在说明里讲，画板不提供运算模式，也不做对错判断。界面参考 Xiaoxue Workbench 的工作区优先结构重新实现：左侧图案工具箱、中间白色大画布、右侧按选择出现的命名面板；老师交流仍走 DSH 对话。

## 界面与交互

- 工具箱默认放小孩最常用的五个图案：小猫、小狗、汽车、人、苹果。点图案直接添加；也可以把图案拖到画布上的指定位置。
- 工具箱末尾的「更多图案」或左侧「设置」打开图案库；点一下图案就加入工具箱，再点一下收起来。已经摆在画布上的图形不会因为收起图案而消失，图案库共有 19 个图案：圆形、方块、三角形、星形、六边形、菱形、爱心、椭圆、小猫、小狗、汽车、人、苹果、小鱼、火箭、小花、蝴蝶、房子、冰淇淋。
- 单击选择，Shift 点击或用「多选」加选，空白处拖框多选；拖动已选图形可一起移动。拖动过程只显示预览，松手后一次性记入历史，单击不产生撤销记录。
- 选中图形后，浮动栏提供圈组、合并、拆开、复制、划去/恢复、删除。
- 右侧面板按选择变化：未分组时改名字；选中整组时改**组名**，组内图形不单独命名。
- 撤销/重做在画布工具行；「只看画布」可隐藏两侧面板；画布可缩放或全图显示。

## 分组规则

分组是平铺的「小兵编队」，没有子组：

- 选中任意图形点「圈为一组」：如果其中有图形原本属于别的组，那些旧组整体解散，未被选中的旧成员回到未分组，再组成一个新组。
- 组内点任意一个图形会选中整组；Shift 点击可把别的图形加进选择，再点「圈为一组」就并成新组。
- 「解散组」把成员全部变回独立图形；组名可改；解散后成员恢复各自的别名。
- 整个动作都是一步撤销。

## 合并规则

合并**只改数值和颜色，不换图形**：3 个「代表 2」的绿圆合并成 1 个蓝色圆、数值 6，名字不变，并记录合并来源，可「拆开」还原。

- 只有同一形状、同一数值、同属一组（或都未分组）、同一别名，且总量正好落在学生设定的一级时才能合并。
- 没有对应量级就先在设置里加一级，画板不会替你换图案或自己造量级。
- 合并结果带角标显示由几个图形合并而来；拆开后恢复原来的图形与数值。

## 设置：量级与图案

量级阶梯由学生自己设定，颜色按阶梯顺序取固定调色板（绿、蓝、紫、青、橙，再接橙红、红、洋红、深紫）。图形上始终标数值，不只靠颜色识别。

- 「设置」可增删数值级、调顺序，并在图案库里添加或收起工具箱图案。
- 「这些图案默认代表多少」列出当前工具箱里的图案，可给每个图案设定默认数值和默认名字；收起的图案保留自己的默认值，重新加入时继续生效。
- 保存时选择「只用于新图形」或「也改已有图形」；已合并的图形保留合并时的数值，未合并的已有图形改成本形状的默认值。
- 默认阶梯是 1、10、100、1000、10000，学生可以整个换掉；默认工具箱是猫、狗、汽车、人、苹果。

学生在对话里说「一个圆代表两个苹果」时，模型调 `math_board_settings` 把同一份设置写回本会话，工作台打开时自动同步；这走与设置面板相同的操作，不读取未提交的画板。设置里的 `shapes` 是工具箱显示清单，模型除非被明确要求添加或收起图案，否则原样带回。

## 学生怎样用

1. `/learn 加减法`（其他主题也可以），点「打开工作台」。
2. 从左侧挑图案点选或拖入；需要更多图案就到「设置」的图案库添加；拖动、框选、Shift 加选整理成想说的样子。
3. 选中后圈组、起名字、划去，或把同形同值的图形合并成更大量级。
4. 在「我想说」里写清这些图形代表什么。
5. 点「放入回答」回到对话，检查输入框后**自己**发送。

键盘：Tab 聚焦图形，Enter/空格选择，Shift+Enter 切换多选，方向键移动，Delete 删除。

## 数据

`kind: "math-board", schemaVersion: 3`：

```
settings: { levels: [{value, color}], defaults: [{shape, value, alias}], shapes: [shape] }
objects:  [{ id, shape, value, color, alias, x, y, groupId, removed, sources }]
groups:   [{ id, alias }]
note:     学生说明
summary:  确定性数量汇总（不是对错结论）
```

`settings.defaults` 覆盖全部 19 个图案，学生的默认值不会因图案收起而丢失；`settings.shapes` 是工具箱当前显示的图案顺序（至少一个）。`model.js` 是唯一领域实现；`config-bridge.js` 是设置的服务端桥（工具、用户命令、会话投影共用同一操作），画板本身仍只存在浏览器本地，按 DSH 会话隔离。坐标不隐含算式。

旧版 `schemaVersion: 1` 和 `2` 的 JSON 会自动迁移：v1 保留圆形、方块、三角形作为工具箱内容，v2 保留原来的十个图案，并为新图案补上默认值；浏览器草稿会从 v2 存储键读入后写回新的 v3 存储键。详见 [教学协议](<../math-low/skills/math-core/references/structured-drawing.md>)。

## 开发与安装

```bash
node math-board/build.mjs
node --check math-board/client.js
node --test math-board/model.test.js math-board/config-bridge.test.js math-board/view.test.js
node scripts/check-skills.mjs
node math-board/preview.mjs /tmp/math-board-shapes.html   # 可选：在无头 Chrome 或浏览器里目视检查图案
# 用 DSH plugin_manager 安装本目录；也可人工运行：
dsh plugin --profile web add link:/Users/yugeng/programming/dsh-edu/math-board
```

纯 JavaScript 包，无第三方依赖、无安装脚本。提交生成的 `client.js`；修改模型、视图、样式或字典后运行 build。`preview.mjs` 用最小 React→SVG 适配器渲染全部图案，便于对比猫、狗等小尺寸辨识度；它不进入运行时包。首次安装支持 live activation，替换已安装模块是否需要重启以安装结果为准。

图案是本项目用 SVG 基本图元绘制的原创图形；`build.mjs` 将视图与图案工厂一起内联进 `client.js`，运行时不需要外部图片。

## 手工验收

- 进入真实会话打开工作台；检查触摸拖动、框选、键盘操作、明暗主题与窄窗口。
- 工具箱默认显示猫、狗、汽车、人、苹果；猫有尖耳朵和胡须，狗有下垂耳朵、口鼻和舌头，缩到 28 px 仍能区分。
- 打开「设置」→ 图案库，添加小鱼/火箭等图案后工具箱出现，收起后消失；已摆在画布上的对应图形仍在。至少保留一个工具箱图案。
- 给新加入的图案设默认数值和名字，保存后添加该图案使用新默认值；恢复默认回到猫、狗、汽车、人、苹果。
- 画布底部工具行（撤销/重做、多选、只看画布、缩放）和页脚（保存/打开/清空、放入回答、返回对话）在桌面、窄窗口和短窗口下都完整可见，不被画布或弹窗边缘裁切。
- 拖动图形能摆放，多选后一起移动，松手只产生一条撤销记录。
- 分组：选中含旧组员后重新圈组，旧组解散且未选中成员回退为未分组；解散后成员别名恢复。
- 合并：设为「圆代表 2」后合并 3 个圆，得到一个蓝色圆、数值 6，图形不变；拆开后恢复 3 个绿圆。
- 设置：改「圆代表 2」只影响新图形；选「也改已有图形」后未合并的圆也变成 2。自然语言说同一句话后，打开工作台看到同样结果。
- 原输入框有文字时「放入回答」不丢失原稿；导出再导入数据一致；无效 JSON 显示失败且不更改现有画板。
