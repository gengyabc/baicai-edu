# 几何模式、教师演示与老师参考图

[English](geometry.md) | [中文](geometry.zh.md)

## 三个 tab

画板顶部有三个 tab：算数、几何、教师演示。算数和几何各自的画布、工具栏、草稿存储键、撤销历史、选择与视口互相独立；切换 tab 不转换、不传递数据，两个草稿都保留。教师演示页只显示老师用几何图元放下的已知条件，学生不能在这一页上改图；这一页整体可纵向滚动，图的画框在缩放后也能横向、纵向滚动，长标题或说明不会把图挤没。点「放到我的几何画板」才把当前这幅图追加到几何草稿，并记成几何页上的一步撤销。教师图里的文字元素会原样复制成学生草稿里的文字元素；图形旁短标签（图形 `note`）随图形一起复制，复制后同样能点开修改；两者复制后都是学生自己的文字，可以选中、拖动、改写或删除；同一幅图可以连续放多次，后放的那份会换一组新 id，不会覆盖或改坏先放的那份。它们共用题目参考。算数和几何还共用「我想说」和「放入回答」；教师演示页没有这两项。三个页面底部都有「返回对话」；演示页没有自己的教程或引导。老师还没放图时演示页只显示题目参考和「返回对话」，不显示标题或「老师还没有在这里放图」的占位说明。它和两个学生页一样由外层统一接收关闭回调，所以任何 tab 上点它都会关掉画板。

## 工具

选择、点、线段、三角形、多边形、圆、平行四边形、矩形、文字、取中点、辅助线。先放点再连线；线/面工具在空白处点击会自动落点。三角形点三个点即闭合，存成三顶点多边形。取中点不是画图工具：选中一条两端都是自由点、且还没有中点的线段后，按钮才可点，点一下在该线段上标出中点。辅助线是开关，打开后新画的图形用虚线。点显示 A/B/C 标签且可改名，改名不破坏引用。派生点可见、可选中、可写说明，但不能当作拖动把手或新图形的端点。

## 文字

文字工具点画布空白处，弹出写字卡，写下内容点「保存」（Esc 或「取消」放弃，空内容不写入）。写好的文字是画板上的一个元素：选择工具可选中、拖动（贴住画板边缘停下）、Delete 或「删除所选」删掉，也可以框选（框住或碰到文字就算选中）；选中后浮动栏的「修改文字」在原地改写，不新增第二个文字。文字保留学生自己的换行，最多 200 字，存成 `type: "text"`，带自己的锚点 `x`/`y`（左侧基线），不引用任何点，也不参与端点吸附、取中点和图形选择。它是学生的书写内容，不是那种「图形旁短说明」的 `note`。

## 图形旁短标签也是可改的字

图形 `note` 不超过 20 字时会画在图形旁边。现在这行字本身就能点：选中工具下点它，直接打开写这条说明的卡片，改完保存，画布上的字立刻跟着变；鼠标移上去会变蓝。选中带短标签的图形时，「我想说」也指向这条标签，避免看着画布上的字却改到整板说明。

## 拖动

自由点直接拖动；松手才记一步撤销，拖动中只显示预览。派生点由构造算出，不可拖动。圆拖圆心时整个圆一起平移、半径不变；拖圆上点改半径，半径不小于阈值。矩形的第三个点只决定「哪一侧、多高」：点落在垂直于 `P1P2` 的那一点上，不在直角位置的点击点不会留在画板上成为一个多余的角。平行四边形与矩形都按三点构造（`P4 = P1 + P3 − P2`），两个对角对是 `P1P3` 和 `P2P4`：拖动任一自由角，该角跟随指针，它的对角保持不动，另外两角绕这条对角的中点重算。矩形按对角等长且垂直重算，因此怎么拖都还是四个直角。拖动跟随指针，非法位置被吸收在退化阈值处（在允许的方向上滑到最后一个合法位置）：多边形和四边形不与自己交叉，拖动落点不允许原本分离的图形新产生重叠，只共用一个顶点或圆的外切接触不算重叠。圆的检查包含内部区域与包含关系，并在圆心携带半径点后检查最终形状；已有圆重叠的组合图仍可编辑，一旦分开便不能再拖成重叠。创建和导入规则不变，拖动检查候选落点，不做连续路径碰撞检测。

## 视图

网格与吸附是本地 UI 状态，不进快照。「适应宽度」按当前可见区域同时考虑宽和高，把整张画板连同点标签、图形旁短说明和学生文字一起放进画框，不会因为窗口较矮就裁掉画板下半部分。缩放会真正放大图形（线宽、标签与点一起变大）：画布随缩放变大，画框出现滚动条可以看到全部内容，不再把视图裁成中间一块；点「＋」「−」即离开适应视图，点「适应宽度」回到全图。

## 说明

整板一份说明；每个点、每个图形各一条说明。选中对象后点「我想说」写的就是该对象的说明；选中同一图形的一条或多条边时写它所属图形的说明。未选中或混合选中多个对象时写整板说明。算数和几何各有自己的一份整板说明，互不覆盖。教师演示图上的短说明画在图形旁边。

## 说明与短标签

整板说明和点上说明可以写长；图形旁画出来的短标签最多 20 字，更长的图形说明只留在说明卡里，画布上不再标注「有说明」，也不会出现看不着的字。点这行短标签就直接改写这条说明，可点的范围正好是画出来的那行字。

## 清空本模式

确认后清空几何画布与该模式撤销历史，不删除已放入或已发送的附件，也不影响数量画板。

## 放入回答

只附带 `我的几何画板.json` 和整板说明；没有几何修改记录附件。附件是只读快照，学生检查后自己发送。

## 清空工具的作用范围

`math_board_clear` 只作用于数量模式；几何 tab 不显示它的任何入口或提示。工具本身的任务边界见[任务切换清空](clearing.zh.md)。

## 快照格式

`kind: "geometry-board", schemaVersion: 1`：

```
points:   [{ id, label, kind: "free"|"derived", x, y, construction?, note }]
elements: [{ id, type: "segment"|"polygon"|"circle"|"parallelogram"|"rectangle", points|centerPointId+radiusPointId, role, note }]
          文字：{ id, type: "text", role, note, x, y, text }
note:     整板说明
canvas?:  { width, height } // 可选纸面范围；省略时为 800×600
```

几何页按可见区域扩展纸面、网格和可绘制坐标，横纵始终使用同一个缩放比例，不将固定画板居中留白，也不拉伸图形。窗口尺寸变化不会移动已有点；重新适配保留全部已有内容，空余纸面不因反复横竖切换无限累积。扩展纸面通过可选 `canvas` 随快照保存，宽为 800–10000 的整数、高为 600–10000 的整数；旧版未带尺寸的 v1 文件仍按 800×600 打开。清空本模式保留纸面尺寸，教师演示复制使用目标纸面范围。

派生点只保存构造（`midpoint` 或三点定第四点，`P4 = P1 + P3 - P2`），位置由构造重算，不作为权威坐标；快照验证会忽略伪造的派生坐标，并拒绝悬空引用、退化图形、重名标签和跨模式文件。文字元素在快照里保存学生写下的原文和它的锚点；空文字、控制字符、超过 200 字、写到画板外，或给文字挂上点引用、给图形挂上文字字段的文件都会被拒绝，不做猜测修复。教师演示图也支持文字元素，复制后可由学生改写。插件系统提示声明只读提交边界；两个数学年级段的共同读取与信任规则由[共享画板契约](<../../math-common/skills/math-common/references/board-contract.md>)统一维护。

## 教师示意与学生作图

几何已知条件画在「教师演示」页。算数页和几何页都不显示独立的「老师示意图」。学生点「放到我的几何画板」后，当前这幅图才复制进自己的几何草稿。教师通过 `geometry_board_draw` 管理几何演示：先 `get`，再以 `expectedRevision` 调用 `show` 或 `hide`。返回 `recorded` 表示请求已记录，不是目视执行回执，也不表示学生已经复制。

- **按目标选择**：理解已给条件而画图操作会分散注意时，可提供简洁标注图；选择表征、构造、整理数量本身是学习目标时，留给学生画或描述。部分起点与逐步撤去支持按实际表现调整，不固定采用“老师先画”或“学生先画”。图示也有读图/操作负担，不保证降低认知负荷。
- **不替学生推理**：例如长9宽1与长6宽4的比较，可只给轮廓、名称和已知边长；面积、比较结论及关键辅助线仍留给学生。学生也可直接用算式、口述或纸笔，不必复制教师图。
- **完全隔离**：教师参考不读、不改任一学生草稿，不进撤销/重做、修改记录、导出文件、输入框或作答附件，不自动打开画板；教师展示不算学生表现。两个现有快照格式和几何只读判断边界不变。
- **最小图元**：`reference` 包含 `title`、`description`、`width`、`height`、`shapes`；只接受矩形、线段、圆和纯文本标注，不接收任意 SVG、HTML、图片或外部链接图元。描述用于无障碍文本替代；以标注/题目条件为准，不从图形比例自动测量。
- **独立生命周期**：每个DSH会话只保留最新教师参考，切换题目文本下拉框不会切换示意图；标题应明确对应任务。换题、结束或旧图会泄露独立检查的方法时，由教学方隐藏/替换，不清学生画布。工具不可用时继续用文字或可选纸笔。

教学依据、适用范围与产品推论见[研究笔记](<../../docs/research/math-representation-scaffolding-research.md>)；共享决策规则见[表征契约](<../../math-common/skills/math-common/references/representation-contract.md>)。只读参考隔离是证据与隐私边界设计，尚未通过学生实验验证其学习效果。
